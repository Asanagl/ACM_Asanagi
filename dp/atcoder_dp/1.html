Codeforces 算法竞赛讲解

k松散子序列 DP推导

本质不同子序列计数 + 间隔限制

步骤 0 / 8

示例输入

字符串 S (n=6), k=2
a b a b c a
点击"下一步"开始讲解...

DP数组 (dp[i] 表示前i个字符的方案数，含空串)

i 0 1 2 3 4 5 6
dp[i] 1 ? ? ? ? ? ?
字符 - a b a b c a
计算过程：

核心递推式

dp[i] = dp[i-1] + add - sub
其中 add = get(i-k-1) // 选S[i]，接在合法前缀后
sub = get(last[S[i]]-k-1) // 去重：上次该字符的贡献
get(x) = 1 if x<0 else dp[x] // 负数时只有空串

C++ 实现

O(n) 复杂度 
const int MOD = 998244353;
// dp[i] 前i个字符的方案数（含空串）
// last[c] 字符c上一次出现的位置

auto get = [&](int x) -> int {
    if (x < 0) return 1;  // 只有空串
    return dp[x];
};

for (int i = 1; i <= n; i++) {
    int c = S[i-1] - 'a';
    
    int add = get(i - k - 1);  // 选S[i-1]
    int sub = 0;
    if (last[c] != 0) 
        sub = get(last[c] - k - 1);  // 去重
    
    dp[i] = (dp[i-1] + add - sub) % MOD;
    if (dp[i] < 0) dp[i] += MOD;
    
    last[c] = i;  // 更新最后出现位置
}
return (dp[n] - 1 + MOD) % MOD;  // 去掉空串

💡 竞赛选手思路

  • 1. 先看k=0的特殊情况 → 这就是经典的不同子序列问题
  • 2. 发现"松散"限制只影响能接在哪些子序列后面
  • 3. 去重的本质是：减去上次该字符新增的那些方案
