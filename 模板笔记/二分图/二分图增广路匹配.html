📚 核心概念解析

1. 什么是增广路？

增广路 (Augmenting Path) 是二分图中一条从某个未匹配点出发， 到另一个未匹配点结束的路径，且路径上的边交替出现： 未匹配边 → 匹配边 → 未匹配边 → 匹配边 → ... → 未匹配边。

关键性质：增广路的起点和终点都是未匹配点，且路径长度（边数）一定是奇数。 如果我们把增广路上的匹配状态全部翻转（匹配变未匹配，未匹配变匹配）， 匹配数就会增加 1！

2. 匈牙利算法核心思想

匈牙利算法（König-Egeváry定理）的核心就是不断寻找增广路：

// 伪代码 while (存在增广路) { 找到一条增广路 P; // 翻转P上所有边的匹配状态 for (P中的每条边 e) { e.匹配 = !e.匹配; } 匹配数++; } return 匹配数; // 此时达到最大匹配

当图中不存在增广路时，当前的匹配就是最大匹配。 这是Berge定理的直接推论。

3. 为什么增广路能增加匹配数？

假设增广路有 k 条匹配边和 k+1 条未匹配边（因为路径交替且两端是未匹配边）。 翻转后：k 条匹配边变成未匹配，k+1 条未匹配边变成匹配。 净增加：(k+1) - k = 1 条匹配边！

4. 算法复杂度

每次增广匹配数至少增加1，最多进行 |V| 次增广。 每次DFS寻找增广路复杂度 O(E)。 总复杂度：O(V × E)。
