核心代码

for (int i = 0; i < n; i++) { int t = -1; // 线性扫描找最小 for (int j = 0; j < n; j++) if (!st[j] && (t == -1 || dist[j] < dist[t])) t = j; st[t] = 1; for (int j = 0; j < n; j++) dist[j] = min(dist[j], dist[t] + g[t][j]); }
与堆优化版对比：
• 无需优先队列 (priority_queue)
• 每次 O(V) 扫描代替 O(logV) 取堆顶
• 稠密图 (E≈V²) 时反而更快
• 代码短，适合竞赛手写
💡 操作提示：
• 左键点击空白处：添加节点
• 右键点击节点：设为源点
• 拖拽节点：调整位置
• 双击节点/边：删除
