# 357 号样本：最后一刀——题解

## 一、核心观察

题目中的每件样本会一直保持为一个包含核心方块的长方体。

对于核心坐标为 $(x,y,z)$ 的样本，分别观察核心到六个外表面之间还有多少层可以被削掉：

| 表面 | 可削厚度 |
| --- | ---: |
| `X-` | $x-1$ |
| `X+` | $3-x$ |
| `Y-` | $y-1$ |
| `Y+` | $5-y$ |
| `Z-` | $z-1$ |
| `Z+` | $7-z$ |

例如核心位于 $(2,1,1)$ 时，六个厚度依次为：

$$
1,\ 1,\ 0,\ 4,\ 0,\ 6.
$$

如果从某个表面削掉 $k$ 层，只有这个表面对应的厚度会减小 $k$，其余五个厚度完全不变。

不同样本之间也互不影响。

注意，削层时其他方向的截面面积可能变小，但可削的层数不变。例如从 `X+` 面削层会缩小之后每一层的宽度，却不会改变核心到 `Y-`、`Y+` 两侧分别隔着多少层。需要记录的是层数，而不是剩余小方块总数。

更严格地说，若当前保留的坐标区间是 $[l_x,r_x]$、$[l_y,r_y]$、$[l_z,r_z]$，六个厚度应为 $x-l_x,r_x-x,y-l_y,r_y-y,z-l_z,r_z-z$。一次合法操作只改变其中一个端点，恰好将一个厚度减小，且任意更小的非负厚度都能通过一刀实现。上表是三个区间初始为 $[1,3]$、$[1,5]$、$[1,7]$ 时的特例。

因此，整局游戏可以改写为：

- 当前有若干个非负整数；
- 每次选择其中一个正整数；
- 把它减小为任意更小的非负整数；
- 所有整数都变成 $0$ 时游戏结束；
- 完成最后一次操作的人获胜。

这正是 Nim game。

本题真正需要发现的是：一件三维样本不是对应一个状态，而是隐藏了六个相互独立的状态。

## 二、胜负判定

将所有样本的全部可削厚度进行按位异或，记结果为 $S$。

$$
S=h_1\mathbin{\mathtt{xor}}h_2
\mathbin{\mathtt{xor}}\cdots
\mathbin{\mathtt{xor}}h_{6n}.
$$

结论如下：

- $S=0$：当前玩家必败，输出 `Second`；
- $S\ne0$：当前玩家必胜，输出 `First`，并构造一个操作将异或和变为 $0$。

### 为什么异或和为 0 时必败

假设当前异或和为 $0$，一次操作把某个厚度从 $h$ 改成 $h'$，其中 $h'<h$。

操作后的异或和为：

$$
S'=0\mathbin{\mathtt{xor}}h\mathbin{\mathtt{xor}}h'
  =h\mathbin{\mathtt{xor}}h'.
$$

因为 $h\ne h'$，所以 $h\mathbin{\mathtt{xor}}h'\ne0$。

也就是说，从异或和为 $0$ 的局面出发，无论怎样合法操作，都会进入异或和不为 $0$ 的局面。

### 为什么异或和不为 0 时必胜

设当前异或和为 $S\ne0$。

一定可以找到一个厚度 $h$，使得：

$$
h'=h\mathbin{\mathtt{xor}}S<h.
$$

具体来说，设 $S$ 的最高位 $1$ 位于第 $p$ 位。因为所有厚度在第 $p$ 位的异或结果为 $1$，所以至少有一个厚度 $h$ 的第 $p$ 位也是 $1$。计算 $h\mathbin{\mathtt{xor}}S$ 后，比第 $p$ 位更高的各位不变，第 $p$ 位则从 $1$ 变成 $0$，因此结果一定小于 $h$。

将 $h$ 减小为 $h'$ 后，新异或和为：

$$
S'
=S\mathbin{\mathtt{xor}}h\mathbin{\mathtt{xor}}h'
=S\mathbin{\mathtt{xor}}h
 \mathbin{\mathtt{xor}}(h\mathbin{\mathtt{xor}}S)
=0.
$$

因此，先手可以主动把局面变成异或和为 $0$ 的局面。

之后对手每次都会把异或和从 $0$ 变成非 $0$，先手再将它恢复为 $0$。最终完成最后一次操作的一定是先手。

## 三、如何构造第一刀

当 $S\ne0$ 时，依次枚举每件样本的六个厚度。

对于当前厚度 $h$，计算：

$$
h'=h\mathbin{\mathtt{xor}}S.
$$

如果 $h'<h$，就找到了可以操作的表面。

将目标厚度 $h'$ 转成切割位置。设核心在该方向的编号为 $c$：

- 缩小坐标较小一侧的厚度：$k=c-h'-1$；
- 缩小坐标较大一侧的厚度：$k=c+h'$。

输出样本编号、方向 `X` / `Y` / `Z` 和 $k$，即在第 $k$、$k+1$ 层之间切开。

Nim 的性质保证：当 $S\ne0$ 时，一定至少存在一个满足 $h'<h$ 的厚度。

以下用 `X-`、`X+` 等记号区分各方向的两侧，仅用于分析，不是输出格式。六个数组下标的对应关系为：

| 下标 | 表面 | 厚度 |
| ---: | --- | ---: |
| $0$ | `X-` | $x-1$ |
| $1$ | `X+` | $3-x$ |
| $2$ | `Y-` | $y-1$ |
| $3$ | `Y+` | $5-y$ |
| $4$ | `Z-` | $z-1$ |
| $5$ | `Z+` | $7-z$ |

## 四、样例推导

### 第一局

核心坐标为 $(2,3,4)$，六个厚度是：

$$
1,\ 1,\ 2,\ 2,\ 3,\ 3.
$$

每个数都出现两次，因此：

$$
1\mathbin{\mathtt{xor}}1
\mathbin{\mathtt{xor}}2\mathbin{\mathtt{xor}}2
\mathbin{\mathtt{xor}}3\mathbin{\mathtt{xor}}3=0.
$$

所以 Bob 必胜，输出 `Second`。

### 第二局

核心坐标为 $(2,1,1)$，六个厚度是：

$$
1,\ 1,\ 0,\ 4,\ 0,\ 6.
$$

异或和为：

$$
S=1\mathbin{\mathtt{xor}}1
\mathbin{\mathtt{xor}}0
\mathbin{\mathtt{xor}}4
\mathbin{\mathtt{xor}}0
\mathbin{\mathtt{xor}}6
=2.
$$

枚举到 `Z+` 时，当前厚度 $h=6$：

$$
h'=6\mathbin{\mathtt{xor}}2=4<6.
$$

所以应当从坐标较大的一侧削掉：

$$
6-4=2
$$

层。切割位置为 $k=1+4=5$，可以输出：

~~~text
First
1 Z 5
~~~

### 第三局

两件样本完全相同，每个厚度都会在全局异或中出现两次，因此总异或和为 $0$，输出 `Second`。

## 五、正确性证明

### 引理 1

每个表面对应的可削厚度都是一个独立的 Nim 堆。

**证明：**

从某个表面削掉 $k$ 层，只会使这个表面的可削厚度减少 $k$，不会改变同一样本其他五个表面的可削厚度，也不会影响其他样本。

当六个方向的厚度全部为 $0$ 时，该样本只剩核心方块；当所有样本的厚度都为 $0$ 时，游戏结束。

因此每个厚度的变化规则与一个 Nim 堆完全相同。证毕。

### 引理 2

若所有厚度的异或和为 $0$，当前玩家必败；否则当前玩家必胜。

**证明：**

异或和为 $0$ 时，修改任意一个厚度都会使异或和变为非 $0$。

异或和为非 $0$ 时，一定存在某个厚度 $h$，满足 $h\mathbin{\mathtt{xor}}S<h$。将其修改为 $h\mathbin{\mathtt{xor}}S$ 后，异或和变为 $0$。

每次操作都会严格减小所有厚度之和，因此游戏一定结束。非 $0$ 局面可以进入 $0$ 局面，而 $0$ 局面只能进入非 $0$ 局面。终止局面的全部厚度均为 $0$，其异或和也为 $0$。对厚度总和归纳，即可得到结论。证毕。

### 定理

算法输出的胜负结果与第一刀均正确。

**证明：**

根据引理 1，原游戏等价于所有可削厚度组成的 Nim game。

当 $S=0$ 时，根据引理 2，先手 Alice 必败，算法输出 `Second` 正确。

当 $S\ne0$ 时，算法找到满足 $h'=h\mathbin{\mathtt{xor}}S<h$ 的厚度，并从对应表面削掉 $h-h'$ 层。该操作合法，且操作后的全局异或和为 $0$。根据引理 2，这是一刀必胜开局，因此算法输出 `First` 和该操作正确。证毕。

## 六、复杂度分析

每件样本只处理六个厚度，因此：

- 时间复杂度：$O(n)$；
- 空间复杂度：$O(n)$。

参考实现保存了每件样本的六个厚度，便于读完本局输入后寻找第一刀，因此使用 $O(n)$ 空间。这不是空间下界：由于厚度只有 $0$ 至 $6$，也可为每种厚度保存一个出现位置，将额外空间降至 $O(1)$；本题无须采用这一优化。

## 七、参考代码

~~~cpp
#include <array>
#include <iostream>
#include <string>
#include <vector>

using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    const string axes = "XYZ";

    int T;
    cin >> T;

    while (T--) {
        int n;
        cin >> n;

        vector<array<int, 6>> thickness(n);
        int xor_sum = 0;

        for (int i = 0; i < n; ++i) {
            int x, y, z;
            cin >> x >> y >> z;

            thickness[i] = {
                x - 1, 3 - x,
                y - 1, 5 - y,
                z - 1, 7 - z
            };

            for (int h : thickness[i]) {
                xor_sum ^= h;
            }
        }

        if (xor_sum == 0) {
            cout << "Second\n";
            continue;
        }

        cout << "First\n";

        bool found = false;
        for (int i = 0; i < n && !found; ++i) {
            for (int j = 0; j < 6; ++j) {
                int h = thickness[i][j];
                int new_h = h ^ xor_sum;

                if (new_h < h) {
                    int core = thickness[i][j / 2 * 2] + 1;
                    int k = (j % 2 == 0) ? core - new_h - 1 : core + new_h;
                    cout << i + 1 << ' ' << axes[j / 2] << ' ' << k << '\n';
                    found = true;
                    break;
                }
            }
        }
    }

    return 0;
}
~~~

## 八、常见错误

1. 把一件样本只看成三个状态。  
   每个维度被核心分成正、负两个方向，一件样本实际对应六个独立厚度。

2. 将 `X+` 的厚度写成 $x-1$。  
   `X-` 对应 $x-1$，`X+` 对应 $3-x$，其他方向同理。

3. 将剩余厚度或削去层数直接当作 $k$ 输出。  
   $k$ 是切割位置：较小坐标侧取 $c-h'-1$，较大坐标侧取 $c+h'$。

4. 在 $S=0$ 时继续输出操作。  
   此时只需要输出一行 `Second`。

5. 忘记本题使用 Special Judge。  
   必胜第一刀可能不唯一，只要操作合法且操作后异或和为 $0$ 即可。
