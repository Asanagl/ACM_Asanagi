# 子矩阵求和题解

## 思路

题目要求 $q$ 次独立的矩形求和，每次询问给出闭区间 $[r_1,r_2]\times[c_1,c_2]$。因为 $n,m\le 100$、$q\le 1000$，本题有两条都能通过的路：

1. **逐格枚举**：对每次询问，把矩形内的格子逐个累加。总代价 $O(qnm)\le 1000\times100\times100=10^{7}$ 次加法。
2. **二维前缀和**：先建一张 $(n+1)\times(m+1)$ 的前缀表，之后每次询问用四次查表容斥出答案，总代价 $O(nm+q)$。

主解走第一条（最贴题面定义、不易写错），独立参考解走第二条（算法完全不同，用来交叉印证）。注意两条路都必须用 $64$ 位整数累加：单个答案的绝对值可达 $100\times100\times10^9=10^{13}$。

二维前缀和的定义是

$$
P[i][j]=\sum_{x=1}^{i}\sum_{y=1}^{j}a_{x,y},\qquad P[0][\ast]=P[\ast][0]=0,
$$

递推为 $P[i][j]=a_{i,j}+P[i-1][j]+P[i][j-1]-P[i-1][j-1]$，询问容斥为

$$
\mathrm{ans}=P[r_2][c_2]-P[r_1-1][c_2]-P[r_2][c_1-1]+P[r_1-1][c_1-1].
$$

容斥的直觉：取"左上角到 $(r_2,c_2)$"的大矩形，减去上方一条和左方一条，但左上角那块被减了两次，所以再加回来一次。

## 算法

主解（`solution.cpp`）：

1. 读入 $n,m,q$，读入整个矩阵到 $a[1..n][1..m]$（`long long`）。
2. 对第 $k=1..q$ 次询问，读入 $r_1,c_1,r_2,c_2$。
3. 双重循环 $i=r_1..r_2$、$j=c_1..c_2$，把 $a_{i,j}$ 累加进 `total`（`long long`，每次询问前清零）。
4. 输出 `total` 并换行。

参考解（`solution2.cpp`）：

1. 读入 $n,m,q$。
2. 边读边建前缀表：$P[i][j]=a_{i,j}+P[i-1][j]+P[i][j-1]-P[i-1][j-1]$，其中 $a_{i,j}$ 读入后即用即弃。
3. 每次询问按上式四点容斥，输出结果。

## 正确性证明

**引理 1：逐格枚举的输出等于题目定义的子矩阵和。**

证明：题面把答案定义为 $\sum_{i=r_1}^{r_2}\sum_{j=c_1}^{c_2}a_{i,j}$。程序的双重循环下界取 $r_1,c_1$、上界取 $r_2,c_2$，且循环变量取遍区间内每个整数一次。因此被累加的项集合与题面求和的项集合完全相同，顺序不影响加法结果，`total` 即为答案。$\square$

**引理 2：前缀表满足 $P[i][j]=\sum_{x\le i,\,y\le j}a_{x,y}$。**

证明：对 $i+j$ 归纳。$i=0$ 或 $j=0$ 时 $P=0$，与空和一致。设 $i,j\ge1$ 且更小的下标都成立。把"$x\le i,\,y\le j$"的格子按是否含第 $i$ 行、第 $j$ 列分成四类：
- 不含第 $i$ 行也不含第 $j$ 列：$x\le i-1,\,y\le j-1$，和为 $P[i-1][j-1]$；
- 含第 $i$ 行不含第 $j$ 列：$P[i][j-1]-P[i-1][j-1]$；
- 不含第 $i$ 行含第 $j$ 列：$P[i-1][j]-P[i-1][j-1]$；
- 同时含第 $i$ 行与第 $j$ 列：只有格子 $(i,j)$ 本身，为 $a_{i,j}$。

四类互不相交且覆盖全部，相加得 $a_{i,j}+P[i-1][j]+P[i][j-1]-P[i-1][j-1]$，与递推式一致。$\square$

**引理 3：四点容斥给出的恰是 $[r_1,r_2]\times[c_1,c_2]$ 的和。**

证明：由引理 2，

$$
P[r_2][c_2]-P[r_1-1][c_2]-P[r_2][c_1-1]+P[r_1-1][c_1-1]
=\sum_{x\le r_2,\,y\le c_2}a_{x,y}-\sum_{x\le r_1-1,\,y\le c_2}a_{x,y}-\sum_{x\le r_2,\,y\le c_1-1}a_{x,y}+\sum_{x\le r_1-1,\,y\le c_1-1}a_{x,y}.
$$

对每个格子 $(x,y)$ 考察它在四项中的系数。记指示量 $[x\le u]$ 与 $[y\le v]$，系数为

$$
[x\le r_2][y\le c_2]-[x\le r_1-1][y\le c_2]-[x\le r_2][y\le c_1-1]+[x\le r_1-1][y\le c_1-1]
=\big([x\le r_2]-[x\le r_1-1]\big)\big([y\le c_2]-[y\le c_1-1]\big).
$$

因为 $x,y\ge1$，$[x\le r_2]-[x\le r_1-1]$ 在 $r_1\le x\le r_2$ 时等于 $1$，否则等于 $0$；列的因子同理。故系数为 $1$ 当且仅当 $x\in[r_1,r_2]$ 且 $y\in[c_1,c_2]$，其余为 $0$。$\square$

**定理：主解与参考解的输出均正确。**

证明：主解由引理 1 直接得证。参考解由引理 3 得证：第 $k$ 次询问的输出正是题面要求的那一个求和。两解都由 $k=1$ 循环到 $k=q$，每次输出一行一个整数，输出格式也符合要求。$\square$

## 复杂度

- 主解：时间 $O(nm+qnm)$，最坏 $10^{7}$ 次加法；空间 $O(nm)$。
- 参考解：建表 $O(nm)$，询问 $O(1)$ 每次，总时间 $O(nm+q)$；空间 $O(nm)$。

两者在 $n,m\le100$、$q\le1000$ 下都远低于 $1000\,\mathrm{ms}$ 与 $256\,\mathrm{MiB}$。

## 边界情况

- $n=m=1$：只有一个格子，任何询问（必然 $r_1=r_2=c_1=c_2=1$）输出该格子的值，可能就是 $a_{1,1}$ 本身，也可能是 $-10^9$。
- $r_1=r_2$：询问退化为一行；$c_1=c_2$ 退化为列；两者同时成立退化为单点。程序不需要任何特判，闭区间的循环自然覆盖。
- 全负矩阵：累加结果单调递减，正是考察 `long long` 与初值 $0$ 是否正确的地方。
- 全零矩阵：答案恒为 $0$，`unsigned` 或未清零的累加器会在这里暴露。
- 满覆盖询问 $(1,1,n,m)$：答案绝对值最大可达 $10^{13}$，`int` 必然溢出。
- $q=1000$ 且每次都是满覆盖：主解要跑 $1000\times10^{4}=10^{7}$ 次加法，是本题最慢的形态。

## 常见错误与数据设计

按三个层次枚举：

- **思路层**
  - 把闭区间当半开区间（`wrong-a.cpp`）：循环写成 `i < r2`、`j < c2`，漏掉第 $r_2$ 行与第 $c_2$ 列。`full-cover-1`、`point-query-1`（单点询问会被算成 $0$）和样例即可击杀。
  - 容斥漏掉 $+P[r_1-1][c_1-1]$（`wrong-b.cpp`）：左上角被多减一次。`target-prefix-*`、`target-half-*`（前缀/半平面形态）与所有 $r_1>1,c_1>1$ 的询问都会偏差。
  - 忽略列边界、对整行求和（`wrong-d.cpp`）：`target-colrange-*`（列区间很窄而行范围很宽）会给出远大于正确答案的值，`single-col-1`（$m=1$ 时恰好正确，但其它用例立刻暴露）也一样。
- **复杂度层**
  - 每次询问按定义四重循环重算整张前缀表（`wrong-e.cpp`，$O(qn^2m^2)\approx10^{11}$）：`max-1`、`max-2` 稳定超时。注意本题的"逐格枚举" $O(qnm)$ 是**正确且合法**的，故意没有把它列为错解；只有 $O(qn^2m^2)$ 这种明显不合理的写法才应被卡掉。
- **实现层**
  - 用 32 位 `int` 累加（`wrong-c.cpp`）：`large-sum-1`、`large-neg-1`、`max-mixed-*` 上答案超过 $2^{31}-1$，输出变成负数或错误值。样例第 $1$ 个询问的 $6000000000$ 就已经溢出，因此这条错解在样例上即被击杀。

所有保留的错解都产生**内容错误**或**超时**，没有依赖数组越界、除零等意外运行时错误来伪装成预期 WA。

## 实现注意事项

- 累加变量必须是 `long long`，矩阵元素也建议直接存 `long long`，避免读入时截断。
- 主解的 `total` 要在每次询问开始前重置为 $0$，且声明在询问循环内部最省心。
- 前缀表的第 $0$ 行、第 $0$ 列必须初始化为 $0$，并让下标从 $1$ 开始，否则 $r_1=1$ 或 $c_1=1$ 时会出现负下标。
- 读入量最大约 $10^{4}+4\times10^{3}$ 个整数，建议关闭 `cin` 与 `stdio` 的同步；用 `scanf`/`printf` 亦可。
- 输出用 `'\n'`，不要用 `endl`；$q\le1000$ 行虽不多，但保持习惯。
- 不要把 $n,m$ 与 $q$ 的读入顺序弄反，也不要把询问的四个数当成 $(r_1,r_2,c_1,c_2)$ ——题面顺序是 $(r_1,c_1,r_2,c_2)$。
