# 两条对角线 题解

## 思路

题目要两个数：主对角线元素之和、副对角线元素之和。关键在于"对角线上第 $i$ 行的元素在哪一列"。

方阵的行、列都从 $1$ 编号：

- 主对角线：第 $i$ 行的元素在第 $i$ 列，即 $a_{i,i}$。
- 副对角线：第 $i$ 行的元素在第 $n+1-i$ 列。因为该行的列号要满足「行号 $+$ 列号 $= n+1$」，也就是 $j = n+1-i$。

于是在读入第 $i$ 行的第 $j$ 个整数时，只要判断：

- 若 $j=i$，把它加进主对角线和 `mainSum`；
- 若 $j=n+1-i$，把它加进副对角线和 `antiSum`。

两个判断必须是**两个独立的 `if`**，不能写成 `if … else if …`，也不能在答案里减去中心元素。原因：当 $n$ 为奇数时，正中心的位置 $i=j=(n+1)/2$ 同时满足两个条件，它本来就应当被两个和**各加一次**；用 `else if` 会让它只进入分支之一，副对角线和就少了一个中心元素。

因此不需要存整个矩阵，边读边算即可，空间是常数级。

## 算法

1. 读入 $n$。
2. `mainSum = antiSum = 0`。
3. 对 $i=1$ 到 $n$，对 $j=1$ 到 $n$：读入整数 $x$；若 $j=i$ 则 `mainSum += x`；若 $j=n+1-i$ 则 `antiSum += x`。
4. 输出 `mainSum`，换行，再输出 `antiSum`，换行。

## 正确性证明

记 $S_1=\sum_{i=1}^{n}a_{i,i}$，$S_2=\sum_{i=1}^{n}a_{i,n+1-i}$。题面以这两个求和式直接定义答案，所以正确答案唯一，就是 $(S_1,S_2)$。

**引理 1**：处理完前 $k$ 行后，`mainSum` $=\sum_{i=1}^{k}a_{i,i}$。
对 $k$ 归纳。$k=0$ 时为空和 $0$，成立。设处理完前 $k-1$ 行时成立。处理第 $k$ 行时，$j$ 从 $1$ 到 $n$ 各取一次，其中只有 $j=k$ 满足 $j=i$（此处 $i=k$），故本行恰好把 $a_{k,k}$ 加进一次，其余元素不加。归纳成立。取 $k=n$ 得 `mainSum` $=S_1$。

**引理 2**：处理完前 $k$ 行后，`antiSum` $=\sum_{i=1}^{k}a_{i,n+1-i}$。
同样归纳。第 $k$ 行中条件 $j=n+1-i$ 即 $j=n+1-k$；因为 $1\le k\le n$，有 $1\le n+1-k\le n$，该列在行内存在且唯一，于是本行恰好把 $a_{k,n+1-k}$ 加进一次。取 $k=n$ 得 `antiSum` $=S_2$。

**引理 3（中心元素各计一次）**：若 $n$ 为奇数，令 $m=(n+1)/2$。在第 $m$ 行上 $i=m$，此时 $n+1-i = n+1-m = m$，故 $j=m$ 同时满足 $j=i$ 与 $j=n+1-i$。由于两个 `if` 彼此独立，该元素被 `mainSum` 与 `antiSum` 各加一次，没有去重也没有漏算。若 $n$ 为偶数，$i=n+1-i$ 无整数解，两条对角线无公共元素，独立 `if` 也不会重复计数。

**定理**：算法输出的第一个数是 `mainSum` 的终值，由引理 1 等于 $S_1$；第二个数由引理 2 等于 $S_2$；输出顺序与题面一致，恰好两个整数。而 $(S_1,S_2)$ 是唯一正确答案，故算法对每个合法输入都输出正确答案。

## 复杂度

- 时间复杂度：$O(n^2)$，恰好读入 $n^2$ 个整数并做 $O(1)$ 次判断。$n\le 200$ 时是 $4\times 10^4$ 次操作，相对 1000ms 余量极大。
- 额外空间复杂度：$O(1)$（只用一个整数变量与两个累加器，不存矩阵）。若先存矩阵再遍历，也需要 $O(n^2)$ 空间，同样远低于 256MiB。

## 边界情况

- $n=1$：唯一元素既是主对角线元素又是副对角线元素，两个答案相等（样例 3）。
- $n$ 为奇数：中心元素必须被两条对角线各算一次，这是本题唯一的语义陷阱。
- $n$ 为偶数：两条对角线无公共元素，与奇数情形共用同一份代码即可。
- 全为负数：答案都是负数，不能取绝对值、不能初始化成 `-1` 之类。
- 全为零：两个答案都是 $0$，输出 `0` 与 `0` 两行。
- $n=200$、元素全为 $10^9$：答案 $2\times 10^{14}$，超出 32 位 `int` 上界，必须用 64 位整数。

## 常见错误

按"思路 / 复杂度 / 实现"三层枚举本题特有的错误：

| 层次 | 错误 | 表现 | 击杀数据 |
|---|---|---|---|
| 思路 | 把输出顺序写成先副后主 | 两个数交换 | `directed-swap-*`（主和对角线全正、副全负，数值可直接区分）、`diag-only-*`、`anti-only-*` |
| 思路 | 认为中心"共享所以只算一次"，从两个和里各减去中心 | 奇数阶时两行都偏小 | `odd-center-*`、`directed-dedup-*`（中心取 $10^9$ 极值） |
| 思路 | 只算主对角线，漏掉第二行输出 | 只输出一个数 | 全部测试点（checker 要求恰好两个整数） |
| 复杂度 | 无渐进错误空间 | 任何正确读入 $n^2$ 个元素的实现都是 $O(n^2)$，$n\le200$ 时仅 $4\times10^4$ 次操作，不存在能骗过 1000ms 的错法；该层不适用，不硬凑错解 | —— |
| 实现 | 两个判断写成 `if / else if` | 奇数阶时副对角线和漏掉中心 | `odd-center-*`、`directed-dedup-*` |
| 实现 | 副对角线列号写成 `n - i`（1 基，少加 1） | 副对角线整体错位一列 | `directed-off-by-one-*`、`anti-only-*`、全部随机点 |
| 实现 | 副对角线误写成"右上到左上的单点/单列"（如 $j-i=n-1$） | 只累加到极少元素 | `anti-only-*`、`random-*` |
| 实现 | 用 32 位 `int` 求和 | 满规模时溢出，答案错误 | `directed-overflow-*`、`max-*`（$200\times10^9=2\times10^{14}$） |

以上 7 个错解都在静态数据上被 checker 判 WA 稳定击杀，不依赖意外 RE 或 TLE：其中 `wrong-off-by-one` 与 `wrong-int-sum` 的下标/读入始终合法，失败原因确实是答案错误。

## 参考实现（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    long long mainSum = 0, antiSum = 0;
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= n; ++j) {
            long long x;
            cin >> x;
            if (j == i) mainSum += x;
            if (j == n + 1 - i) antiSum += x;
        }
    }
    cout << mainSum << '\n' << antiSum << '\n';
    return 0;
}
```
