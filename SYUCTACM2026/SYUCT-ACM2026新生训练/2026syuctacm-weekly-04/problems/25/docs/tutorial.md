# 最短循环节题解

## 思路

按定义直接枚举。设 $|s|=n$。如果 $s$ 能由长度为 $L$ 的串 $t$ 整次重复得到，那么首先必须满足 $L\mid n$（否则重复若干次后长度凑不齐 $n$）；其次每个位置都必须有 $s[i]=t[i\bmod L]$，而 $t$ 就是 $s$ 的前 $L$ 个字符，所以只需检查 $s[i]=s[i\bmod L]$ 是否对所有位置成立。

于是从小到大枚举 $L=1,2,\ldots,n$：跳过不能整除 $n$ 的 $L$，对能整除的 $L$ 做一次 $O(n)$ 逐字符验证，第一个通过验证的 $L$ 就是答案，循环单元为 $s$ 的前 $L$ 个字符。

独立的参考解走了另一条路：先只枚举 $n$ 的约数（约数必为整次重复的候选长度），再升序验证，验证时用 $s[i]$ 与 $s[i-L]$ 反向比较，实现结构完全不同。

## 正确性证明

**引理 1**：若长度为 $L$ 的串 $t$ 是 $s$ 的循环单元，则 $L\mid n$ 且 $t=s[0..L-1]$，且验证条件 $s[i]=s[i\bmod L]\ (\forall i)$ 成立。

证明：由定义 $s=t^k$ 是 $t$ 的 $k$ 次拼接，故 $n=kL$，即 $L\mid n$；同时 $t$ 是 $s$ 的前缀，$t=s[0..L-1]$。第 $i$ 位属于第 $\lfloor i/L\rfloor$ 个 $t$ 的第 $i\bmod L$ 位，所以 $s[i]=t[i\bmod L]=s[i\bmod L]$。∎

**引理 2**：若 $L\mid n$ 且 $s[i]=s[i\bmod L]$ 对所有 $i$ 成立，则 $s[0..L-1]$ 是 $s$ 的一个循环单元。

证明：把 $s$ 按每 $L$ 个字符分段，第 $j$ 段为 $s[jL..jL+L-1]$。由条件，段内第 $r$ 个字符 $s[jL+r]=s[(jL+r)\bmod L]=s[r]$，与第一段第 $r$ 个字符相同。故每段都等于 $s[0..L-1]$，$s$ 是它的整次重复。∎

**引理 3**：长度相同的最短循环单元至多一个。

证明：长度为 $L$ 的循环单元必为前缀 $s[0..L-1]$（引理 1），而前缀唯一。∎

**定理**：算法从小到大第一个通过验证的 $L$ 等于最短循环单元的长度，且输出的 $s[0..L-1]$ 就是最短循环单元。

证明：由引理 1，任何可行循环单元长度必被算法检查且能通过验证，故答案长度 $L^*$ 满足：算法在遇到 $L^*$ 时验证通过；又由引理 2，算法验证通过的长度都是可行循环单元长度，所以任何小于 $L^*$ 的长度都不通过。算法恰在 $L^*$ 处首次通过并输出 $s[0..L-1]$，由引理 1 它就是最短循环单元，由引理 3 它唯一。∎

## 复杂度

- 时间复杂度：$O(n^2)$。最坏情况（如答案为 $n$ 的串）约 $n$ 个候选长度、每个 $O(n)$ 验证；$n\le 3000$ 时约 $9\times 10^6$ 次基本字符比较，远在限制内。
- 空间复杂度：$O(n)$（保存输入与答案串）。
- 参考解（只枚举约数）为 $O(n\,d(n))$，其中 $d(n)$ 为约数个数，$n\le 3000$ 时 $d(n)\le 32$。

## 边界情况

- $n=1$：答案为 $1$。
- 全部字符相同（如 `aaaa`）：答案为 $1$。
- 完全无重复（如 `abcab`）：答案为 $n$，需要验证所有更小的长度都不成立。
- 重复次数 $k\ge 4$ 的串（如 `abcabcabcabc`）：答案远小于 $n/2$，能击穿"折半"类错解。
- 末尾多出不完整周期的串（如 `ababa`、`abcabcab`）：答案是 $n$ 而不是平移周期 $2$ 或 $3$，能击穿"允许残缺"类错解。

## 常见错误（三层枚举）

**思路层**

- 把循环单元当成平移周期：只查 $s[i]=s[i+L]$（允许末尾残缺），`ababa` 会错答 $2$。对应错解 `wrong-shift.cpp`，由 `anti-tail-*`、`near-max-tail-1` 定向击杀。
- 用最长前后缀反推：认为答案是 $n$ 减最长 border，`abcab` 会错答 $3$。对应错解 `wrong-border.cpp`，由 `anti-border-*` 定向击杀（它们有很长 border 但答案是 $n$）。
- 只检查能否对折：`abcabcabcabc` 对折相等但答案是 $3$ 而非 $6$。对应错解 `wrong-half.cpp`，由 `anti-half-*` 定向击杀。

**复杂度层**

- 在 $n\le 3000$ 的约束下，所有 $O(n^2)$ 实现（含大常数写法）都能通过，TLE 型错解没有区分度，故不提供，以说明代替。
- 若未来把上限调大（如 $10^5$ 以上），"枚举每个 $L$ 再 $O(n)$ 验证"会变成 $O(n^2)$ 而超时，届时只枚举约数的写法才稳。

**实现层**

- 验证循环时上界多写一格（`i <= n`），读到 `s[n]` 的 `'\0'`，导致所有真正循环的串都失败。对应错解 `wrong-offbyone.cpp`，由任何 `repeated-*`、`all-same-*`、`anti-half-*` 击杀。
- 忘记检查 $L\mid n$：与思路层的平移周期错误同根，同样会被 `anti-tail-*` 击杀。
- 输出格式错误（多行、漏长度、多余文字）：checker 会按 token 严格判 WA；样例与说明已强调输出唯一、不要多余内容。
