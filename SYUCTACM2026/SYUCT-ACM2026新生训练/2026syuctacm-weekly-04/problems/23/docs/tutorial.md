# 回文修补题解

## 思路

使用从 $0$ 开始的下标。字符串成为回文串，等价于每个位置 $i$ 都与位置 $n-1-i$ 上的字符相同。

只需依次检查 $0\le i<\lfloor n/2\rfloor$ 的对称位置对 $(i,n-1-i)$：

- 两个字符相同，这一对不需要修改；
- 两个字符不同，答案加 $1$。

奇数长度字符串的正中间位置与自身对称，不需要检查。主解用左右双指针实现，独立参考解用半区间下标循环实现。

## 正确性证明

设字符不同的对称位置对共有 $k$ 对。证明最少操作次数恰好为 $k$。

### 下界

考虑任意一对原本字符不同的对称位置。如果这两个位置都没有被修改，它们仍然不同，字符串就不是回文串。因此，每一对这样的位置都至少要修改一个位置。

不同的对称位置对互不重叠，而一次操作只能修改一个位置，所以一次操作不可能同时处理两对不同的对称位置。任何可行方案都至少需要 $k$ 次操作。

### 构造

对每个字符不同的对称位置对 $(i,n-1-i)$，执行一次操作，把 $s_{n-1-i}$ 改成 $s_i$。每一对都只需这一次修改，且修改不会影响其他位置对。

对全部 $k$ 对执行上述操作后，所有对称位置上的字符都相同，得到了一个回文串。因此 $k$ 次操作一定足够。

下界为 $k$，又存在恰好使用 $k$ 次操作的构造，所以最少操作次数就是 $k$。算法统计的正是 $k$，故算法正确。

### 奇数长度的中心

当 $n$ 为奇数时，中心位置 $n/2$ 与自身对称，天然满足相等条件，也不需要借助其他位置的修改。因此它对答案没有贡献，循环到 $i<n/2$ 即可。

## 复杂度

每个对称位置对只比较一次：

- 时间复杂度：$O(n)$；
- 额外空间复杂度：$O(1)$，不计存储输入字符串所需的空间。

## 边界情况

- $n=1$ 时答案为 $0$；
- $n=2$ 时只有一对位置，答案为 $0$ 或 $1$；
- 原串已经是回文串时答案为 $0$；
- 所有对称位置对都不同，答案取到最大值 $\lfloor n/2\rfloor$；
- 奇数与偶数长度的循环边界不同，但都可以统一写成 `left < right` 或 `i < n / 2`；
- 答案不超过 $100000$，使用 `int` 足够。

## 常见错误与定向数据

按三层枚举本题的典型错误：

1. **思路层：重复计算。** 从两端各扫描一次、把每对统计两遍，会把所有非零答案翻倍，`wrong-a.cpp` 实现此错误；认为一对不同字符必须分别修改两次也属于同类错误。`sample-1` 与 `min-even-diff-1` 可稳定击杀。
2. **复杂度层：本题不设。** 曾考虑把"每修复一对就重新扫描整串判断是否回文"（`src/wrong/wrong-d.cpp`）当作超时错解，但实测表明它**结果是正确的**：修复顺序是从外向内，`isPalindrome` 只有在所有失配对都修完时才会返回真，因此那个 `break` 永远不会提前触发。它的最坏复杂度为 $O(n^2)$，在 $n=2\times10^5$ 的上限用例上实测约 $1.29\,\mathrm{s}$，仍然低于本地验题器的超时阈值（$3\times$ 时限 $=3000\,\mathrm{ms}$），所以它无法被稳定击杀。按"不硬凑会通过的错解"的原则，该实现已从 `config.json` 的 `wrongSolutions` 中移除，只作为记录保留在源码目录里。本题正确解法必须是 $\Theta(n)$（至少要读完整个字符串），不存在其它有意义的渐进错误，因此复杂度层不适用。
3. **实现层：中心与下标边界。** 把奇数长度的中心无条件计入答案对应 `wrong-b.cpp`，`min-odd-1` 和 `center-only-1` 可击杀；从下标 $1$ 开始扫描而漏掉最外层对应 `wrong-c.cpp`，`min-even-diff-1` 和 `outer-only-1` 可击杀。

静态数据还覆盖最小长度、短奇偶回文、一对与两对失配、全相同、交替、周期串、两段字符、半失配、随机小数据、随机中数据、近上限随机、上限回文、上限单对失配和上限最大答案。
