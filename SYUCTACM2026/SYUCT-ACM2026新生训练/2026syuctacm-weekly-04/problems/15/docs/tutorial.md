# 最大值的位置题解

## 思路

题目要输出三样东西：最大值、它第一次出现的行号、它第一次出现的列号（行列都从 $1$ 开始）。

最直接的做法是一次扫描：按行优先顺序（先第 $1$ 行，再第 $2$ 行，……，每行内从左到右）依次读入每个格子，边读边维护

- `best`：目前见过的最大值；
- `bi`、`bj`：在已扫描的格子中，取到 `best` 且行优先顺序最靠前的位置。

对当前格子 $(i,j)$ 的值 $x$，只有 $x$ **严格大于** `best` 时才更新三者。这样做的关键理由：

- 扫描顺序本身就是行优先顺序，所以"第一次遇到最大值"＝"行优先顺序最靠前的最大值"。
- 当 $x$ 等于 `best` 时，最大值此前已经出现过，当前格子在行优先顺序里更靠后，绝对不是第一次出现，因此**不能**更新。
- 若把判定写成 `x >= best`，最终保留下来的是最后一次出现的位置，正好与题目要求相反。

初始值的选取有两条路，都正确：

1. 把第一个格子（第 $1$ 行第 $1$ 列）的值作为 `best` 初值，位置记为 $(1,1)$，然后从第 $1$ 个格子开始扫描（重复比较一次无副作用）；也可以从第二个格子开始扫。
2. 把 `best` 初始化为一个比所有可能取值都小的数（例如 `LLONG_MIN`），位置记为 $(1,1)$。因为每个元素都满足 $-10^9\le a_{i,j}$，第一个格子必然触发更新，位置会被正确改写。

**不能**把 `best` 初始化为 $0$：本题元素可以是负数，若整个矩阵都是负数，`best` 会永远停在 $0$，输出一个矩阵里根本不存在的最值。

## 算法

```
读入 n, m
读入第 1 行第 1 列的值 v，best = v, bi = 1, bj = 1
for i = 1..n:
    for j = 1..m:
        if (i == 1 and j == 1) continue
        读入 a[i][j]
        if a[i][j] > best:
            best = a[i][j], bi = i, bj = j
输出 best, bi, bj
```

或者干脆先把整个矩阵读进二维数组，再用上面的双重循环扫描一遍，效果相同。本题最多 $200\times 200=40000$ 个元素，存下来只有约 $160$ KB，怎么存都很宽松。

需要注意输出的是 $1$ 起始的行列号。如果代码内部用 $0$ 起始的下标记录位置，输出时要各加 $1$。

## 正确性证明

把矩阵按行优先顺序展开成序列 $p_1,p_2,\dots,p_{nm}$，其中 $p_{(i-1)m+j}$ 就是格子 $(i,j)$，记它的值为 $v_{(i-1)m+j}$。算法依次处理这个序列。设处理完前 $t$ 个格子后的状态为 $(\text{best}_t,\text{pos}_t)$。

**不变量**：对每个 $1\le t\le nm$，

1. $\text{best}_t=\max\{v_1,\dots,v_t\}$；
2. $\text{pos}_t$ 是集合 $S_t=\{p_k\mid 1\le k\le t,\ v_k=\text{best}_t\}$ 中行优先顺序最靠前的位置。

*基础情形 $t=1$*：第一个格子被直接作为初值，$\text{best}_1=v_1$，$\text{pos}_1=p_1$。而 $S_1=\{p_1\}$，其唯一元素就是最靠前的位置，成立。

*归纳步*：设处理完前 $t$ 个格子时不变量成立，考察第 $t+1$ 个格子，值为 $x$。

- 若 $x>\text{best}_t$：由归纳假设 $\text{best}_t$ 是前 $t$ 个元素的最大值，所以 $x$ 严格大于它们全部，于是 $\text{best}_{t+1}=x$ 就是前 $t+1$ 个元素的最大值。又因为前面没有任何元素等于 $x$（它们都小于 $x$），所以 $S_{t+1}=\{p_{t+1}\}$，其最靠前的位置就是 $p_{t+1}$，与算法的赋值一致。
- 若 $x\le\text{best}_t$：前 $t+1$ 个元素的最大值仍是 $\text{best}_t$，数值不变。此时 $S_{t+1}$ 等于 $S_t$（当 $x<\text{best}_t$）或 $S_t\cup\{p_{t+1}\}$（当 $x=\text{best}_t$）。无论哪种情况，新加入的 $p_{t+1}$ 都是序列中最后一个位置，在行优先顺序里严格排在 $S_t$ 的所有元素之后，因此最靠前的元素仍然是 $\text{pos}_t$，算法保持不动是正确的。

两种情况都与算法行为一致，故不变量对 $t+1$ 成立。由归纳法，不变量对所有 $t$ 成立。

*结论*：处理完全部 $nm$ 个格子后，$\text{best}=\max\{v_1,\dots,v_{nm}\}$ 就是整个矩阵的最大值，$\text{pos}$ 是所有达到该最大值的格子中行优先顺序最靠前的那一个，即题目所说的"第一次出现"的位置。输出的三元组（最大值，行号，列号）与题目要求完全一致。

*唯一性*：行优先顺序是有限位置集合上的全序（任意两个不同位置都可以比较，且"更靠前"关系满足反对称与传递），所以非空的"达到最大值的格子集合"一定存在唯一的最小元，答案唯一确定，不存在多解。

## 复杂度

- 时间复杂度：$O(nm)$。每个格子只被读入一次、比较一次，最多触发一次常数次赋值。$nm\le 40000$，远低于 1000 ms 的时限，常数再大也很宽松。
- 空间复杂度：边读边扫的写法是 $O(1)$（只有几个标量）；把矩阵存下来的写法是 $O(nm)$，最多 $40000$ 个整数，约 $160$ KB，相对于 256 MiB 可以忽略。

## 边界与常见错误

- **重复最大值**：必须用严格大于 `>`。用 `>=` 会输出最后一次出现的位置，样例 1 就会从 `7 1 2` 变成 `7 3 3`。
- **全负矩阵**：`best` 不能初始化为 $0$，否则答案会变成一个矩阵里不存在的 $0$。用第一个元素作初值，或用 `LLONG_MIN`。
- **$1\times 1$ 矩阵**：只有一格，答案是"该值 $1$ $1$"。若从"第二个格子"开始扫描的写法没有特殊处理，可能输出未初始化的位置。
- **单行 / 单列**：行号或列号被固定为 $1$，退化成一维的"第一个最大值"。
- **最大值在最后一行或最后一列**：循环边界写成 `i < n`、`j < m`（漏掉最后一行/列）时，若唯一最大值恰好在 $(n,m)$ 就会输出错误的位置或错误的值。
- **最大值在 $(1,1)$**：扫描中不会有任何严格大于，位置应保持 $(1,1)$。
- **行列颠倒**：把位置输出成"列号 行号"顺序，在行列不相等的坐标上立刻出错。
- **0/1 起始混淆**：内部下标从 $0$ 开始却直接输出，会整体少 $1$。
- **多输出内容**：本题评测按 token 严格比较，必须恰好输出三个整数；打印"最大值是"之类的提示文字会被判错。

## 参考实现（C++17）
主解先把矩阵读入从 $1$ 开始的二维数组，再用第一个元素初始化 `best` 与位置，然后按行优先顺序扫描、严格大于才更新：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<vector<long long>> a(n + 1, vector<long long>(m + 1, 0));
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j) {
            cin >> a[i][j];
        }
    }

    long long best = a[1][1];
    int bestRow = 1;
    int bestCol = 1;
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j) {
            if (a[i][j] > best) {
                best = a[i][j];
                bestRow = i;
                bestCol = j;
            }
        }
    }

    cout << best << ' ' << bestRow << ' ' << bestCol << '\n';
    return 0;
}
```

独立的参考解 `src/solution2.cpp` 采用不同的写法：不存矩阵、边读边扫，`best` 初始化为 `LLONG_MIN`，I/O 使用 `scanf`/`printf`。它与主解在初始化和存储策略上都不同，但由上面的不变量可知两者等价。
