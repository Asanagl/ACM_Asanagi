# 边框元素之和题解

## 思路

记边框格子集合

$$
B=\{(i,j)\mid 1\le i\le n,\ 1\le j\le m,\ i=1\ \text{或}\ i=n\ \text{或}\ j=1\ \text{或}\ j=m\}\text{。}
$$

本题的答案就是 $\sum_{(i,j)\in B}a_{i,j}$。核心是**每个边框格子恰好被加一次**：角落格子同时满足两个甚至四个条件，但只能贡献一次。

有两种自然的写法。

**写法一（逐格判定，参考解 `solution2.cpp`）**：边读入边判定。对每个格子，计算

```
i == 1 || i == n || j == 1 || j == m
```

这个布尔条件与 $B$ 的定义逐字相同。条件为真就累加，为假就跳过。四个条件用 `||` 连成一个整体，只在通过它之后执行**一次**加法，因此角落天然不会被重复累加，也不需要为 $n=1$、$m=1$ 单独写分支。

**写法二（分区累加，主解 `solution.cpp`）**：把 $B$ 拆成三块互不相交的部分，每块直接加对应元素：

1. 第一行的全部 $m$ 个元素；
2. 当 $n>1$ 时，第 $n$ 行的全部 $m$ 个元素；
3. 对每个中间行 $2\le i\le n-1$，加它的左端点 $a_{i,1}$，并在 $m>1$ 时再加它的右端点 $a_{i,m}$。

第 2、3 步的两个 `if` 正是为了避免 $n=1$ 时第一行被加两次、$m=1$ 时唯一一列被加两次。

答案用 `long long` 保存：当 $n,m\ge2$ 时边框恰有 $2n+2m-4\le1996$ 个格子，当 $n=1$ 或 $m=1$ 时边框格子数为 $nm\le500$，两种情况都不超过 $1996$。因此答案绝对值不超过 $1996\times10^7=1.996\times10^{10}$，超出 32 位有符号整数范围。

## 正确性证明

**引理 1（枚举不重不漏）**：两层循环恰好把 $n\cdot m$ 个位置各访问一次。外层 `i` 取遍 $1..n$，内层 `j` 取遍 $1..m$，每次迭代由一组不同的 $(i,j)$ 唯一确定，总迭代次数为 $n\cdot m$。

**引理 2（判定与定义等价）**：对任意合法位置 $(i,j)$，布尔式 `i == 1 || i == n || j == 1 || j == m` 为真当且仅当 $(i,j)\in B$。这直接来自 $B$ 的定义。

**定理（参考解恰好求和一次）**：由引理 1，每个位置被处理一次；由引理 2，恰好边框格子通过判定；每次通过判定只执行一次 `sum += a[i][j]`。角落格子即使使多个析取项为真，仍然只通过一次判定、只加一次。非边框格子使四个析取项全假，从不进入加法。因此输出恰为 $\sum_{(i,j)\in B}a_{i,j}$。

**定理（主解的三块恰好覆盖 $B$）**：下面证明主解各部分两两不交且并集为 $B$。

- 第一部分覆盖 $\{(1,j)\}$，即 $i=1$ 的边框格子，每个一次。
- 第二部分仅在 $n>1$ 时执行，覆盖 $\{(n,j)\}$。因 $n>1$，行 $n$ 与行 $1$ 不同，与第一部分不交。若 $n=1$，行 $n$ 就是行 $1$，已被第一部分覆盖，此时跳过正是为了不重复。
- 第三部分覆盖 $\{(i,1)\mid 2\le i\le n-1\}$ 与 $\{(i,m)\mid 2\le i\le n-1\}$。这些位置的行号严格介于 $1$ 与 $n$ 之间，故与第一、二部分不交；当 $m>1$ 时左端点与右端点列号不同，互不重合，当 $m=1$ 时二者是同一格，`if (m > 1)` 保证只加一次。
- 并集：第一、二部分给出所有 $i=1$ 与 $i=n$ 的位置，第三部分给出所有 $2\le i\le n-1$ 且 $j\in\{1,m\}$ 的位置，正好是 $B$；而任何 $2\le i\le n-1$、$2\le j\le m-1$ 的内部位置都不被任何部分访问。

所以主解各项之和等于 $\sum_{(i,j)\in B}a_{i,j}$，且没有位置被加两次。

**定理（无溢出）**：$|B|\le1996$（$n,m\ge2$ 时为 $2n+2m-4$，否则为 $nm\le500$），故部分和与最终答案的绝对值都不超过 $1996\times10^7<2^{63}-1$，`long long` 的每次加法都精确。

## 复杂度

- 时间复杂度：两种写法都是 $O(nm)$，必须读完全部 $nm$ 个元素，这已是输入规模下的下界。$n=m=500$ 时共 $250000$ 次读入。
- 额外空间复杂度：参考解边读边算，为 $O(1)$；主解存下整个矩阵，为 $O(nm)$，在 256 MiB 下约 $1$ MB 量级。

## 边界情况

- $1\times1$：唯一格子满足全部四个条件，四个角落规则叠加，仍然只加一次。样例 2 就是这个情况（$-7$）。
- 只有一行（$n=1$）：每个格子都满足 $i=1$，答案是整行之和。特别注意第一行与最后一行是同一行，不能加两遍。
- 只有一列（$m=1$）：同理，答案是整列之和；左右端点重合。
- 恰好两行或两列（$n=2$ 或 $m=2$）：所有格子都在边框上，中间部分为空，答案是全矩阵之和。
- 负数与全负矩阵：直接做有符号加法，不要取绝对值、不要用无符号类型、不要把答案初值设成 $-1$ 或"无穷大"。
- 答案为 $0$：边框正负抵消时仍必须输出 `0`，不能把它当成"没有答案"而少输出。
- 元素取到 $\pm10^7$ 且 $n=m=500$：边框 $1996$ 格，答案可达 $\pm1.996\times10^{10}$，必须用 64 位整数。

## 常见错误与定向数据

### 思路层

- **整矩阵求和**（`wrong-whole.cpp`）：把内部格子也算进去了。`hollow-1` 的边框全为 $0$、内部非零，正确输出 `0`，该错解输出 `368`；`zero-sum-1` 同样构造了边框和为 $0$、全矩阵和为 $900$ 的例子。
- **四条边各自完整累加**（`wrong-corners-twice.cpp`）：把第 1 行、第 $n$ 行、第 1 列、第 $m$ 列分别整段相加，角落被加两次，单行/单列时整行整列都被加两次。`min-1` 的唯一元素为 $7$，该错解输出 $28$。
- **只累加第一行和最后一行**（`wrong-rows-only.cpp`）：漏掉中间行的左右端点。公开样例 1 即可击杀。

### 复杂度层

本题不存在有教学价值的渐近复杂度错解：任何正确算法都必须读入 $nm$ 个数，$O(nm)$ 已是输入下界，存不存矩阵只影响常数与空间。因此没有为了凑数而加入重复扫描或死循环的伪错解，近上限数据（`near-max`、`big-random-*`、`int-edge`，均为 $500\times500$）用来确认实际运行余量。

### 实现层

- **行边框、列边框用两个独立 `if`**（`wrong-degenerate-double.cpp`）：角落以及单行、单列中的格子会被加两次。`sample-2`、`min-*`、单行、单列数据都能击杀。
- **单行/单列时直接输出 $0$**（`wrong-single-zero.cpp`）：由 `sample-2`、`min-neg`、`one-row-*`、`one-col-*` 击杀。
- **从 $0$ 开始的下标套用从 $1$ 开始的边界**（`wrong-offbyone.cpp`）：判定写成 `i == 1 || i == n || j == 1 || j == m`，于是真正的第 $0$ 行、第 $0$ 列被漏掉，第 $1$ 行、第 $1$ 列被误算。全部 34 个数据都能击杀它。
- **用 32 位 `int` 存答案**（`wrong-int.cpp`）：`big-positive` 的边框和为 $19960000000$，`big-negative` 为 $-19960000000$，`int-edge` 同样超范围，三个数据都能稳定击杀。

全部 7 个错解都由 checker 判为 WA（退出码 2，输出数值不同），无一个依赖崩溃或运行时错误。
