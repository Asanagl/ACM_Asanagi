# 四邻格统计题解

## 思路

每个格子的答案只由它自己和四个正交邻居决定，与网格其它部分无关。因此不需要任何整体技巧：对每个格子，依次检查上、下、左、右四个方向，如果该方向存在邻居（不越界）且邻居字符是 `1`，就计入一次，最后输出这个计数。

关键在于**两个判断必须同时成立**：

1. 该方向的下标仍在网格内（`0 <= ni < n` 且 `0 <= nj < m`）；
2. 该方向邻居的字符等于 `'1'`。

漏掉第一项会越界访问或回绕；漏掉第二项会变成"数邻居个数"。斜向从不出现，因为我们只使用偏移量 $(-1,0),(1,0),(0,-1),(0,1)$，它们的曼哈顿距离恒为 1。

## 算法

1. 读入 $n,m$，再读入 $n$ 个长度为 $m$ 的字符串（必须按字符串读，见"常见错误"）。
2. 对 $i=0..n-1$、$j=0..m-1$：
   - `cnt = 0`；
   - 若 $i>0$ 且 `g[i-1][j] == '1'`，`cnt` 加一；
   - 若 $i+1<n$ 且 `g[i+1][j] == '1'`，`cnt` 加一；
   - 若 $j>0$ 且 `g[i][j-1] == '1'`，`cnt` 加一；
   - 若 $j+1<m$ 且 `g[i][j+1] == '1'`，`cnt` 加一；
   - 输出 `cnt`，同行用空格分隔，行末换行。
3. 全部输出完毕即结束。

主解采用另一种结构：把网格向外补一圈 `0` 得到 $(n+2)\times(m+2)$ 的整型数组，再用 `a[i-1][j] + a[i+1][j] + a[i][j-1] + a[i][j+1]` 直接求和，完全不需要在求和处写四个边界判断。独立参考解 `solution2.cpp` 则按上面"逐方向 + 边界判断"书写。两种写法的边界处理位置不同，可以相互印证。

## 正确性证明

定义"扩充值" $a(x,y)$：当 $0\le x<n$ 且 $0\le y<m$ 时取原网格 $g[x][y]$（`'1'` 记为 1，`'0'` 记为 0），否则记为 0。令

$$
T(i,j)=a(i-1,j)+a(i+1,j)+a(i,j-1)+a(i,j+1).
$$

**引理 1：对任意格子 $(i,j)$，$T(i,j)$ 等于题目要求的答案。**

证明：逐方向考察这四项。若该方向的邻居落在网格内，$a$ 取的就是该邻居的真实值，而这个邻居确实存在，题面要求统计它是否为 `1`，贡献正确。若该方向越界，则 $a=0$，而题面规定越界方向"没有邻居、不参与统计"，贡献 0 同样正确。四个方向互不重复，并且恰好穷尽了上、下、左、右这四个正交邻居。整个表达式中只出现偏移 $(0,\pm1)$ 与 $(\pm1,0)$，从未出现 $(\pm1,\pm1)$，因此斜向格子恒被排除。$\square$

**引理 2：参考解逐方向累加出的 `cnt` 等于 $T(i,j)$，主解的补圈求和也等于 $T(i,j)$。**

证明：先看参考解，逐条对齐四个条件。程序仅在 $i>0$ 时累加 `g[i-1][j]`，恰对应"$i=0$ 时上邻居不存在、$a(-1,j)=0$"；`i+1<n` 对应 $i=n-1$ 时下邻居不存在；`j>0` 与 `j+1<m` 同理对应左右两个方向。字符比较 `=='1'` 与数值判 1 等价，因为数据范围保证每个字符只能是 `'0'` 或 `'1'`。四项累加即为 $T(i,j)$。再看主解，补上去的一圈 `0` 恰好在所有越界下标处给出 $a=0$，而原网格区域上取的就是原值，所以 `a[i-1][j] + a[i+1][j] + a[i][j-1] + a[i][j+1]` 逐项等于 $T(i,j)$。$\square$

**定理：程序输出正确。**

证明：外层循环 $i=0..n-1$、内层循环 $j=0..m-1$，每个格子被处理恰好一次且只输出一个整数，所以输出恰好 $n$ 行、每行恰好 $m$ 个整数，形状正确；由引理 2 与引理 1，该位置上的整数就是正确答案。$\square$

**边界情形无需单独论证。** 引理 1 中的"越界取 0"对所有下标一致成立。$n=1$ 时上下两个条件恒不成立；$m=1$ 时左右两个条件恒不成立；$n=m=1$ 时四项全不成立，答案必为 $0$；$n,m\ge2$ 时四角恰有两项成立、边界非角格恰有三项成立。程序不需要任何特判。

## 复杂度

- 时间复杂度：$\Theta(nm)$。每个格子做常数次判断，$nm\le 2.5\times10^{5}$。
- 空间复杂度：$\Theta(nm)$，用于存网格与输出缓冲；参考解的补圈数组为 $(n+2)(m+2)$，同阶。

在 $n,m\le 500$ 下远低于 $1000\,\mathrm{ms}$ 与 $256\,\mathrm{MiB}$ 的限制。

## 边界情况

- $n=m=1$：唯一格子没有邻居，答案恒为 $0$，无论它是 `0` 还是 `1`。
- 单行（$n=1$）或单列（$m=1$）：所有格子都缺少两个方向，端点只有 1 个邻居。
- $n=2$ 或 $m=2$：不存在"内部格"，所有格子都是边界格。
- 全 `0` 网格：答案全为 0；全 `1` 网格：内部 4、边界 3、四角 2。
- 斜向排列（两条对角线为 1）：正确输出全 0。
- 上限 $500\times500$：约 25 万个输出整数，需要注意输出效率。

## 常见错误与数据设计

按三个层次枚举：

- **思路层**
  - 把斜向也算成邻居（8 邻域，`wrong-diagonal.cpp`）：样例一第 3 行第 3 列因此会输出 3 而不是 1；`diag-1`、`kill-diagonal-1` 让 1 只分布在对角线上，正确输出全 0，八邻域实现会大面积偏大。
  - 把格子自身计入（`wrong-self.cpp`）：`kill-self-1`（$1\times1$，值为 `1`）中正确答案是 0，该实现输出 1；`all-one-1` 也会稳定偏差。
  - 统计"存在的邻居个数"而不是"值为 1 的邻居个数"（`wrong-count-neighbors.cpp`）：`kill-count-neighbors-1`、`all-zero-1` 上正确答案全为 0，该实现输出 2/3/4。
- **复杂度层**
  - 对每个格子扫描整个网格（`wrong-quadratic.cpp`，$O(n^2m^2)$）：在 $500\times500$ 上约 $6\times10^{10}$ 次操作，`max-1` 稳定超时。本题正确解法是 $O(nm)$ 的，不存在合法的亚线性做法，因此只保留这一个复杂度错解，`near-max-*`、`max-*` 共同保证它必然被卡住。
- **实现层**
  - 用取模回绕代替边界检查（`wrong-wrap.cpp`）：`kill-wrap-1`（单行、两端为 1）与所有含首末行列的用例会给出错误计数。
  - 漏掉下、右两个方向（`wrong-missing-down-right.cpp`）：`kill-boundary-1`（最后一行与最后一列全为 1）会稳定暴露。
  - 行列写反输出转置（`wrong-transpose.cpp`）：`single-row-*`、`single-col-*` 以及所有 $n\ne m$ 的用例形状不符，直接判错。

所有保留的错解都输出内容错误的结果（或超时），不依赖意外的运行时错误伪装成预期 WA。

## 实现注意事项

- 每行必须按字符串读入。用 `cin >> int` 会把 `0101` 读成十进制 101，并且随后的读入错位。
- 字符比较要写 `== '1'`，不能写 `== 1`。
- 边界条件的下界必须严格：`i > 0`、`j > 0`，不要写成恒真或遗漏。
- 输出用 `'\n'`，不要逐行 `endl`；25 万个数建议一次性拼接后写出。
- 本题只有一组测试数据，不要写 `while (cin >> n >> m)` 式的多组循环。
