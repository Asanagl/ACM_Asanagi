# 字符串的头和尾题解

## 思路

任务要求输出一个字符串的三个信息：长度、第一个字符、最后一个字符。

C++ 的 `std::string` 直接提供这三个量：

- 用 `cin >> s` 读入字符串（本题不含空白字符，因此读一个词即可）。
- `s.size()`（等价于 `s.length()`）返回字符串中字符的个数，即长度。
- 下标从 $0$ 开始：`s[0]` 是第一个字符。
- 最后一个字符的下标是「长度 $-1$」，即 `s[s.size() - 1]`。

按 `长度 首字符 尾字符` 的顺序、用单个空格分隔输出即可。

## 算法

1. 读入字符串 $s$。
2. 计算 `len = s.size()`。
3. 输出 `len`、`s[0]`、`s[len - 1]`，两两之间用一个空格分隔，行末换行。

独立的 C++ 参考解使用 `s.length()`、`s.front()`、`s.back()`，与主解的 `size()`、下标写法在实现层面相互独立。

## 正确性证明

**引理 1**：`s.size()` 返回值等于 $s$ 的长度。
这是 `std::string::size` 的标准语义，无需证明。

**引理 2**：`s[0]` 是 $s$ 的第一个字符，`s[s.size() - 1]$` 是 $s$ 的最后一个字符。
C++ 字符串下标从 $0$ 开始连续编号，故下标 $0$ 对应第一个字符；共有 `size()` 个字符，最后一个字符的下标为 `size() - 1`。题目保证 $s$ 非空，下标 `size() - 1` 合法。

**定理**：对任意合法输入，算法输出 `长度 首字符 尾字符` 的正确答案。
算法输出的三个量依次为 `s.size()`、`s[0]`、`s[s.size()-1]`；由引理 1 与引理 2，它们恰好就是题目所要求的长度、第一个字符、最后一个字符，且输出顺序与格式与题目规定一致。因此算法对每个合法输入都输出正确答案，而正确答案唯一。

## 复杂度

- 时间复杂度：$O(|s|)$（瓶颈在读入字符串；三个输出量都是 $O(1)$ 取得）。
- 额外空间复杂度：$O(1)$（不计存放输入字符串本身的 $O(|s|)$ 空间）。

## 边界情况

- $|s|=1$：第一个字符与最后一个字符是同一个字符，如样例 2。
- $|s|=2$：首尾不同，可区分"首字符复用"类错误。
- $|s|=1000$：规模上限，本题余量极大。
- 整串同一字符（如 `aaaa...`）：首尾相同，不能据此假定首尾一定不同。

## 常见错误与错解对照

按"思路 / 复杂度 / 实现"三层枚举本题特有的错误：

| 层次 | 错误 | 表现 | 击杀数据 |
|---|---|---|---|
| 思路 | 把首、尾字符顺序颠倒 | 输出 `长度 尾 首` | `two-1`、`directed-*`、绝大多数随机点（首尾不同即 WA） |
| 思路 | 漏读输出要求，只输出长度 | 只输出一个数 | 全部测试点（checker 要求恰好三个 token） |
| 复杂度 | —— | 本题任何合理实现均为 $O(\|s\|)$，不存在能骗过 1000ms 时限的渐进错误实现，该层不适用（特此说明，不硬凑错解） | —— |
| 实现 | 把末下标当长度，输出 `size() - 1` | 长度永远少 1 | 全部测试点 |
| 实现 | 用 `char` 接收字符串 | 长度恒为 1 | 任意长度 $\ge 2$ 的测试点 |
| 实现 | 首尾都取 `s[0]` | 尾字符恒为首字符 | `two-1`、`directed-*`、绝大多数随机点 |

以上 5 个错解均在静态数据上被稳定击杀（由 checker 判 WA，而非依赖意外 RE）。

## 参考实现（C++17）

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    string s;
    cin >> s;
    const size_t len = s.size();
    cout << len << ' ' << s[0] << ' ' << s[len - 1] << '\n';
    return 0;
}
```
