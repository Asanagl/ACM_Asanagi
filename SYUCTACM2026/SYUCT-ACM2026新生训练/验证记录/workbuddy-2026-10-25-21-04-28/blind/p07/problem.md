# 回文判断

如果一个字符串从左到右读和从右到左读完全相同，就称它是**回文串**。例如 `abba`、`ababa`、`a` 都是回文串，而 `abcab`、`abxbba` 都不是回文串。

给定一个只由小写英文字母组成的字符串 $s$，请判断它是不是回文串。

## 输入格式

输入一行一个字符串 $s$（$1\le |s|\le 100000$），其中 $|s|$ 表示字符串中字符的个数。

$s$ 只由小写英文字母 `a` 到 `z` 组成，不含空格、制表符或其他空白字符。**$s$ 不允许是空串**，即一定有 $|s|\ge 1$；输入中只有这一行字符串，不含多组测试数据。

## 输出格式

输出一行：如果 $s$ 是回文串，输出 `YES`；否则输出 `NO`。

答案唯一。评测程序读取输出中第一个空白分隔的单词，这个单词必须恰好是全大写的 `YES` 或 `NO`，并且与唯一正确答案相同；该单词之后不得再出现其他非空白内容。也就是说，只能输出一个单词 `YES` 或 `NO`（建议在它后面再输出一个换行符），不要输出小写形式、其他单词、数字或任何解释性文字。行末的空白不影响判定。

## 数据范围

- $1\le |s|\le 100000$；空串不会出现在输入中。
- $s$ 的每个字符都是小写英文字母 `a` 到 `z`。
- 输入恰好包含这一行字符串，没有前导或尾随的多余内容。

## 样例 1

~~~input1
a
~~~

~~~output1
YES
~~~

长度为 $1$ 的字符串只有一个字符，它和自己的反转完全相同，因此是回文串。这也是 $|s|$ 的最小取值。

## 样例 2

~~~input2
ababa
~~~

~~~output2
YES
~~~

长度为奇数 $5$。首字符 `a` 与尾字符 `a` 相同，第二对 `b` 与 `b` 相同，正中间的 `a` 没有配对对象，不需要比较。

## 样例 3

~~~input3
abba
~~~

~~~output3
YES
~~~

长度为偶数 $4$。所有字符恰好两两配对：`a` 与 `a` 配对、`b` 与 `b` 配对，每一对都相同。

## 样例 4

~~~input4
abcab
~~~

~~~output4
NO
~~~

首字符是 `a`，尾字符是 `b`，第一对就不相同，所以不是回文串。

## 样例 5

~~~input5
abxbba
~~~

~~~output5
NO
~~~

这一行是**强样例**。最外层的两对 `a` 与 `a`、`b` 与 `b` 都相同，只有最里面的一对 `x` 与 `b` 不同。必须把每一对都检查完才能得出结论，不能只比较开头几对或只比较最外层一对。

## 提示

令左下标 `l` 指向字符串开头、右下标 `r` 指向字符串结尾。比较 `s[l]` 与 `s[r]`：一旦不同就说明不是回文串；相同则让 `l` 加一、`r` 减一，两个下标同时向中间移动。当 `l >= r` 时所有配对都已检查完毕，字符串是回文串。
