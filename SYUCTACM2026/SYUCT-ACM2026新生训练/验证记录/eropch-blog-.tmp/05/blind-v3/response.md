• ## 1. 任务与约束复述

  **任务**：给定非空小写字符串 $s$ 与两个小写字母 $x,y$，把 $s$ 中所有等于 $x$ 的字符改成 $y$，其余字符原位不动，输出结果串。
  **输入**：两行。第一行为 $s$（$1\le|s|\le10^5$，仅 `a`–`z`）；第二行为 `x y`，单个空格分隔。
  **输出**：恰好一行结果串，长度与 `s` 相同；`x=y` 时原样输出，不含 `x` 时原样输出。
  **判定**：逐字符精确比较，除该行加一个行结束符（LF 或 CRLF）外不得有任何其他字符（含长度、提示、多余空行、多余空格）；空输出判错。答案唯一。
  **资源**：1000 ms / 256 MiB，单组数据。

  ## 2. 算法

  1. 用 `getline` 读入整行 $s$（可能残留行尾 `\r`，裁掉）。
  2. 用 `cin >> x >> y` 读入两个字符（`>>` 自动跳过空白，CRLF 也无影响）。
  3. 单趟线性扫描，原地修改：`for (char &c : s) if (c == x) c = y;`
  4. 输出 `s` 加一个 `\n`。

  关键点：题面是**字符对字符**的替换，不是子串替换，因此不存在“替换后新产生的 $y$ 又被再次替换”的级联问题，单趟原地扫描即为正确；一次比较只依赖原始字符值，不需要额外缓冲区。

  ## 3. 逐步正确性证明

  设原串为 $s_0$，长度为 $n$，正确答案为 $T$：$T[i]=y$ 当 $s_0[i]=x$，否则 $T[i]=s_0[i]$。

  **循环不变式**：在第 $i$ 次迭代开始时（$i$ 从 $0$ 到 $n$），对每个 $j<i$ 都有 $s[j]=T[j]$；对每个 $j\ge i$ 都有 $s[j]=s_0[j]$。

  - **初始化**：$i=0$，两段条件都未被触发，$s=s_0=T$ 在空范围上成立，不变式成立。
  - **保持**：设第 $i$ 次迭代前不变式成立。
    - 若 $s[i]=x$：由不变式 $s[i]=s_0[i]$，且 $s_0[i]=x$，故 $T[i]=y$；赋值后 $s[i]=y=T[i]$。
    - 若 $s[i]\ne x$：不改动，$s[i]=s_0[i]=T[i]$。
    - 两种情况都只修改位置 $i$，$j<i$ 的部分保持正确，$j>i$ 的部分仍为原值，于是迭代后（$i+1$ 时）不变式成立。
  - **终止**：$i=n$ 时前半段覆盖全部下标，得 $s=T$，即输出恰为正确答案。

  **特例验证**：
  - $x=y$ 时每次赋值都是自赋值 `c = c`，串不变，与题面“替换不改变任何字符”一致；不变式仍然成立（$T=s_0$）。
  - $s$ 中无 $x$ 时循环体从不执行，$s=s_0=T$。
  - 长度与位置：仅对已有字符赋值，既不插入也不删除，长度恒为 $n$，下标不变。

  **唯一性**：$T$ 逐位置由 $s_0,x,y$ 唯一确定，程序输出正是 $T$ 加一个行结束符，故与官方答案逐字符相同。

  ## 4. 复杂度

  - 时间：读入 $O(n)$ + 扫描 $O(n)$ + 输出 $O(n)$，合计 $O(n)$，$n\le10^5$，远低于 1000 ms。
  - 空间：$O(n)$ 存放字符串本身（$\approx 100$ KB 量级），除此之外仅常数个 `char`，远低于 256 MiB。

  ## 5. 边界条件、实现风险与高风险用例

  **必测边界**
  | 用例 | 期望 |
  |---|---|
  | `a` / `a b`（$n=1$，唯一字符被替换） | `b` |
  | `a` / `a a`（$x=y$，且整串都是 $x$） | `a` |
  | `abc` / `z z`（$x$ 不存在且 $x=y$） | `abc` |
  | `abc` / `z q`（$x$ 不存在） | `abc` |
  | `aaaa` / `a b`（整串全替换） | `bbbb` |
  | `aba` / `a b`（首尾替换、中间保留，注意不能连成 `bbb`） | `bbb`（此处 $b$ 是目标，中间 $b$ 原本就是 $b$，正确结果确为 `bbb`）——更保险的版本：`axa` / `a b` → `bxb` |
  | `a` $\times 10^5$ / `a a`，与 `a` $\times10^5$ / `a b`（规模与性能） | 原样 / 全 `b` |
  | 第二行行尾为 CRLF | 结果后面不能多出 `\r` 之外的任何东西（原样保留 `\r` 会被判错，必须裁掉） |

  **实现风险**
  1. **第一行行尾 `\r`**：若评测数据是 CRLF，`getline` 会把 `\r` 留在串尾，导致多输出一个字符而 WA。必须裁剪（相对地，第二行用 `>>` 读字符天然免疫）。
  2. **多余输出**：不要打印长度、提示语、空行，不要用 `endl` 反复刷新输出多行；只在最后输出一个 `\n`。
  3. **读入方式**：不要用 `scanf("%s")` 配过小缓冲区（需 $\ge 10^5+1$）；不要用 `cin >> s` 后又误以为能读到空格（本题串无空格，`>>` 其实也可，但 `getline` 更直观）。
  4. **误写成子串替换**：用 `find`/`replace` 循环替换会引入长度变化与级联替换（如把 `a` 换 `b`、再匹配到新 `b`），是典型错解；本题必须逐字符处理。
  5. **`x=y` 时做“二次替换”优化**（例如先转成别的哨兵再转回）容易出错，本题根本不需要哨兵。
  6. **`std::replace(s.begin(), s.end(), x, y)`** 与本解等价，可放心替代手写循环。
  7. **编译环境**：`bits/stdc++.h` 在 GCC/Clang 下可用但非标准，下面代码改用显式头文件以提高可移植性。

  ## 6. 假设与无法证明之处

  - 假设输入严格符合题面格式：第一行非空、仅含小写字母（因此裁剪“行尾 `\r`/空格”不会误删有效字符）；第二行恰好两个小写字母与一个分隔空格。若实际输入违约（例如串内含空格），本解按题面约定不负责。
  - 假设行结束符仅为 LF 或 CRLF，`\r` 不会作为实义字符出现在 $s$ 内部。
  - 假设评测机使用支持 C++17 的 GCC/Clang（标准 `<iostream>` 部分与平台无关，已规避 `bits/stdc++.h`）。
  - 唯一无法在“无工具”条件下亲自验证的是样例的实际运行输出；但两组样例均可手工推演：`banana` + `a o` → `bonono`；`abacaba` + `a a` → `abacaba`，与算法一致。

  ## 7. 完整 C++17 程序

  ```cpp
  #include <iostream>
  #include <string>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      std::string s;
      if (!std::getline(std::cin, s)) return 0;
      // 兼容 CRLF 行尾：去掉行尾的 '\r'（题面保证 s 只含小写字母，故不会误删）
      while (!s.empty() && (s.back() == '\r' || s.back() == '\n')) s.pop_back();

      char x = '\0', y = '\0';
      if (!(std::cin >> x)) return 0;
      if (!(std::cin >> y)) return 0;

      for (char &c : s) {
          if (c == x) c = y;   // x == y 时为自赋值，串不变
      }

      std::cout << s << '\n';  // 恰好一行，末尾单个换行
      return 0;
  }
  ```

  样例自检（手工推演）：`banana` / `a o` → `bonono`；`abacaba` / `a a` → `abacaba`，均与题面输出一致。
