【题目公开信息】

题目名称：《字符替换》

题目描述：给定一个由小写字母组成的字符串 s，以及两个小写字母 x 和 y。请把 s 中所有等于 x 的字符都替换为 y，其余字符保持原样不变，输出替换后的字符串。特别地，如果 x=y，替换不会改变任何字符；如果 s 中本来就没有字符 x，输出应与输入的 s 完全相同。

输入格式：输入共两行。第一行一个字符串 s，仅由小写字母组成。第二行两个小写字母 x 和 y，中间用一个空格隔开。

输出格式：输出一行一个字符串，表示把所有 x 替换为 y 之后的结果。

数据范围：
- 1 ≤ |s| ≤ 100000（|s| 表示字符串 s 的长度）。
- s 中的每个字符都是小写英文字母（a 到 z）。
- x、y 都是小写英文字母，允许 x=y。

样例：
输入：
banana
a o
输出：
bonono
（解释：banana 中共有三个 a，分别位于第 2、4、6 个位置，替换成 o 后得到 bonono；其余字符 b、n 不变。）

判题语义：本题输出唯一。选手输出必须恰好是一行替换后的字符串，多输出或少输出任何字符都会被判为错误答案（Wrong Answer）。
