• ## 1. 任务与约束复述

  **任务**：读入一个由小写字母组成的字符串 `s`，再读入两个小写字母 `x`（原字符）和 `y`（目标字符），把 `s` 中所有等于 `x` 的字符改成 `y`，其余字符原样保留，输出替换后的整个字符串。

  **约束**：
  - 输入共两行：第 1 行是 `s`，第 2 行是 `x` 和 `y`，中间用一个空格隔开。
  - `1 ≤ |s| ≤ 10^5`，`s` 只含 `a`–`z`（**保证非空，且不含空格**）。
  - `x`、`y` 均为 `a`–`z`，**允许 `x = y`**。
  - 若 `x = y`，结果与 `s` 完全相同；若 `s` 中不含 `x`，结果也与 `s` 完全相同（题面明确点出的两种退化情形）。
  - 输出**恰好一行**：替换后的字符串 + 一个行结束符（LF 或 CRLF 均可）。不得有空输出、额外 token 或任何额外非空内容。
  - Judge：答案唯一，逐字符精确比较（因此不能多打空格、提示语或空行）。
  - 资源：1000 ms / 256 MiB。

  ## 2. 算法

  逐字符映射，$O(|s|)$ 一趟扫描：

  1. 用 `cin >> s` 读入字符串（`s` 不含空白，流提取会自动跳过可能的前导空白，并天然忽略行尾的 `\r`，避免 CRLF 污染字符串）。
  2. 用 `cin >> x >> y` 读入两个字符（中间空格被流自动跳过）。
  3. 遍历 `s` 的每个字符 `c`：若 `c == x`，令 `c = y`，否则不动。
  4. 输出修改后的 `s`，仅追加一个 `'\n'`。

  不使用 `std::replace` 之外的任何依赖；整体是一个“就地映射”操作。

  ## 3. 逐步正确性证明

  记输入串为 $s = s_0 s_1 \dots s_{n-1}$，目标串为 $T$，其中
  $$T_i = \begin{cases} y, & s_i = x \\ s_i, & s_i \ne x \end{cases}$$

  **循环不变式**：在第 $k$ 次迭代开始前（$0 \le k \le n$），对任意 $0 \le i < k$ 有 $s_i = T_i$，而 $i \ge k$ 的位置仍是原始输入值。

  - **初始化**（$k = 0$）：尚未修改任何字符，`s` 即输入串，不变式空真成立。
  - **保持**：设第 $k$ 次迭代前不变式成立。迭代考察位置 $k$：
    - 若 $s_k = x$，执行 `s[k] = y`，则 $s_k = y = T_k$；
    - 若 $s_k \ne x$，不修改，则 $s_k$ 仍为原值 $= T_k$。
    且迭代未触碰其他位置，故 $k+1$ 次迭代前不变式仍成立。
  - **终止**：循环结束时 $k = n$，不变式给出对所有 $0 \le i < n$ 有 $s_i = T_i$，即整个字符串等于 $T$。

  **输出正确性**：程序打印修改后的 `s`，它与 $T$ 长度相同、逐字符相同，随后仅输出一个换行符，故输出恰为“一行 $T$”，满足精确比较与唯一性要求。

  **退化情形**：
  - $x = y$ 时，对任意 $i$，无论 $s_i$ 是否为 $x$，赋值 `s[k] = y` 都保持原值（$y = x = s_k$）或不做修改，故输出 $= s$，与题面一致。
  - $s$ 不含 $x$ 时，不变式的第二分支全程生效，$s$ 从未被修改，输出 $= s$。

  ## 4. 复杂度

  - 时间：读入 $O(n)$，单次扫描 $O(n)$，输出 $O(n)$，总计 $O(n)$，$n \le 10^5$，远低于 1000 ms。
  - 空间：存储字符串 $O(n)$（约 100 KB 上限），其余为 $O(1)$。

  ## 5. 边界条件、实现风险与高风险用例

  **实现风险**
  1. **CRLF 污染**（最主要风险）：若用 `getline` 读第 1 行且不剥离行尾 `\r`，则 `s` 尾部会混入 `\r`，输出多一个字符，精确比较必错。本实现用 `cin >> s`，`\r` 被视作空白被丢弃，天然免疫。
  2. **混用 `getline` 与 `>>`**：先 `>>` 后 `getline` 会读到残留空行，导致读空。本实现全程只用 `>>`，不存在该问题。
  3. **多余输出**：不能输出长度、换行后再多打空行或任何提示文字；结尾只输出一个 `'\n'`。
  4. **`ios::sync_with_stdio(false)`** 后不要再与 C 的 `printf/scanf` 混用（本程序未混用）。
  5. 字符比较用 `char` 与 `x` 直接比较即可，全部为 ASCII 小写字母，无符号性歧义。

  **高风险用例**
  | 用例 | 期望 | 考察点 |
  |---|---|---|
  | `s = "a"`, `x=y='a'` | `a` | $n=1$、$x=y$ |
  | `s = "z"`, `x='a' y='b'` | `z` | 无匹配字符 |
  | `s = "aaaaa"`, `x='a' y='a'` | `aaaaa` | 全匹配但 $x=y$ |
  | `s = 10^5 个 'a'`, `x='a' y='z'` | 10^5 个 `z` | 长度上限、性能 |
  | 同上的输入以 CRLF 结尾 | 无 `\r` 的纯字母行 | 换行符处理 |
  | `s = "banana"`, `x='a' y='o'` | `bonono` | 样例 1 |
  | `s = "abacaba"`, `x='a' y='a'` | `abacaba` | 样例 2 |

  ## 6. 假设与无法证明之处

  - 假设输入格式严格符合题面：第 1 行非空且不含空白字符，第 2 行恰有两个字母与一个空格，不存在前导空行或多余行。题面已冻结说明，故视为成立；即便首行有前导空格，`cin >> s` 也能正确处理。
  - 假设 `s` 中不存在 `\0` 或非 ASCII 字节（题面已限定）。
  - 除此之外无未证事项：正确性证明与复杂度均为上述严格论证，不依赖任何未说明的前提。

  ## 7. 完整 C++17 程序

  ```cpp
  #include <bits/stdc++.h>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      string s;
      char x = 0, y = 0;

      if (!(cin >> s)) return 0;   // 题面保证 |s| >= 1
      cin >> x >> y;               // 第二行：x 空格 y

      for (char &c : s) {
          if (c == x) c = y;
      }

      cout << s << '\n';
      return 0;
  }
  ```

  （编译：`g++ -std=c++17 -O2 -o main main.cpp`；运行结果仅输出一行替换后的字符串。）
