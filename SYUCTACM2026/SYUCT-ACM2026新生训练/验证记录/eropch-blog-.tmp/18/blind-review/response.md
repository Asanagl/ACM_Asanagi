• ## 任务与约束复述

  给定一个 \(n\) 行 \(m\) 列的整数矩阵 \(a\)，输出它的转置矩阵 \(b\)：

  \[
  b_{j,i}=a_{i,j}\quad(1\le i\le n,\ 1\le j\le m)
  \]

  因此，输出共有 \(m\) 行，每行 \(n\) 个整数；输出的第 \(j\) 行依次是原矩阵的第 \(j\) 列，从第 1 行到第 \(n\) 行。

  约束与要求：

  - \(1\le n,m\le100\)，矩阵不一定是方阵。
  - 每个元素满足 \(-10^9\le a_{i,j}\le10^9\)。
  - 每行相邻整数之间恰好一个空格，行首、行尾不能有额外空格。
  - 必须输出恰好 \(m\) 行，每行末尾有换行符，包括最后一行。
  - 不能增加空行、说明文字或其他内容。
  - 答案唯一，不能排序、去重或改变元素位置。
  - 使用 GNU C++17，资源限制为 1000ms、256MiB。

  ## 算法

  1. 读入 `n` 和 `m`。
  2. 按输入顺序，将矩阵保存到 `a[i][j]`，其中 `i`、`j` 从 0 开始。
  3. 枚举原矩阵的列 `j = 0 ... m-1`：
     - 枚举原矩阵的行 `i = 0 ... n-1`，依次输出 `a[i][j]`。
     - 仅在 `i > 0` 时，于当前整数前输出一个空格。
     - 每列输出完毕后输出 `'\n'`。

  元素最大绝对值为 \(10^9\)，虽然可由 32 位有符号整数表示，程序仍使用 `long long` 存储，避免不必要的类型范围顾虑。

  ## 逐步正确性证明

  1. **读入位置正确**  
     输入第 \(i\) 行第 \(j\) 个数被保存到程序中的 `a[i-1][j-1]`。因此程序中的 `a[i][j]` 恰好对应数学记号的 \(a_{i+1,j+1}\)。

  2. **每个输出位置的值正确**  
     对固定的 `j`，内层循环依次枚举 `i = 0 ... n-1`，输出：
     \[
     a_{1,j+1},a_{2,j+1},\ldots,a_{n,j+1}
     \]
     这正是转置矩阵第 \(j+1\) 行应包含的 \(n\) 个元素，顺序也完全符合 \(b_{j+1,i+1}=a_{i+1,j+1}\)。

  3. **行列数正确且没有元素遗漏或重复**  
     外层循环恰好执行 \(m\) 次，所以输出恰好 \(m\) 行。每次内层循环恰好执行 \(n\) 次，所以每行恰好 \(n\) 个整数。每个 \((i,j)\) 组合只被访问一次，因此所有元素恰好输出一次。

  4. **格式正确**  
     每行第一个整数前不输出空格；从第二个整数开始，每个整数前输出恰好一个空格。因此没有行首或行尾空格，且相邻整数之间恰好一个空格。每行结束后输出一个 `'\n'`，包括最后一行；程序没有其他输出。

  综上，在输入符合题面的前提下，程序输出恰好是唯一要求的转置矩阵。

  ## 复杂度

  - **时间复杂度：** \(O(nm)\)。读入和输出各处理 \(nm\) 个元素，且每个元素的十进制长度受题面范围限制。
  - **空间复杂度：** \(O(nm)\)，用于保存矩阵。
  - 最多保存 \(100\times100=10000\) 个 `long long`，原始元素数据约占 80,000 字节，加上少量容器开销，远低于 256MiB。

  ## 边界条件与高风险用例

  - `n = m = 1`：只输出一个整数和一个换行符，不能输出空格。
  - `n = 1, m = 100`：原矩阵只有一行，转置后必须有 100 行，每行一个整数。
  - `n = 100, m = 1`：原矩阵只有一列，转置后只有一行，包含 100 个整数。
  - `n != m`：容易误把输出循环写成 `n` 行、`m` 列；本程序明确输出 `m` 行、`n` 列。
  - 元素为 `-1000000000` 或 `1000000000`：必须原样输出，符号和数值均不能改变。
  - 存在重复元素：不能去重，必须按原位置关系保留。
  - 最后一行：必须有末尾换行，但不能再输出额外空行。

  ## 假设与无法实际验证之处

  - 假设评测输入严格符合题面，因此不处理缺数、非整数或额外输入等 malformed 情况。
  - 假设评测环境提供标准的 GNU C++17 编译与运行环境。
  - 数学正确性已由上述循环过程证明；没有尚未证明的算法环节。
  - 按只读盲审要求，未调用工具、未实际编译或运行，因此不对特定评测机上的实测耗时作断言。程序仅使用标准头文件和 C++17 支持的基础功能。

  ## 完整 GNU C++17 程序

  ```cpp
  #include <iostream>
  #include <vector>

  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int n, m;
      if (!(cin >> n >> m)) {
          return 0;
      }

      vector<vector<long long>> a(n, vector<long long>(m));

      for (int i = 0; i < n; ++i) {
          for (int j = 0; j < m; ++j) {
              cin >> a[i][j];
          }
      }

      for (int j = 0; j < m; ++j) {
          for (int i = 0; i < n; ++i) {
              if (i > 0) {
                  cout << ' ';
              }
              cout << a[i][j];
          }
          cout << '\n';
      }

      return 0;
  }
  ```
