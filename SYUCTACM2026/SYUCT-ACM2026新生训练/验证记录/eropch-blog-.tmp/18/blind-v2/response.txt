• ## 1. 任务、输入、输出与约束复述

  **任务**：给定一个整数矩阵，把它转置后输出。转置的含义是：原矩阵的第 $j$ 列，从上到下读出的 $n$ 个数，恰好成为新矩阵的第 $j$ 行；新矩阵共有 $m$ 行、$n$ 列。数值本身不改变，不排序、不去重、不合并，也不做任何算术运算。

  **输入**：第一行是两个整数 $n,m$，中间用一个空格隔开。之后有 $n$ 行，每行 $m$ 个整数，按行给出原矩阵。整个输入只包含这一组矩阵，不包含多组测试数据。

  **输出**：输出 $m$ 行。第 $j$ 行从左到右依次是原矩阵第 $j$ 列的 $n$ 个数，即原矩阵第 $1$ 行第 $j$ 列、第 $2$ 行第 $j$ 列、……、第 $n$ 行第 $j$ 列。每行恰好 $n$ 个整数，相邻整数之间恰好一个空格；行首和行尾不能有空格；每行（包括最后一行）以换行符结束；不能有空行、制表符或其他多余内容。

  **约束**：$1\le n\le 100$，$1\le m\le 100$；每个元素满足 $-10^9\le a_{i,j}\le 10^9$；$n$ 与 $m$ 相互独立，可以相等也可以不等，矩阵不一定是方阵；答案唯一，checker 会严格按行结构和每个数值比较；时间限制 1000 ms，内存限制 256 MiB，语言标准 gnu++17。

  ## 2. 算法与下标变化

  采用最直接的做法：先把整个矩阵读入二维数组，再按“列优先”的顺序输出。

  读入阶段使用两层循环：

  - 外层 $i$ 从 $0$ 到 $n-1$，表示输入行；
  - 内层 $j$ 从 $0$ 到 $m-1$，表示输入列；
  - 每次读入 `a[i][j]`。内层 $j$ 递增时，在同一输入行内从左向右移动；内层结束后，$i$ 递增，进入下一输入行。

  输出阶段把两层循环的角色互换：

  - 外层 $j$ 从 $0$ 到 $m-1$，表示输出行，也就是输入列；
  - 内层 $i$ 从 $0$ 到 $n-1$，表示输出列，也就是输入行；
  - 每次输出 `a[i][j]`。内层 $i$ 递增时，沿固定的输入列从上向下移动；内层结束后，$j$ 递增，换到下一输入列，也就是下一输出行。

  因此，输入中的位置 $(i,j)$ 在输出中变成位置 $(j,i)$，行列角色正好互换。输出时，若 $i>0$ 就先输出一个空格，再输出数值；内层结束后输出一个换行。

  伪代码：

  ```text
  读入 n, m
  for i = 0 .. n-1:
      for j = 0 .. m-1:
          读入 a[i][j]

  for j = 0 .. m-1:
      for i = 0 .. n-1:
          if i > 0: 输出一个空格
          输出 a[i][j]
      输出换行
  ```

  ## 3. 正确性证明

  以下使用 $0$ 下标：输入矩阵记为 $A$，$A[i][j]$ 表示输入的第 $i+1$ 行第 $j+1$ 列；输出矩阵记为 $B$，$B[j][i]$ 表示输出的第 $j+1$ 行第 $i+1$ 个数。题面要求：

  $$B[j][i]=A[i][j].$$

  **引理 1（读入正确）**：读入阶段结束后，`a[i][j]` 恰好等于输入矩阵第 $i+1$ 行第 $j+1$ 列的数。

  证明：对 $i$ 归纳。$i=0$ 时，内层 $j$ 从 $0$ 到 $m-1$ 依次读入第一行的 $m$ 个数，顺序正确。假设第 $i$ 行已经正确读入，外层递增到 $i+1$ 后，内层重新从 $j=0$ 到 $m-1$ 读入下一行的 $m$ 个数，因此第 $i+1$ 行也正确。归纳成立。

  **引理 2（每一行输出正确）**：固定任意 $j\in[0,m-1]$，输出的第 $j+1$ 行恰好是

  $$A[0][j],\ A[1][j],\ \ldots,\ A[n-1][j],$$

  相邻两个数之间恰好一个空格，行首无空格，行尾无空格，并以一个换行结束。

  证明：固定 $j$ 后，内层 $i$ 从 $0$ 到 $n-1$ 依次执行。$i=0$ 时条件 `i > 0` 为假，直接输出 $A[0][j]$，所以行首没有空格。之后每个 $i>0$ 都先输出一个空格，再输出 $A[i][j]$，所以相邻数值之间恰好一个空格，且行尾不会多出空格。内层结束后输出一个换行，因此该行格式正确。

  **定理（输出就是转置矩阵）**：

  - **形状正确**：外层 $j$ 执行 $m$ 次，所以输出恰好 $m$ 行；每行内层执行 $n$ 次，所以每行恰好 $n$ 个整数。输出形状为 $m\times n$，与转置后行数 $m$、列数 $n$ 一致。
  - **元素位置正确**：输出第 $j+1$ 行第 $i+1$ 个数是 $A[i][j]$，即输入的第 $i+1$ 行第 $j+1$ 列。按题面定义，转置矩阵满足 $b_{j+1,i+1}=a_{i+1,j+1}$，两者完全一致。
  - **出现次数正确**：映射 $(i,j)\mapsto(j,i)$ 是 $n\times m$ 个输入位置到 $m\times n$ 个输出位置的一一对应。每个输入元素恰好被写入一个输出位置，没有遗漏，也没有重复写入；重复出现的数值也按各自原来的行列位置分别保留，不会被合并或去重。
  - **格式正确**：每行第一个数前没有空格，相邻数之间恰好一个空格，行末没有空格；每行以且仅以一个换行结束，最后一行也有换行；$n\ge1$ 保证不会出现空行；输出中没有制表符或其他字符。

  所以输出与唯一的标准转置矩阵逐行、逐值完全一致，满足严格 checker 的要求。

  ## 4. 复杂度

  - **时间复杂度**：读入需要 $O(nm)$，输出也需要 $O(nm)$，总时间为 $O(nm)$。最大 $n=m=100$ 时只有 $10^4$ 个元素，远低于 1000 ms 的限制。
  - **额外空间复杂度**：存储整个矩阵需要 $O(nm)$ 的空间；除矩阵和常数个循环变量外，没有其他与规模相关的额外空间。最大约 $10^4$ 个 `long long`，约 80 KiB，远低于 256 MiB。

  ## 5. 边界情况与高风险用例

  - **$1\times1$**：输入 `1 1` 和一个数，例如 `-1000000000`，输出必须是该数加一个换行。代码中外层、内层各执行一次，正确。
  - **只有 1 行（$n=1,m>1$）**：输出 $m$ 行，每行只有 1 个数。例如输入 `1 3` 和 `5 6 7`，输出应为三行 `5`、`6`、`7`。高风险：误输出成一行 `5 6 7`。
  - **只有 1 列（$m=1,n>1$）**：输出 1 行 $n$ 个数。样例 2 即此情况。高风险：误输出成 $n$ 行。
  - **行列不相等**：一般 $n\ne m$，输出行数必须变成 $m$、列数变成 $n$。样例 1 是 $2\times3$ 变 $3\times2$，可用于检查。
  - **方阵（$n=m$）**：仍然要做转置，不能原样输出。例如 $2\times2$ 的 `[[1,2],[3,4]]` 应输出 `1 3` 和 `2 4` 两行。
  - **重复元素**：例如 $2\times3$ 的 `[[1,2,1],[3,4,3]]`，输出三行 `1 3`、`2 4`、`1 3`。两个 $1$ 和两个 $3$ 都必须保留，不能去重。
  - **元素取到 $\pm10^9$**：数值必须原样输出，不能溢出、不能丢负号。代码用 `long long` 读入，虽然本题用 `int` 也足够。
  - **全 0、全相同值、全负数**：数值不变，位置按转置关系排列。
  - **最大规模 $100\times100$**：共 $10^4$ 个数，输入输出量很小；单行最多 100 个数，长度约 1.1 KB，时间和内存都很宽裕。
  - **格式高风险点**：行尾多空格、最后一行漏换行、多输出空行、使用制表符、把 $n$ 和 $m$ 写反、把内外层循环写反、输出成原矩阵而不是转置矩阵。

  ## 6. C++17 程序

  ```cpp
  #include <iostream>
  #include <vector>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      int n, m;
      std::cin >> n >> m;

      std::vector<std::vector<long long>> a(n, std::vector<long long>(m));
      for (int i = 0; i < n; ++i) {
          for (int j = 0; j < m; ++j) {
              std::cin >> a[i][j];
          }
      }

      for (int j = 0; j < m; ++j) {
          for (int i = 0; i < n; ++i) {
              if (i > 0) {
                  std::cout << ' ';
              }
              std::cout << a[i][j];
          }
          std::cout << '\n';
      }

      return 0;
  }
  ```

  ## 7. 假设、无法证明之处与实现风险

  - **假设**：输入严格符合题面，即只有一组数据，$1\le n,m\le100$，元素个数正好为 $n\times m$，且每个元素在 $[-10^9,10^9]$ 内。这是题面保证，不是算法额外依赖的假设。
  - **无法证明之处**：无。正确性直接由转置定义、读入循环的归纳和输出循环的逐行分析给出。
  - **实现风险**：无实质风险。唯一需要小心的是输出空白格式；代码用 `if (i > 0)` 控制空格，保证行内恰好一个空格且无行尾空格，并在每行末尾输出 `'\n'`，保证最后一行也有换行。标准库 I/O 在 $10^4$ 个数规模下远低于 1000 ms。
