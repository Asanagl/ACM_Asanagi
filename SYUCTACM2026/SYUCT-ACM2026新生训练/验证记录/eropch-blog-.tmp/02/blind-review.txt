• ## 1. 任务与完整约束复述

  给定一行字符串 \(s\)，统计其中 **ASCII 码为 32 的空格字符**总数。

  - 输入只有一行，没有多组测试数据。
  - \(0\le |s|\le 100000\)。
  - \(s\) 只包含 ASCII 码 32 至 126（含端点）的可打印字符。
  - 输入行可以为空，此时 \(s\) 为空串，答案为 0。
  - 行末换行符不属于 \(s\)，不能计入答案。
  - 每个空格都要单独计数：
    - 连续空格不能合并；
    - 行首、行尾的空格也要计数；
    - 全部由空格组成的字符串，答案就是其长度。
  - 输出必须且只能是一个等于空格总数的非负整数，不得包含解释文字或其他非空白内容。允许常规的末尾换行。
  - 样例 `a  b   c` 中有 \(2+3=5\) 个空格；空行输出 0；恰好四个空格时输出 4。
  - 使用 gnu++17 和标准输入输出，时间限制 1000 ms，内存限制 256 MiB。

  ## 2. 算法

  1. 使用 `std::getline` 完整读入一行，保留行内所有空格，并去掉行末换行符。
  2. 将答案 `answer` 初始化为 0。
  3. 依次遍历字符串中的每个字符：
     - 如果字符等于 `' '`，即 ASCII 32，就将 `answer` 加 1；
     - 否则不做任何操作。
  4. 输出 `answer` 和一个换行符。

  ## 3. 正确性证明

  设字符串为 \(s_0s_1\cdots s_{n-1}\)，定义指示函数：

  \[
  I(c)=
  \begin{cases}
  1,&c\text{ 是 ASCII 32 的空格},\\
  0,&\text{其他情况}.
  \end{cases}
  \]

  题目要求的答案为：

  \[
  \sum_{i=0}^{n-1} I(s_i).
  \]

  **第一步：读入内容正确。**  
  `std::getline(std::cin, s)` 读取到第一个换行符为止，换行符不会存入 `s`，而行首、行尾及连续空格都会保留。因此程序处理的恰好是题目定义的字符串。

  **第二步：证明循环不变量。**  
  在处理完前 \(i\) 个字符后，恒有：

  \[
  answer=\sum_{j=0}^{i-1}I(s_j).
  \]

  - 初始时没有处理任何字符，`answer = 0`，等于空串中的空格数，不变量成立。
  - 假设处理前 \(i\) 个字符后不变量成立。处理 \(s_i\) 时：
    - 若它是空格，程序将 `answer` 加 1，恰好增加 \(I(s_i)=1\)；
    - 否则 `answer` 不变，恰好增加 \(I(s_i)=0\)。

  因此处理下一个字符后，不变量仍然成立。

  **第三步：得到最终答案。**  
  循环在遍历完全部 \(n\) 个字符后终止。由不变量：

  \[
  answer=\sum_{i=0}^{n-1}I(s_i),
  \]

  这正是题目要求的空格总数。程序只输出该整数和换行符，因此输出格式也正确。

  ## 4. 复杂度

  设 \(n=|s|\)，且 \(n\le100000\)。

  - **时间复杂度：** 读入一行需要 \(O(n)\)，遍历计数需要 \(O(n)\)，总计 **\(O(n)\)**。
  - **空间复杂度：** 保存字符串需要 **\(O(n)\)** 空间；除字符串本身外，计数器等辅助变量只占 **\(O(1)\)** 空间。
  - 最大只需保存约 100000 个字符，且答案最大为 100000，`int` 足够存储。

  ## 5. 边界情况、常见风险与不确定之处

  边界情况：

  - 空行：`s` 为空，循环不执行，输出 0。
  - 没有空格：输出 0。
  - 只有一个空格：输出 1。
  - 全部为前导或尾随空格：`getline` 不会丢弃它们，均能计入。
  - 连续多个空格：逐字符计数，不会错误合并。
  - 全部 \(100000\) 个字符都是空格：输出 100000，不会整数溢出。
  - 其他字母、数字和可打印标点：只有严格等于 `' '` 的字符才计数。

  常见错误：

  - 使用 `std::cin >> s`：会跳过空格并只读取一个非空白片段，无法正确处理本题。
  - 统计“空格段”而不是每个空格：会导致连续空格少计。
  - 先行去除首尾空格：会漏计前导和尾随空格。
  - 把行末换行符计入字符串：可能产生多余计数。
  - 按多组测试循环读取并输出多个答案：不符合本题只有一行的输入约定。
  - 输出 `ans =` 等说明文字：不符合唯一输出要求。

  在题面规定的合法输入范围内，没有影响算法正确性的未确定事项。程序不需要为非法字符、额外输入行或其他输入错误定义特殊行为。

  ## 6. 完整 C++17 程序

  ```cpp
  #include <iostream>
  #include <string>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      std::string s;
      std::getline(std::cin, s);

      int answer = 0;
      for (char c : s) {
          if (c == ' ') {
              ++answer;
          }
      }

      std::cout << answer << '\n';
      return 0;
  }
  ```
