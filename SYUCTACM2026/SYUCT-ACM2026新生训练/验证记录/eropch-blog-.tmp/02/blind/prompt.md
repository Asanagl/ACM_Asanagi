# 空格计数

给出一行文本，请统计其中空格字符的个数。每个空格都要单独计数：连续多个空格不能只算一次，行首和行尾的空格也不能漏掉。

文本可以是空串（此时答案是 0），也可以全部由空格组成。

## 输入格式

输入仅有一行，为字符串 s。行末的换行符不属于 s，不计入答案。

输入行可能为空，此时 s 是空串；除这一行的行末换行之外，输入中没有其他内容。

## 输出格式

输出一个非负整数，表示 s 中空格字符（ASCII 码为 32）的个数，行末输出一个换行符。

本题答案唯一：答案就是空格的总个数，不存在其他合法输出，也不得输出任何说明文字或第二行。

## 数据范围

- 长度（0 <= |s| <= 100000）。
- 每个字符的 ASCII 码（32 <= code <= 126），即 s 由可打印 ASCII 字符组成，可以包含空格。
- 除行末换行外没有其他空白字符；s 中不含制表符。

输入：

解释：a 与 b 之间有 2 个空格，b 与 c 之间有 3 个空格，两个连续段合起来是 5 个空格。

## 样例 3
