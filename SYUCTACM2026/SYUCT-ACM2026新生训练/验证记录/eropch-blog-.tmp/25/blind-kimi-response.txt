• ## 1. 任务与约束复述

  给定一个非空字符串 \(s\)。若存在非空字符串 \(t\) 和正整数 \(k\)，使得

  \[
  s=\underbrace{tt\cdots t}_{k\text{ 个 }t},
  \]

  则称 \(t\) 是 \(s\) 的循环单元。要求找到**长度最短**的循环单元 \(t\)，输出其长度 \(L\) 和字符串本身。

  - 输入只有一组数据，一行一个字符串 \(s\)。
  - \(1\le |s|\le 3000\)。
  - \(s\) 仅包含小写英文字母 `a`–`z`。
  - 循环必须完整重复，末尾不能留下多余字符，因此 \(|t|\) 必须整除 \(|s|\)。
  - 输出一行，恰好为 `L t`，中间一个空格，不能输出其他内容。
  - \(s\) 自身重复一次总是合法，因此答案必然存在。
  - 任意循环单元都是 \(s\) 的等长前缀，所以最短循环单元唯一。
  - 资源限制为 1000 ms、256 MiB。

  ## 2. 算法

  令 \(n=|s|\)，按照 \(L=1,2,\ldots,n\) 的顺序枚举循环单元长度。

  对于每个 \(L\)：

  1. 若 \(L\) 不能整除 \(n\)，直接跳过。
  2. 令候选循环单元为 \(s\) 的长度为 \(L\) 的前缀。
  3. 检查所有 \(i\in[L,n-1]\) 是否满足：
     \[
     s[i]=s[i\bmod L].
     \]
     这表示每一段长度为 \(L\) 的字符块都与该前缀完全一致。
  4. 第一个通过检查的长度就是最短答案，输出 \(L\) 及对应前缀，然后结束。

  不需要真的构造重复后的字符串。

  ## 3. 正确性证明

  ### 引理：检查条件等价于候选前缀是循环单元

  固定候选长度 \(L\)，令 \(u\) 为 \(s\) 的长度为 \(L\) 的前缀。

  **充分性：**

  假设 \(L\mid n\)，且所有 \(i\ge L\) 都满足 \(s[i]=s[i\bmod L]\)。对于 \(i<L\)，有 \(i\bmod L=i\)，相应等式显然也成立。

  把 \(s\) 按每 \(L\) 个字符分块。因为 \(L\mid n\)，设 \(n=kL\)，恰好能得到 \(k\) 个完整块。任意位置都可以写成

  \[
  i=qL+r,\qquad 0\le r<L,\quad 0\le q<k.
  \]

  检查条件给出 \(s[i]=s[r]\)，即第 \(q\) 块的第 \(r\) 个字符等于 \(u[r]\)。因此每一块都等于 \(u\)，从而 \(s=u^k\)，所以 \(u\) 是循环单元。

  **必要性：**

  若 \(u\) 是循环单元，则存在正整数 \(k\) 使 \(s=u^k\)。于是 \(n=kL\)，故 \(L\mid n\)。对于任意 \(i=qL+r\)，其中 \(0\le r<L\)，完整重复的定义直接给出

  \[
  s[i]=u[r]=s[r]=s[i\bmod L].
  \]

  因此算法使用的检查条件**当且仅当**候选前缀是循环单元。

  ### 定理：第一个通过检查的长度最短

  任意循环单元 \(t\) 的第一次出现都位于 \(s\) 的开头，所以 \(t\) 必然等于 \(s\) 的长度为 \(|t|\) 的前缀。算法枚举了所有可能的正长度，并根据上述引理精确判断对应前缀是否为循环单元。

  由于长度从小到大枚举，第一个通过检查的 \(L\) 不可能晚于任何更短的合法循环单元，因此它就是最短循环单元长度。

  ### 终止性与输出唯一性

  当 \(L=n\) 时，\(n\mid n\)，内层检查为空，前缀 \(s\) 自身必然通过。因此算法一定输出答案。

  最短长度 \(L\) 唯一，而长度为 \(L\) 的循环单元只能是 \(s\) 的长度为 \(L\) 的前缀，因此输出字符串也唯一。

  综上，算法输出的长度和字符串恰好是题目要求的最短循环单元。

  ## 4. 复杂度

  设 \(n=|s|\)。

  - 外层枚举 \(O(n)\) 个长度。
  - 每个候选长度最多进行 \(n-L\) 次字符比较。
  - 总比较次数不超过
    \[
    \sum_{L=1}^{n}(n-L)=\frac{n(n-1)}2,
    \]
    所以最坏时间复杂度为 **\(O(n^2)\)**。
  - 当 \(n=3000\) 时，该上界为 \(4\,498\,500\) 次比较，能够轻松满足限制。
  - 存储输入需要 \(O(n)\) 空间；程序直接输出原字符串的前缀，不额外构造答案字符串，因此辅助空间为 **\(O(1)\)**。

  ## 5. 边界条件、风险与重点测试

  重点用例：

  - `a` → `1 a`：最短合法输入。
  - `aaaa` → `1 a`：所有字符相同。
  - `ababab` → `2 ab`：公开样例，存在多个循环单元时选择最短者。
  - `abababab` → `2 ab`：不能把 `abab` 当作答案。
  - `abcab` → `5 abcab`：公开样例，末尾出现前缀不等于能完整重复。
  - `ababa` → `5 ababa`：字符串具有周期 \(2\) 的性质，但 \(2\nmid5\)，不存在长度为 \(2\) 的循环单元。
  - `abcabcabc` → `3 abc`：重复三次。
  - `abac` → `4 abac`：长度有真因数，但字符串不能由更短前缀完整重复。
  - 长度为 3000 的全 `a` 字符串：答案长度为 1。
  - 长度为 3000、没有非平凡循环单元的字符串：答案为整个字符串。
  - 长度为 3000、由较短字符串大量重复得到的输入：检查较长重复场景及输出正确性。

  常见错误：

  - 只检查周期性而遗漏 \(L\mid n\)，会误判 `ababa` 一类数据。
  - 把“某前缀也在末尾出现”误认为完整重复。
  - 找到一个循环单元后未确认它是最短的。
  - 前缀长度或下标出现差一错误。
  - 输出提示文字、调试信息或其他多余内容。

  ## 6. 完整 C++17 程序

  ```cpp
  #include <iostream>
  #include <string>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      std::string s;
      if (!(std::cin >> s)) {
          return 0;
      }

      const int n = static_cast<int>(s.size());

      for (int L = 1; L <= n; ++L) {
          if (n % L != 0) {
              continue;
          }

          bool ok = true;
          for (int i = L; i < n; ++i) {
              if (s[i] != s[i % L]) {
                  ok = false;
                  break;
              }
          }

          if (ok) {
              std::cout << L << ' ';
              std::cout.write(s.data(), L);
              std::cout << '\n';
              return 0;
          }
      }

      return 0;
  }
  ```
