# 回文修补

小艾有一个长度为 n 的字符串 s。如果一个字符串正着读和倒着读完全相同，就称它为回文串，例如 abba 和 abcba 都是回文串，而 abca 不是。

每次操作，小艾可以选中 s 中恰好一个位置，把这个位置上的字符替换成任意一个小写英文字母。操作不会改变字符串的长度，也不会改变其他位置上的字符。

请你计算：把 s 变成回文串，至少需要多少次操作？

## 输入格式

第一行输入一个整数 n（1 <= n <= 2 * 10^5），表示字符串的长度。

第二行输入一个字符串 s，长度为 n，仅由小写英文字母 a 到 z 组成，不含空格等空白字符。

## 输出格式

输出一个整数，表示把 s 变成回文串所需的最少操作次数，行末换行。

最少操作次数由 s 唯一确定，因此本题只有一个正确答案，不要输出任何其他内容。

## 数据范围

- n（1 <= n <= 2 * 10^5）：字符串长度；
- s 的长度恰好为 n；
- s 中每个字符都是小写英文字母 a 到 z。

## 样例 1

输入：
8
abccdzaa

输出：
3

解释：第 1 个字符与第 8 个字符都是 a，这一对已经相同，不需要操作。其余三对对称位置 (2,7)、(3,6)、(4,5) 上的字符分别是 (b,a)、(c,z)、(c,d)，都不相同，所以每一对至少要修改其中一个位置，至少需要 3 次操作。另一方面，把第 7 个字符改成 b、第 6 个字符改成 c、第 5 个字符改成 c，得到 abccccba，恰好用了 3 次操作。因此答案是 3。

## 样例 2

输入：
7
abxdcba

输出：
1

解释：三对对称位置中，只有第 3 个字符 x 与倒数第 3 个字符 c 不同。把 x 改成 c，得到回文串 abcdcba，用了 1 次操作。正中间的第 4 个字符 d 与它自身对称，不需要修改。原串不是回文串，0 次操作不够，因此答案是 1。

## Judge 语义

唯一答案。输出必须恰好是一个整数，其值等于唯一的最少操作次数；允许行首行尾空白与末尾换行，但不允许出现其他非空白内容。标准输入、标准输出。使用完整 C++17 程序，编译环境 gnu++17，时间限制 1000 ms，内存限制 256 MiB。
