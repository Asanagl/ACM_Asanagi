• ## 1. 任务与约束复述

  题目给定一个长度为 $n$ 的字符串 $s$，每次操作可以选中恰好一个位置，把该位置上的字符替换成任意一个小写英文字母（长度不变，其他位置不变）。要求求出把 $s$ 变成回文串所需的最少操作次数。

  - 输入：第一行整数 $n$；第二行一个长度恰为 $n$ 的字符串 $s$，只含 `a`–`z`，不含空白字符。
  - 输出：一个整数，即最少操作次数，行末换行；不允许输出任何其他非空白内容。
  - 数据范围：$1 \le n \le 2\times 10^5$；$s$ 长度恰好为 $n$；字符集为 26 个小写字母。
  - Judge 语义：唯一答案，标准输入/标准输出，C++17（gnu++17），时限 1000 ms，内存 256 MiB，允许首尾空白与末尾换行。

  ## 2. 算法与直觉

  **答案就是“对称位置字符不同的对”的数量**：令 $k=\#\{\,i \mid 0\le i<n-1-i,\ s_i \ne s_{n-1-i}\,\}$，输出 $k$。

  直觉：回文只要求每一对对称位置 $(i,\,n-1-i)$ 上的字符相等，不同对之间互不影响。若某一对已经相等，动它只会浪费操作；若某一对不等，至少得动其中一个位置，而只动一个位置就能让它相等（把其中一个改成另一个）。因此答案就是“坏对”的个数。

  实现上只需双指针/单循环比较 $i$ 与 $n-1-i$。

  ## 3. 正确性证明

  记 $j=n-1-i$。把位置 $i$ 与 $j$ 称为一对（$i<j$）。

  **下界（任何方案至少 $k$ 次）。**
  设把 $s$ 变成回文串 $t$ 的某方案共用了 $c$ 次操作，$t$ 满足 $t_i=t_j$ 对所有 $i<j$ 成立（$j=n-1-i$）。
  取出任意一对满足 $s_i\ne s_j$ 的 $(i,j)$。若该方案既没改 $i$ 也没改 $j$，则 $t_i=s_i$、$t_j=s_j$，于是 $t_i=s_i\ne s_j=t_j$，与 $t_i=t_j$ 矛盾。故这一对中至少有一个位置被操作过。又因为每次操作只触及一个位置，而所有对 $(i,j)$ 两两不相交（每个位置只属于一对），所以不同坏对需要的操作互不重复，总操作数 $c\ge$ 坏对个数 $=k$。

  **构造（存在恰好 $k$ 次的方案）。**
  对每个坏对 $(i,j)$，只做一次操作：把位置 $j$ 的字符改成 $s_i$（等价地改 $i$ 也可）。好对（$s_i=s_j$）不做任何操作。共 $k$ 次。改完后记新串为 $t$，则对每个 $i<j$：好对有 $t_i=s_i=s_j=t_j$；坏对按构造有 $t_i=s_i=t_j$。所以每对对称位置字符都相等。

  - **$n$ 为偶数**（$n=2m$）：位置被 $m$ 对 $(i,\,2m-1-i)$，$i=0..m-1$ 完全覆盖，没有“自身配对”的位置。上面的论证直接给出 $t$ 是回文串，且恰好 $k\le m$ 次。
  - **$n$ 为奇数**（$n=2m+1$）：$m$ 对 $(i,\,2m-i)$，$i=0..m-1$，再加上正中间位置 $m$。中间位置满足 $m=n-1-m$，即它只和自己对称，恒有 $t_m=t_m$，**无论它是什么字符都不需要修改，也不影响任何其他位置**。所以只需处理 $m$ 对，构造只用 $k$ 次，并且回文性质在中间位置自动成立。

  下界与构造吻合，故最少操作次数恰为 $k$；且当且仅当 $s$ 已是回文时 $k=0$，与“唯一答案”一致。

  ## 4. 复杂度

  - 时间：$O(n)$，一次线性扫描。
  - 空间：$O(n)$ 用于存储输入字符串（除此之外只用 $O(1)$ 的额外变量）。答案上限为 $\lfloor n/2\rfloor \le 10^5$，`int` 足够。

  ## 5. 边界情况、常见错误与假设

  边界：$n=1$（答案必为 0）；整个串已回文（答案 0）；$n=2$ 且两字符不同（答案 1）；全同字符；长度 $2\times10^5$ 的最大输入（答案可达 $10^5$）。

  常见错误（每条附具体输入）：

  1. **把正中间字符当成需要改的位置**，例如写 `ans = (n+1)/2 - 相等对数`。输入 `1 / a`，正确 0，错误输出 1；输入 `3 / aba`，正确 0，错误输出 1。
  2. **重复计数：把一对不匹配算成 2 次**（直接统计“与镜像位置不同的位置数”）。输入 `4 / abcd`，正确 2，错误输出 4。
  3. **循环上界写错**（`i <= n/2` 而不是 `i < n/2`，偶数长度时多比较了一对）。输入 `4 / abab`，正确 2，错误输出 3。
  4. **把“最少操作次数”误解为“是否回文”**（把答案写成 0/1）。输入 `8 / abccdzaa`，正确 3，错误输出 1。
  5. **`cin >> n` 与 `getline` 混用未吞掉换行**，导致 `s` 读成空串。输入 `3 / aba`，正确 0，错误可能输出 0（碰巧）或崩溃/越界；换 `3 / aab`（正确 1）就会错。
  6. **用定长小数组读字符串**（如 `char s[100]`）。输入第一行 `200000` 加对应长串，会缓冲区溢出或结果错误。
  7. **输出多余内容**（如 `ans=3`、`Case #1: 3`）。按 Judge 语义“不允许出现其他非空白内容”，任何输入都会判错。
  8. **把答案写成 $n/2$ 或 $n$**（把“对数”和“位置数”混淆）。输入 `4 / aaaa`，正确 0，错误输出 2 或 4。

  题面未明说处的假设：只有一组测试数据；第二行长度就是 $n$ 且无空格与 `\r` 之类残留（用 `cin >> s` 读取时前导空白与 `\r` 会被自动跳过）；输入一定合法，无需做异常处理；答案用 32 位整数即可。

  ## 6. 最大风险点／最易误解处

  最大风险是**题意极简导致的实现细节失误**，而不是算法难度：把“坏对的个数”错算成“坏位置的个数”（翻倍），以及奇数长度时对正中间字符的处理（它永远不需要修改：`1 / a` 的答案是 0）。其次是输入读取方式（`>>` 与 `getline` 混用、定长数组越界）和输出格式（多打印提示文字会直接判错）。另外要确认“每次操作改一个位置”而非“一次改一对”——样例 1 的答案是 3 而不是 1 正好印证了这一点。

  ## 7. 参考程序（C++17）

  ```cpp
  #include <bits/stdc++.h>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int n;
      if (!(cin >> n)) return 0;

      string s;
      cin >> s;

      int m = static_cast<int>(s.size());
      int ans = 0;
      for (int i = 0; i < m / 2; ++i) {
          if (s[i] != s[m - 1 - i]) ++ans;
      }

      cout << ans << '\n';
      return 0;
  }
  ```
