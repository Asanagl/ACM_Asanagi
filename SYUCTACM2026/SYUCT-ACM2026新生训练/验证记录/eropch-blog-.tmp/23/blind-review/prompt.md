# 回文修补

## 题目描述

小艾有一个长度为 n 的字符串 s。回文串是指正着读和倒着读完全相同的字符串，例如 abba 和 abcba 都是回文串。

每次操作，小艾可以选择 s 中恰好一个位置，把这个位置上的字符替换成任意一个小写英文字母。

请计算：把 s 变成回文串，至少需要多少次操作？

## 输入格式

第一行输入一个整数 n（1 <= n <= 2 * 10^5），表示字符串的长度。

第二行输入一个字符串 s（长度为 n，只含小写英文字母 a 到 z）。

## 输出格式

输出一个整数，表示把 s 变成回文串所需的最少操作次数。答案唯一，不要输出其他内容。

## 样例 1

输入：
8
abccdzaa

输出：
3

解释：第 1 个字符与第 8 个字符已经相同。其余三对对称位置 (2,7)、(3,6)、(4,5) 上的字符分别为 (b,a)、(c,z)、(c,d)，都不相同，因此每对至少需要一次操作。把第 7 个字符改为 b、第 6 个字符改为 c、第 5 个字符改为 c，得到回文串 abccccba，恰好用了 3 次操作。

## 样例 2

输入：
7
abxdcba

输出：
1

解释：三对对称位置中，只有第 3 个字符 x 与倒数第 3 个字符 c 不同。把 x 改为 c，得到回文串 abcdcba。正中间的第 4 个字符不需要修改。
