## 主代理审查

### 复述一致性

盲审独立复述了：第一行 `n`、第二行 `s`、`1 <= n <= 2*10^5`、`|s| = n`、字符集 `a`–`z`、输出唯一整数、允许首尾空白但禁止其他非空白内容。与冻结题面一致，无越界假设（明确写出"只有一组测试数据"、"输入保证合法"）。

### 算法

`k = #{ i | 0 <= i < n-1-i, s[i] != s[n-1-i] }`，输出 `k`。实现为单层循环 `for (i = 0; i < m/2; ++i)`，用 `m = s.size()`（而非读入的 `n`）驱动循环。这与主解的"左右双指针 `left < right`"在控制流上不同，是可信的独立实现。

### 正确性证明审查

- **下界**：取任一失配对 `(i,j)`，若 `i`、`j` 都未被修改，则 `t_i = s_i != s_j = t_j`，与回文矛盾；故每对至少被触及一次。又因各对称对位置互不相交，一次操作只改一个位置，故 `c >= k`。论证闭合，且显式指出"对之间不相交"这一关键点。
- **构造**：对每个失配对只改 `j` 为 `s_i`，共 `k` 次，逐对验证 `t_i = t_j`。闭合。
- **奇数长度**：指出中心 `m` 满足 `m = n-1-m`，`t_m = t_m` 恒成立，不需要修改也不提供任何操作收益。与偶数 `n=2m` 的"完全覆盖、无自配对位置"分别讨论。闭合。
- **等价性**：指出 `k = 0` 当且仅当原串已是回文，与唯一答案语义一致。

未发现逻辑漏洞。

### 复杂度

`O(n)` 时间、`O(n)` 空间（含输入串）/ `O(1)` 额外空间；答案上界 `floor(n/2) <= 10^5` 用 `int` 足够。正确。

### 代码审查

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n)) return 0;
    string s;
    cin >> s;
    int m = static_cast<int>(s.size());
    int ans = 0;
    for (int i = 0; i < m / 2; ++i)
        if (s[i] != s[m - 1 - i]) ++ans;
    cout << ans << '\n';
    return 0;
}
```

- `m/2` 对奇数长度自动截断，中心不参与，正确；
- 未使用 `n` 驱动循环，对"`n` 与 `|s|` 不一致"的非法输入也不会越界（本题输入保证一致）；
- `int` 范围安全；输出单个整数加换行，满足 strict checker 的 EOF 要求。
