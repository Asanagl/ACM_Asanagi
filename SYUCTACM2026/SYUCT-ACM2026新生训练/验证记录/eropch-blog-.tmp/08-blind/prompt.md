# 8. 子串在哪里

给定两个仅由小写英文字母组成的字符串 s 和 t，请求出 t 在 s 中**第一次**出现的位置。

具体地，如果存在整数 i（0 ≤ i ≤ |s|−|t|）使得 s 中从第 i 个字符开始的连续 |t| 个字符恰好组成 t（字符下标从 0 开始编号），则输出最小的这样的 i；如果不存在这样的 i，输出 -1。

注意匹配可以重叠：例如 s="aaaa"，t="aa" 时，t 既从位置 0 也从位置 1、2 开始出现，答案为 0。

## 输入格式
输入共两行。
第一行一个字符串 s（1 ≤ |s| ≤ 100000），仅由小写英文字母组成。
第二行一个字符串 t（1 ≤ |t| ≤ |s|），仅由小写英文字母组成。

## 输出格式
输出一个整数：t 在 s 中第一次出现的起始下标（下标从 0 开始）；若 t 不是 s 的子串，输出 -1。

## 样例 1
输入：
ababcabc
abc
输出：
2
解释：t 在 s 中出现了两次：从位置 2 开始的 abc 和从位置 5 开始的 abc，第一次出现的位置是 2。

## 样例 2
输入：
aaaa
aab
输出：
-1
解释：s 中所有长度为 3 的子串只有 aaa，没有 aab，所以输出 -1。
