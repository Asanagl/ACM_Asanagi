• ## 1. 题面复述

  输入一个非空字符串 `s`，仅含小写字母 `a`–`z`，长度满足 `1 ≤ |s| ≤ 1000`，不含任何空白字符。要求输出一行三个值：`|s|`（字符个数）、`s[0]`（首字符）、`s[|s|-1]`（尾字符），两两之间恰好一个空格，行末换行。答案由定义唯一确定，采用非交互式、仅按输出判定的方式，编译器为 GNU C++17，限时 1000 ms，限内存 256 MiB。

  ## 2. 算法

  1. 用 `std::cin >> s` 读入整行（因为输入不含空白，`operator>>` 恰好读走整个字符串）。
  2. 令 `n = s.size()`。
  3. 依次输出 `n`、空格、`s.front()`、空格、`s.back()`、换行。

  即直接按下标访问首尾，不做任何字符串变换。

  ## 3. 正确性证明

  记真实输入串为 $s$，其长度为 $n=|s|$，且 $n\ge 1$。

  - **长度正确**：输入中不含空白字符，故 `operator>>` 从流中读到的字符序列恰为整个 $s$，中途不会停止或被截断，因此读入后 `s.size() = n`，输出的第一个值为 $n$。
  - **首字符正确**：按定义，字符串第一个字符是下标 $0$ 的字符。由于 $n \ge 1$，下标 $0$ 合法，`s.front()` 等于 `s[0]`，即所求首字符。
  - **尾字符正确**：按定义，最后一个字符是下标 $n-1$ 的字符。由于 $n\ge 1$，有 $n-1 \ge 0$ 且 $n-1 < n$，下标合法，`s.back()` 等于 `s[n-1]`，即所求尾字符。
  - **格式正确**：输出顺序固定为“长度 → 首字符 → 尾字符”，相邻值之间各输出一个空格，末尾输出换行，与题面输出格式逐字符一致。

  三个输出值均与定义所指对象相同、顺序相同、分隔符相同，故任意合法输入下输出均为唯一正确答案。$\square$

  ## 4. 复杂度

  - 时间：读入需扫描 $n$ 个字符，为 $O(n)$；输出为常数次操作。总计 $O(n) \le O(1000)$。
  - 空间：存储字符串本身需 $O(n)$ 字节；除此之外为常数个变量，额外空间 $O(1)$。远低于 256 MiB。

  ## 5. 边界条件与高风险点

  - **长度为 1**：`s.back() == s.front()`，仍分别输出两次，形如 `1 a a`，不能只输出一个字符。
  - **全部字符相同**（如 `zzz`）：输出 `3 z z`，不是去重后的结果。
  - **最大长度 1000**：`s.size()` 为 `size_t`，直接输出无溢出问题；不要用 `int` 与 `size()-1` 混算导致无符号回绕（本题用 `front()/back()` 规避）。
  - **空输入**：题面保证 $|s|\ge 1$，故不出现；程序不对空串做特殊处理，若强行喂入空串行为不在约定范围内。
  - **读入方式**：不可用 `getline` 后忘记处理行尾 `\r`（若测试数据为 CRLF）——使用 `operator>>` 可自动跳过并丢弃行尾空白，避免尾字符被误判为 `\r`，这是本题最容易出错的地方。
  - 未使用任何浮点、递归或大内存结构，无精度与时序风险。

  ```cpp
  #include <iostream>
  #include <string>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      std::string s;
      if (!(std::cin >> s)) return 0;

      std::cout << s.size() << ' ' << s.front() << ' ' << s.back() << '\n';
      return 0;
  }
  ```

  ## 6. 说明

  程序仅依赖 `<iostream>` 与 `<string>`，`s.size()` 输出十进制长度，`s.front()`/`s.back()` 对应 `s[0]`/`s[n-1]`；样例 `hello` → `5 h o`，`a` → `1 a a` 均吻合。
