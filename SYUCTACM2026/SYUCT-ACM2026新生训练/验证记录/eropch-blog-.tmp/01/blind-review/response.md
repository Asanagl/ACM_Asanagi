• ### 1. 任务复述

  输入一行非空字符串 \(s\)，满足：

  - \(1\le |s|\le 1000\)；
  - 仅由小写英文字母 `a` 到 `z` 组成；
  - 不含空格等空白字符。

  需要输出一行三个值：字符串长度、第一个字符 `s[0]`、最后一个字符 `s[|s|-1]`。相邻值之间恰好一个空格，行末输出换行。长度为 1 时，首字符和尾字符相同。

  ### 2. 算法

  1. 使用 `std::string` 读入字符串 `s`。
  2. 通过 `s.size()` 得到长度。
  3. 通过 `s.front()` 和 `s.back()` 分别取得首、尾字符。
  4. 按规定格式输出。

  ### 3. 正确性证明

  1. 输入字符串不含空白字符，因此 `std::cin >> s` 读入的内容恰好是完整的输入字符串。
  2. `std::string::size()` 返回其中字符的数量，所以输出的第一个值就是 \(|s|\)，并以十进制形式打印。
  3. 因为合法输入保证 \(s\) 非空，所以 `s.front()` 和 `s.back()` 均有定义。前者是 `s[0]`，即首字符；后者是 `s[s.size()-1]`，即尾字符。
  4. 输出语句依次写入长度、一个空格、首字符、一个空格、尾字符和换行符，因此内容与次序正确，格式也完全符合要求。
  5. 当长度为 1 时，首、尾位置都是下标 0，因而两次输出同一字符，符合题意。

  因此，对任意合法输入，程序都输出唯一正确答案。

  ### 4. 复杂度

  设 \(n=|s|\)：

  - 时间复杂度：\(O(n)\)，主要用于读入并存储字符串；输出长度和字符不会增加该渐近复杂度。
  - 空间复杂度：\(O(n)\)，用于保存字符串；除输入字符串外仅需 \(O(1)\) 额外空间。

  \(n\le 1000\)，资源消耗远低于题目限制。

  ### 5. 边界条件与风险

  - **长度为 1**：`front()` 与 `back()` 返回同一个字符，例如 `a` 输出 `1 a a`。
  - **长度为 1000**：`std::string` 可以正常保存，长度可正确输出。
  - **首字符等于尾字符但长度大于 1**：无需特殊处理，直接输出即可。
  - **空字符串风险**：对空字符串调用 `front()`、`back()` 或计算 `s.size()-1` 都不安全，但题面保证字符串非空，所以合法输入不会触发该问题。
  - **输入中的换行**：`operator>>` 会跳过前导空白并在字符串后的空白处停止，适合本题输入格式。
  - 程序依赖题面保证输入合法；空输入或其他非法输入不在需要处理的范围内。在此假设下，没有无法证明之处。

  ### 6. GNU C++17 程序

  ```cpp
  #include <iostream>
  #include <string>

  int main() {
      std::string s;
      std::cin >> s;

      std::cout << s.size() << ' '
                << s.front() << ' '
                << s.back() << '\n';

      return 0;
  }
  ```
