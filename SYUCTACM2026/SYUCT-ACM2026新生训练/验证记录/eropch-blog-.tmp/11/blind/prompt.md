# 矩阵原样输出

给定一个 $n$ 行 $m$ 列的整数矩阵，请将它原样输出：输出的第 $i$ 行第 $j$ 个整数必须等于输入矩阵的第 $i$ 行第 $j$ 个整数。

## 输入格式

第一行输入两个整数 $n$（$1\le n\le 100$）和 $m$（$1\le m\le 100$），分别表示矩阵的行数和列数。

接下来输入 $n$ 行，每行输入 $m$ 个整数，其中第 $i$ 行第 $j$ 个整数为 $a_{i,j}$（$-1000\le a_{i,j}\le 1000$）。同一行内相邻整数之间恰好有一个空格，每行末尾没有空格；最后一行末尾有换行符，输入中没有空行或额外内容。

## 输出格式

输出 $n$ 行，每行输出 $m$ 个整数，依次表示原矩阵。不要输出第一行的 $n,m$。

同一行内相邻整数之间恰好用一个空格分隔，每行末尾不能有空格，最后一行末尾输出一个换行符。不得增加、删除或交换任何元素，也不得改变元素的数值或正负号。

本题输出唯一。数值、顺序、个数、换行或空格不符合上述要求，均会被判为错误答案。

## 样例

### 样例输入 1

~~~input1
3 4
0 -7 1000 0
5 5 -1000 9
-1 0 8 8
~~~

### 样例输出 1

~~~output1
0 -7 1000 0
5 5 -1000 9
-1 0 8 8
~~~

输出不包含第一行的 $3,4$。矩阵中的负数、$0$、重复元素以及边界值 $1000,-1000$ 都保持原值和原位置。

### 样例输入 2

~~~input2
1 5
7 -3 0 42 -56
~~~

### 样例输出 2

~~~output2
7 -3 0 42 -56
~~~

矩阵只有一行时，仍然读入并输出这一行的全部 $m$ 个元素。

### 样例输入 3

~~~input3
4 1
3
-2
3
0
~~~

### 样例输出 3

~~~output3
3
-2
3
0
~~~

矩阵只有一列时，每行只有一个整数，行内不需要输出空格。
