• ## 1. 任务、输入、输出与约束的完整复述

  **任务（用我自己的话）**：程序从标准输入读入一个由整数构成的矩阵，然后把它逐元素、逐位地再写回标准输出。输出中的第 i 行第 j 个数与输入中的第 i 行第 j 个数是同一个整数值；元素个数、行内先后次序、行与行的先后次序、数值本身以及负号都不能改变。不能增、不能删、不能调换。本题答案唯一，不是"任意构造"，因此必须精确复刻。

  **输入格式**：第 1 行两个整数 n、m，用一个空格分隔（题意保证这一行没有多余内容）。随后恰好 n 行，每行恰好 m 个整数，第 i 行第 j 个整数记作 a_{i,j}。同一行内相邻整数之间恰好一个空格，行末无空格，最后一行行末有换行符；输入中不存在空行，也不存在除这 n 行数据之外的内容。

  **输出格式**：输出恰好 n 行。第 i 行包含 m 个整数，对应输入矩阵第 i 行的 m 个元素，顺序与原矩阵一致。同一行内相邻整数之间恰好一个空格；行首、行尾都不允许出现空格；每一行（包括最后一行）以换行符结束。**不得输出输入第一行的 n 和 m**，也不得输出任何其他内容（提示信息、空行、多余空格、多余换行都不允许）。

  **全部约束**：1 ≤ n ≤ 100，1 ≤ m ≤ 100，−1000 ≤ a_{i,j} ≤ 1000。时间限制 1000 ms，内存限制 256 MiB，语言标准 gnu++17。判分语义为：按字节比较，任何数值、顺序、个数、空格或换行的偏差都判为错误答案。

  ## 2. 算法

  直接"读—写"同步进行，不做任何存储：

  1. 读入 n 和 m。
  2. 对 i = 0 … n−1：对 j = 0 … m−1：读入一个整数 a；若 j > 0 先输出一个空格，再输出 a。
  3. 内层循环结束后输出一个换行符。

  也就是说，读到的第 (i·m + j + 1) 个整数原封不动地写为第 i 行第 j 个数，元素之间由"当且仅当 j>0 时输出一个空格"控制，行尾由单独的换行符收束。整个过程 O(1) 辅助空间，一遍扫描完成。

  ## 3. 正确性证明

  约定 n、m 为读入的行列数，a_{i,j} 表示输入矩阵第 i 行第 j 个整数（下标从 0 起）。记输出边界的"第 i 行第 j 个数"为 b_{i,j}，即按输出顺序拆分出的第 i 行第 j 个整数；相邻整数之间须恰一个空格，行末须换行，且不得有行首空格。

  **引理 1（读入准确）**：设输入中除第一行外共有 K = n·m 个整数词元，按行优先顺序记为 t_1, …, t_K。程序第 k 次执行 `cin >> a` 时得到的值是 t_k，且恰有 K 次读入。
  证明：对 k 归纳。`operator>>(int)` 的语义是跳过前导空白（空格与换行皆属空白），然后贪心地读入能构成 `int` 的最长符号/数字序列。输入保证词元之间恰有一个空格、行间以换行分隔、末尾有换行符、没有别的字符，因此每次贪心读取恰好消耗一个完整词元并停在分隔符上；又因读取范围是合法的 32 位可表示整数（|a_{i,j}| ≤ 1000），转换不会溢出，得到的值即该词元的数学值。前 k−1 次已按序消耗 t_1…t_{k−1}，故第 k 次读到 t_k。输入共 K 个词元，所以恰好读 K 次，第 i 行第 j 个词元是 a_{i,j}，于是当 (i, j) 为当前循环状态时变量 a 的值等于 a_{i,j}。

  **引理 2（写出准确）**：记"规范前缀 P(i, j)"为：前 i 行（每行 m 个数、行内单空格分隔、行末换行），接着是第 i 行的前 j 个数 a_{i,0} … a_{i,j−1}（j ≥ 1 时相邻之间各一个空格），且此前不出现任何其他字符。则程序执行到"已完成 (i, j) 这一迭代"时，输出恰为 P(i, j+1)（若 j+1 = m 则视为该行已完成并已输出换行）。
  证明：对二元组按行优先序归纳。基础：进入 (0,0) 前输出为空 = P(0,0)；执行 (0,0)：j = 0 故不输出空格，直接输出 a_{0,0} 与引理 1 的值，得到 P(0,1)。归纳步：已得 P(i,j)，执行 (i,j)：若 j ≥ 1 先输出一个空格再输出 a_{i,j}（值由引理 1 正确），于是这一行已有 j 个值、新值接在空格之后，正是 P(i, j+1)；若 j = 0，则此时 P(i,0) 的末尾恰是第 i−1 行的换行符（i = 0 时为空），不写空格直接写 a_{i,0} 得到 P(i,1)，行首无空格。当 j = m−1 这一迭代之后，内层循环结束，程序输出一个换行符：该行末尾紧跟换行，中间没有空格（因为换行是紧接着 a_{i,m−1} 写出的），得到第 i 行完整结束，即 P(i+1, 0)。特别地 P(0,0) 为空保证第 0 行行首无空格。

  **推论（最终输出）**：由引理 2，i 递增到 n−1 且该行收尾后，输出恰为 P(n, 0)，即恰好 n 行、每行 m 个数、行内单空格、行首行尾无空格、每行（含末行）有且仅有一个换行符结束，且其后不再有任何字符——程序此后直接 `return`，`std::cout` 在正常退出时被刷新，不产生额外字节。

  **每个元素恰输出一次**：外层循环 i 取遍 0…n−1 各一次，内层循环 j 取遍 0…m−1 各一次，故内层循环体（恰含一次整数输出）执行次数恰为 n·m；且 (i,j) ↦ 该次输出的整数在输出中的位置 是单射（不同 (i,j) 落在不同的行或同一行不同列），所以输出中整数总数恰为 n·m，无遗漏、无重复、无多余元素。

  **位置、数值、正负号不变**：第 (i,j) 次输出被写在第 i 行第 j 个数的位置上（引理 2 计数可见：第 i 行此前的整数恰好是 j 个），而写入的数值由引理 1 等于 a_{i,j}；`operator<<(int)` 按十进制写出该 int 的精确值，负值前带一个 `-`、0 写作 `0`，不施加任何算术运算（无取反、绝对值、加减、类型收窄），因此数值与符号原样保留，位置与原矩阵一一对应。

  综上所述，输出的字节序列与题目规定的唯一正确答案逐字节一致。

  ## 4. 复杂度

  - **时间**：O(n·m)。恰好 n·m 次整数输入、n·m 次整数输出、n·m−n 次空格输出、n 次换行输出，n·m ≤ 10⁴，常数极小，远低于 1000 ms。
  - **额外空间**：O(1)。只有一个 `int` 暂存量与两个循环计数（外加标准流自带的定长缓冲，与 n、m 无关）。远低于 256 MiB。

  ## 5. 边界情况与高风险用例清单

  - **1×1**：`1 1` / `-1000` → `-1000⏎`。检查：只有一行一数、无空格、有末尾换行、负号保留。
  - **1×1 且值为 0**：`1 1` / `0` → `0⏎`。检查：不得输出 `-0` 或空行。
  - **1×1 且值为 1000**：`1 1` / `1000` → `1000⏎`。检查边界值不被截断。
  - **1 行多列**（如样例 2：`1 5` / `7 -3 0 42 -56`）：只有一行，行内 4 个单空格，行首无空格、行末无空格、末尾一个换行。
  - **1 行 100 列全为 1000**：最长单行，检查行末没有空格、也没有被折成两行。
  - **1 列多行**（如样例 3：`4 1` / `3 −2 3 0`）：每行一个整数，**行内不得出现空格**，不得把多行合并成一行。
  - **100 行 1 列全为 −1000**：最长的"单列"情形，检查 100 个换行、末行也有换行。
  - **全 0 矩阵**：检查输出 `0` 而非 `00`、`-0`、空格替代。
  - **全 −1000 矩阵**：检查负号逐个保留、不丢号、不变成 1000。
  - **重复元素**：如样例 1 的 `5 5`、`0 … 0`、`8 8`。检查不做去重、不做排序、不压缩。
  - **正负交替的极值**：`1000 -1000 1000 -1000`（多行多列）。检查符号与位置不串位。
  - **相邻易混数值**：`1 11 111 -1 -11 -111`。检查不粘连（少了空格）也不多加空格。
  - **每行首列为负数、末列为负数**：专门检查行首无空格（不会出现 `␣-2`）与行尾无空格（不会出现 `-2␣`）。
  - **最大规模 100×100 交替极值**：输出约 10⁴ 个数、数十 KB；检查无截断、无多余空行、总行数恰为 100、总换行恰为 100 个。
  - **输入无末尾换行（健壮性附加项）**：`cin >>` 在 EOF 处仍能成功取到末元素，程序不受影响。
  - **不得输出 n、m**：任何一个用例都应能在输出第一行直接看到矩阵值，而不是 `3 4`。
  - **不得有末尾空行**：所有用例输出末尾都恰是一个换行，不是两个。

  ## 6. C++17 程序

  ```cpp
  #include <iostream>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      int n = 0, m = 0;
      if (!(std::cin >> n >> m)) {
          return 0;
      }

      for (int i = 0; i < n; ++i) {
          for (int j = 0; j < m; ++j) {
              int a = 0;
              std::cin >> a;
              if (j > 0) {
                  std::cout << ' ';
              }
              std::cout << a;
          }
          std::cout << '\n';
      }

      return 0;
  }
  ```

  编译命令示例：`g++ -std=gnu++17 -O2 -o main main.cpp`。

  ## 7. 假设、无法证明之处与实现风险

  - **假设（表述层面）**："原样输出"按题意理解为**数值等价**而非输入字节的逐字符复制，且标准输出中整数的规范十进制写法（无前导零、无 `+` 号）与判分脚本期望的形式一致。这是本题唯一无法由程序自身证明的约定；若输入出现 `-0`、`+5`、`007` 这类非规范写法，程序会输出 `0`、`5`、`7`（数学值相同、字节不同）。题面已声明是常规整数输入且样例均为规范写法，判定风险极低。
  - **假设**：输入严格符合题面的合法性保证（恰好 n·m 个整数、无额外内容）。若读入失败，程序以不产生输出的方式安静退出，不输出任何错误信息，因此不会产生"非预期多余内容"。
  - **实现风险**：使用了 `sync_with_stdio(false)` 与 `'\n'`（而非 `std::endl`）来避免多余的刷新；`main` 正常返回时 `std::cout` 由静态析构刷新，不存在输出丢失。数据规模 10⁴ 个数，远小于缓冲区与时间限制，无溢出风险（|a| ≤ 1000，索引最大 10⁴）。
  - 除上述"十进制规范写法"的语义假设外，**无**其他无法证明之处：正确性、唯一性、每元素恰输出一次、位置/数值/符号不变均已在前一节闭合证明。
