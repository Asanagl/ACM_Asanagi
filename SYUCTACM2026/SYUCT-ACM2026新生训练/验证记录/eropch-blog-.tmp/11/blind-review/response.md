• ## 1）任务与完整约束复述

  给定一个 \(n\) 行 \(m\) 列的整数矩阵，需要按原有行、列顺序输出全部矩阵元素，不能输出输入第一行的 \(n,m\)。

  - \(1\le n\le 100\)，\(1\le m\le 100\)。
  - 每个元素 \(a_{i,j}\) 满足 \(-1000\le a_{i,j}\le 1000\)。
  - 输入第一行为 \(n,m\)，随后有 \(n\) 行，每行恰好 \(m\) 个整数；输入没有空行或额外内容。
  - 输出必须为 \(n\) 行，第 \(i\) 行依次包含 \(a_{i,1},\ldots,a_{i,m}\)。
  - 同一行相邻整数之间恰好一个空格，行尾不能有空格。
  - 每行之后都要换行，包括最后一行。
  - 不得增加、删除、交换元素，也不得改变元素数值或正负号。
  - Judge 要求数值、顺序、元素个数、空格和换行均符合规定，输出唯一。
  - 资源限制为 \(1000\ \mathrm{ms}\)、\(256\ \mathrm{MiB}\)。

  ## 2）算法

  不需要保存整个矩阵，可以边读边输出：

  1. 读入 \(n,m\)。
  2. 对每一行 \(i=1,\ldots,n\)：
     - 依次读入该行的 \(m\) 个整数。
     - 每行的第一个整数直接输出；从第二个整数开始，先输出一个空格，再输出整数。
     - 该行所有整数输出完毕后，输出一个换行符。
  3. 不输出任何其他内容。

  由于输入元素按行优先顺序给出，每次读到的整数就是当前需要输出的整数。

  ## 3）逐步正确性证明

  **第一步：每次读入的元素位置正确。**

  读入 \(n,m\) 后，剩余输入依次是
  \[
  a_{1,1},\ldots,a_{1,m},a_{2,1},\ldots,a_{n,m}.
  \]
  程序的外层循环按行递增，内层循环按列递增，每次恰好读入一个整数。因此由归纳法可知，处理第 \(i\) 行第 \(j\) 列时，读入的正是 \(a_{i,j}\)，不会遗漏、重复或交换元素。

  **第二步：每个元素的数值被正确保留。**

  程序读入整数后直接输出该整数，没有进行任何算术运算或类型范围缩窄。题面中的所有元素均可由 `int` 表示，因此输出数值等于输入数值，负数、零和重复元素也均被保留。

  **第三步：每一行的内容正确。**

  对固定的第 \(i\) 行：

  - \(j=1\) 时不输出前导空格，直接输出 \(a_{i,1}\)。
  - \(j>1\) 时，先输出一个空格，再输出 \(a_{i,j}\)。
  - 内层循环结束后不再输出空格，而是输出换行符。

  因此第 \(i\) 行恰好为
  \[
  a_{i,1}\ a_{i,2}\ \cdots\ a_{i,m},
  \]
  相邻元素之间恰好一个空格，行尾没有空格。

  **第四步：完整输出格式正确。**

  外层循环恰好执行 \(n\) 次，并按第 \(1\) 行至第 \(n\) 行的顺序输出。每行结束后都输出换行符，所以最后一行末尾也有换行符。程序从不输出 \(n,m\)，也没有任何额外输出。

  综上，程序输出与题面规定的唯一输出完全一致，故算法正确。

  ## 4）时间与空间复杂度

  - **时间复杂度：** \(\Theta(nm)\)。程序恰好读入并输出 \(nm\) 个矩阵元素。
  - **额外空间复杂度：** \(O(1)\)。只保存行数、列数、循环变量和当前元素，不存储矩阵；不计标准输入输出库自身的缓冲。

  最多只有 \(100\times100=10000\) 个元素，远低于给定的时间和内存限制。

  ## 5）边界条件、常见风险与假设

  - \(n=1\)：只输出一行矩阵数据，但末尾仍需换行。
  - \(m=1\)：每行只有一个整数，不应输出任何行内空格。
  - \(n=m=1\)：只输出一个整数和一个换行符。
  - \(0\)、重复元素、负数以及 \(-1000,1000\) 都直接读入并输出，不需特殊处理。
  - 常见错误包括：误输出第一行的 \(n,m\)；每行开头或结尾多输出空格；最后一行缺少换行；使用错误的行列循环次数。
  - 输入整数和矩阵规模都在 `int` 范围内，不存在整数溢出问题。
  - 假设输入严格符合题面，因此无需检查元素读取失败或增加输入合法性校验。“原样输出”指保留各元素的数值和位置，并按规定生成空格与换行，而不是逐字节复制整个输入。

  ## 6）完整 GNU C++17 程序

  ```cpp
  #include <iostream>

  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int n, m;
      if (!(cin >> n >> m)) {
          return 0;
      }

      for (int i = 0; i < n; ++i) {
          for (int j = 0; j < m; ++j) {
              int x;
              cin >> x;

              if (j > 0) {
                  cout << ' ';
              }
              cout << x;
          }
          cout << '\n';
      }

      return 0;
  }
  ```
