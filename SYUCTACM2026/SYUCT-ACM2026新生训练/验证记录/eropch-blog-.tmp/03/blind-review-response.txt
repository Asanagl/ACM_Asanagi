• ### 1. 任务复述

  需要统计输入字符串中五类元音的出现次数。每类元音的大写和小写形式要合并计算，例如 `a` 与 `A` 都增加 `a` 的计数。其他字母一律不计，尤其 `y`、`Y` 不属于元音。

  最终按照 `a、e、i、o、u` 的固定顺序输出五个计数，不能交换顺序，也不能输出其他内容。

  ### 2. 算法思路

  设置五个计数器，初始值均为零，分别对应 `a、e、i、o、u`。

  读取完整字符串后，从左到右逐字符检查：

  - 字符是 `a` 或 `A`：第一个计数器加一。
  - 字符是 `e` 或 `E`：第二个计数器加一。
  - 字符是 `i` 或 `I`：第三个计数器加一。
  - 字符是 `o` 或 `O`：第四个计数器加一。
  - 字符是 `u` 或 `U`：第五个计数器加一。
  - 其他字符：不做任何修改。

  遍历结束后依次输出五个计数器。每个字符只处理一次，不需要排序、嵌套循环或额外建立字符集合。

  ### 3. 正确性证明

  对遍历过程使用循环不变量证明。

  **第一步：定义不变量。**

  在处理完字符串的前 \(k\) 个字符后，五个计数器分别等于这段前缀中 `a、e、i、o、u` 的真实出现次数，且大小写形式已经合并统计。

  **第二步：初始状态成立。**

  尚未处理任何字符时，前缀为空。空前缀中五种元音的出现次数都为零，而算法将所有计数器初始化为零，因此不变量成立。

  **第三步：每处理一个字符，不变量仍然成立。**

  设下一个字符为 \(c\)：

  - 若 \(c\) 是某个元音的大写或小写形式，程序中对应的 `case` 会且只会执行一次，使该元音的计数器恰好加一，其余计数器不变。
  - 若 \(c\) 不是这十个元音字符之一，程序不会修改任何计数器。

  这正好等于在已有前缀计数的基础上加入当前字符的贡献。因此，处理完前 \(k+1\) 个字符后，不变量仍然成立。

  十个元音字符的匹配分支互不重叠，所以一个字符不可能被重复计数；所有其他合法字母，包括 `y` 和 `Y`，都不会触发计数。

  **第四步：遍历结束时得到整串答案。**

  当遍历结束时，已处理的前缀就是整个字符串。根据不变量，五个计数器就是整个字符串中五种元音的正确次数。

  程序随后严格按照 `a、e、i、o、u` 的顺序输出这些计数器，因此输出内容和顺序均正确。由于上述论证只依赖逐字符处理，对任意符合数据范围的字符串都成立。

  ### 4. 复杂度与性能

  设字符串长度为 \(n\)。

  - **时间复杂度：\(\Theta(n)\)**。读入和遍历各进行一次线性处理，每个字符只做常数次比较及至多一次自增，输出部分为常数工作量。
  - **额外空间复杂度：\(O(1)\)**。除输入字符串外，只使用五个计数器和少量变量。
  - **包含输入存储的总空间复杂度：\(\Theta(n)\)**。使用 `std::string` 保存输入。

  当 \(n=1{,}000{,}000\) 时，算法仅进行一百万次简单字符判断；关闭 C++ 标准流同步后，读入一百万个字符的开销也很小，在通常竞赛评测环境下可以 comfortably 满足 1 秒时限。

  输入字符本身约占 1 MB，再加上字符串对象的少量管理开销及程序运行开销，仍远低于 256 MiB。单个计数最大为一百万，使用 `long long` 计数不会溢出。

  ### 5. 边界情况与风险点

  - **长度为 1**：循环仍正常执行，输出该字符对应的计数及其余四个零。
  - **没有元音**：所有计数器保持为零，输出 `0 0 0 0 0`。
  - **全部是元音**：每个字符都会在对应分支中计数，不会遗漏。
  - **大小写混合**：每种元音显式匹配大写和小写两个分支，无需调用 `tolower`，也避免了字符转换及 locale 相关问题。
  - **`y` 和 `Y`**：不匹配任何计数分支，因此不会被统计。
  - **其他辅音字母**：同样不修改计数器。
  - **最大长度且全部为同一个元音**：对应计数为一百万，`long long` 可以安全保存。
  - **读入方式**：题面保证字符串不含空白字符，因此使用 `std::cin >> s` 可以一次读入整行内容，并自动忽略行首、行末的空白及 Windows 换行中的 `\r`。
  - **长度不可使用固定小缓冲区**：`std::string` 会动态分配空间，能够容纳一百万字符。
  - **输出格式**：五个整数之间只在相邻位置输出一个空格，不在行首或空格分隔位置添加多余内容；最后只输出一个允许存在的换行符。
  - **严格评测**：程序不输出提示语、调试信息或其他文本；无输入时直接返回只是防御性处理，不影响任何合法输入。

  ```cpp
  #include <bits/stdc++.h>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      string s;
      if (!(cin >> s)) {
          return 0;
      }

      long long cnt[5] = {};

      for (char c : s) {
          switch (c) {
              case 'a':
              case 'A':
                  ++cnt[0];
                  break;
              case 'e':
              case 'E':
                  ++cnt[1];
                  break;
              case 'i':
              case 'I':
                  ++cnt[2];
                  break;
              case 'o':
              case 'O':
                  ++cnt[3];
                  break;
              case 'u':
              case 'U':
                  ++cnt[4];
                  break;
              default:
                  break;
          }
      }

      for (int i = 0; i < 5; ++i) {
          if (i > 0) {
              cout << ' ';
          }
          cout << cnt[i];
      }
      cout << '\n';

      return 0;
  }
  ```
