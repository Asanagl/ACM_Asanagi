• ## 1. 任务复述

  给定一个非空字符串 `s`：

  - 长度满足 `1 ≤ |s| ≤ 1,000,000`。
  - 只包含英文字母 `a-z` 和 `A-Z`，字符串内部没有空白。
  - 分别统计 `a、e、i、o、u` 的出现次数，大小写合并，例如 `A` 和 `a` 都计入 `a`。
  - `y`、`Y` 以及其他辅音均不计入任何元音。

  输出一行五个非负整数，顺序固定为：

  ```text
  a的出现次数 e的出现次数 i的出现次数 o的出现次数 u的出现次数
  ```

  相邻整数用一个空格分隔，不能输出额外 token。答案唯一。资源限制为 1000 ms、256 MiB。

  ## 2. 算法与正确性证明

  ### 算法

  维护五个计数器 `cnt[0]` 至 `cnt[4]`，分别对应 `a、e、i、o、u`，初始均为 0。

  依次读取每个输入字符：

  - `a` 或 `A`：`cnt[0]` 加 1；
  - `e` 或 `E`：`cnt[1]` 加 1；
  - `i` 或 `I`：`cnt[2]` 加 1；
  - `o` 或 `O`：`cnt[3]` 加 1；
  - `u` 或 `U`：`cnt[4]` 加 1；
  - 其他字符：不做任何修改。

  读完后按 `cnt[0]` 到 `cnt[4]` 的顺序输出。

  不需要调用大小写转换函数，直接列举两种大小写，避免字符分类和区域设置带来的问题。

  ### 正确性证明

  对已经读取的字符串前缀长度进行归纳。

  **不变量：**读取前 `k` 个字符后，每个 `cnt[j]` 恰好等于该前缀中第 `j` 个元音的大小写合并出现次数，其中下标顺序为 `a、e、i、o、u`。

  1. **初始化：**尚未读取字符时，前缀为空，五种元音的出现次数都为 0。五个计数器也全部初始化为 0，因此不变量成立。

  2. **保持：**假设读取前 `k` 个字符后不变量成立。考虑第 `k+1` 个字符 `c`：
     - 若 `c` 是某个元音 `v` 的大写或小写形式，程序只将 `v` 对应的计数器加 1，其他计数器不变。新前缀恰好增加了这一个 `v`，所以所有计数器仍等于新前缀中的实际次数。
     - 若 `c` 不是元音，包括 `y`、`Y`，程序不修改任何计数器。新前缀中的各元音次数也没有变化，因此不变量仍成立。

  3. **终止：**输入是有限的，程序每轮读取一个字符，因此必定终止。合法输入中共有 `n=|s|` 个非空白字符串字符，终止时已经处理完整字符串。由不变量可知，五个计数器就是题目要求的五个答案。

  4. **输出正确性：**程序严格按 `a、e、i、o、u` 对应的下标顺序输出五个计数器，不输出其他数值 token。因此数值和格式均符合要求。

  ## 3. 复杂度、边界与风险

  - **时间复杂度：`O(n)`**。每个字符只进行常数次比较和至多一次加法。
  - **额外空间复杂度：`O(1)`**。程序不保存整个字符串，只保存五个计数器和当前字符；不计标准库的固定开销。
  - 每个计数最大为 `1,000,000`，五个计数之和也不超过 `n`。程序使用 `long long`，不存在整数溢出风险。
  - 长度为 1 的元音或辅音均能正确处理。
  - 全部为辅音、全部为 `y/Y` 时，五项均为 0。
  - 全部为同一种大写或小写元音时，只有对应一项为 `n`。
  - 没有结尾换行时，输入流会在 EOF 正常结束，不影响统计。

  ## 4. GNU C++17 完整程序

  ```cpp
  #include <array>
  #include <iostream>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      std::array<long long, 5> cnt{};
      char c;

      while (std::cin >> c) {
          switch (c) {
              case 'a':
              case 'A':
                  ++cnt[0];
                  break;
              case 'e':
              case 'E':
                  ++cnt[1];
                  break;
              case 'i':
              case 'I':
                  ++cnt[2];
                  break;
              case 'o':
              case 'O':
                  ++cnt[3];
                  break;
              case 'u':
              case 'U':
                  ++cnt[4];
                  break;
              default:
                  break;
          }
      }

      std::cout << cnt[0];
      for (int i = 1; i < 5; ++i) {
          std::cout << ' ' << cnt[i];
      }
      std::cout << '\n';

      return 0;
  }
  ```
