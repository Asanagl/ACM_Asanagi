# 四邻格统计

给定一个 $n$ 行 $m$ 列的 $0/1$ 网格。对于网格中的每个格子，统计它的四个正交邻居（上、下、左、右）中取值为 $1$ 的格子个数，并把统计结果按同样的形状输出成一个整数矩阵。斜向（对角线方向）的格子不算邻居；超出网格边界的方向没有邻居，不参与统计。

## 输入格式

第一行输入两个整数 $n,m$（$1\le n\le 500$，$1\le m\le 500$），分别表示网格的行数和列数。

接下来 $n$ 行，每行输入一个长度为 $m$ 的字符串，字符串中每个字符是 `0` 或 `1`，字符之间没有空格。第 $i$ 行第 $j$ 个字符表示第 $i$ 行第 $j$ 列格子的值：`0` 表示空，`1` 表示被占据。

## 输出格式

输出 $n$ 行，每行 $m$ 个整数，整数之间用一个空格分隔。

第 $i$ 行第 $j$ 个整数表示第 $i$ 行第 $j$ 列格子的四个正交邻居（上、下、左、右）中，值恰好为 `1` 的邻居个数。位于网格边界上的格子不足四个邻居，只统计实际存在的邻居；任何对角线方向的格子都不计入。

## 数据范围

- $1\le n\le 500$。
- $1\le m\le 500$。
- 网格中的每个字符要么是 `0`，要么是 `1`。

## 样例

~~~input1
4 4
0101
1010
0010
1101
~~~

~~~output1
2 0 3 0
0 3 1 2
2 2 1 2
1 1 3 0
~~~

以第 $1$ 行第 $1$ 列的格子为例：它的右邻居是 `1`，下邻居是 `1`，上邻居和左邻居不存在，所以答案是 $2$。

再以第 $3$ 行第 $3$ 列的格子为例：它的上邻居是 `1`，其余三个邻居都是 `0`，所以答案是 $1$。

注意第 $2$ 行第 $2$ 列的格子，它的上、左、右三个邻居都是 `1`，下邻居是 `0`，所以答案是 $3$；而对角线上的 `1` 不被计入。

## 提示

四邻居的位置可以用行、列坐标的偏移量 $(-1,0),(1,0),(0,-1),(0,1)$ 统一表示，配合边界检查即可。请注意第一行、最后一行、第一列、最后一列上的格子邻居数量不足四个。
