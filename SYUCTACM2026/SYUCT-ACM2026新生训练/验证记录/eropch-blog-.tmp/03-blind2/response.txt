• ## 1. 任务与格式复述

  给定一个仅由英文字母组成的字符串 `s`，长度满足 `1 <= |s| <= 1,000,000`，需要统计五个元音字母 `a, e, i, o, u` 各自出现的次数，统计时**不区分大小写**（`A` 记入 `a`，`E` 记入 `e`，其余同理）。`y` 和 `Y` 不是元音，任何情况下都不计入统计。

  输入只有一行，是一个不含空白的字符串，只包含 `a-z` 和 `A-Z`。

  输出只有一行，包含五个非负整数，按固定顺序 `a, e, i, o, u` 给出，相邻整数之间用一个空格分隔。Judge 按顺序读取并比较这五个整数；官方答案与选手输出都必须在第五个整数后结束，**不得有多余 token**。空白字符只用于分隔 token（输出末尾的换行也属于空白），多余内容会被判错。

  ## 2. 算法

  逐字符扫描，维护一个大小为 5 的计数数组。对每个字符先把大写字母映射为对应的小写字母（`c - 'A' + 'a'`），再用分支或查表判断它是否为元音并累加。不需要保存字符串，可在读入的同时统计。

  ```
  cnt[0..4] <- 0            // 对应 a,e,i,o,u
  while 还能从标准输入读到字符 c:
      if 'A' <= c <= 'Z':
          c <- c - 'A' + 'a'    // 只做大小写折叠，不改变字母身份
      if c == 'a': cnt[0] <- cnt[0] + 1
      elif c == 'e': cnt[1] <- cnt[1] + 1
      elif c == 'i': cnt[2] <- cnt[2] + 1
      elif c == 'o': cnt[3] <- cnt[3] + 1
      elif c == 'u': cnt[4] <- cnt[4] + 1
      // 其他字符（含换行）不做任何事
  输出 cnt[0] cnt[1] cnt[2] cnt[3] cnt[4]，用单个空格分隔，行末换行
  ```

  实现上用固定大小缓冲区 `fread` 分块读取，天然支持“输入末尾没有换行符”的情况，并且不依赖locale。

  ## 3. 正确性证明

  记 `s = s_0 s_1 ... s_{n-1}`，`n = |s|`。对每个元音 `v ∈ {a,e,i,o,u}` 定义指示函数 `I_v(c) = 1` 当且仅当 `c` 在忽略大小写后等于 `v`，否则为 `0`。题目要求的第 `j` 个输出就是 `Σ_{k=0}^{n-1} I_{v_j}(s_k)`（`v_j` 依次为 a,e,i,o,u）。

  **循环不变式**：在处理完前 `m` 个字符（`0 <= m <= n`）之后，对每个 `j ∈ {0,1,2,3,4}` 都有 `cnt[j] = Σ_{k=0}^{m-1} I_{v_j}(s_k)`。

  **基础**：`m = 0` 时 `cnt` 全为 0，而空和也为 0，成立。

  **归纳步**：设处理完前 `m` 个字符后不变式成立，现在处理 `s_m`。大小写折叠只把 `'A'..'Z'` 变为对应小写字母，对 `'a'..'z'` 保持不变，因此折叠后的字符 `c'` 与小写字母相等当且仅当原字符与某个大小写形式的元音相等；也就是说，折叠前后 `I_{v_j}` 的取值完全一致，折叠不会误判，也不会漏判（`y/Y` 折叠后为 `y`，不匹配任何分支，符合题意）。随后代码恰好对满足 `c' = v_j` 的那个 `j` 执行一次 `cnt[j] += 1`，其余计数器不变；对不匹配任何元音的字符，五个计数器都不变。因此新的 `cnt[j]` 等于旧值加上 `I_{v_j}(s_m)`，正好等于 `Σ_{k=0}^{m} I_{v_j}(s_k)`，不变式对 `m+1` 成立。

  **终止与输出**：`fread` 循环在读到文件结束（返回 0）时停止，此时已处理的字符数恰为 `n`（缓冲区被完整遍历，分块读取不会丢字符或多读）。由不变式，`cnt[j] = Σ_{k=0}^{n-1} I_{v_j}(s_k)`，正是元音 `v_j` 在 `s` 中不区分大小写的出现次数。`printf` 按 `a,e,i,o,u` 的顺序、以单个空格分隔输出这五个值并换行，恰好五个 token，无多余输出，满足 Judge 语义。故对任意合法输入都输出正确答案。

  另外，`n <= 10^6`，任一计数不超过 `10^6`，`int` 不会溢出，输出始终为非负整数。

  ## 4. 复杂度

  - 时间：每个字符做常数次比较与至多一次自增，总计 `O(n)`；`n = 10^6` 时约百万次简单操作，远低于 1000 ms。
  - 额外空间：计数数组 5 个 `int` 加 64 KiB 输入缓冲区，即 `O(1)`（与 `n` 无关），远低于 256 MiB。
  - 结论：最坏规模（`n = 10^6`）在这两个限制下完全安全。

  ## 5. 边界与高风险用例

  1. 没有任何元音，如 `"bcdfg"` → `0 0 0 0 0`（不能漏掉全零输出）。
  2. 全是元音且大小为写，如 `"AEIOU"` → `1 1 1 1 1`；全小写 `"aeiou"` → `1 1 1 1 1`。
  3. 大小写混排计数合并，如样例 `"AEIOUaeiou"` → `2 2 2 2 2`。
  4. `y` 与 `Y` 不计入，如 `"yyYY"` → `0 0 0 0 0`；`"yes"` → `0 1 0 0 0`。
  5. 长度为 1：`"a"` → `1 0 0 0 0`；`"Z"` → `0 0 0 0 0`。
  6. 长度上限 `10^6` 个 `'a'` → `1000000 0 0 0 0`（检验 `int` 容量与性能）。
  7. 输入末尾无换行符：分块读取到 EOF 即停止，不会少读或死循环。
  8. 大小写折叠的边界：`'A'(65)` 与 `'Z'(90)`、`'U'(85)` 与 `'u'(117)` 都要正确；不要对可能为负的 `char` 直接调用 `std::tolower`（未定义行为且受 locale 影响），本方案用算术映射，安全且确定。
  9. 输出格式：严格五个整数、单个空格分隔；不要多打提示文字、不要多打空格后跟其他内容。

  ## 6. 参考程序（GNU C++17）

  ```cpp
  #include <cstddef>
  #include <cstdio>

  namespace {
  constexpr std::size_t kBufSize = 1u << 16;
  char g_buf[kBufSize];
  }  // namespace

  int main() {
      int cnt[5] = {0, 0, 0, 0, 0};

      std::size_t got;
      while ((got = std::fread(g_buf, 1, kBufSize, stdin)) > 0) {
          for (std::size_t k = 0; k < got; ++k) {
              char c = g_buf[k];
              if (c >= 'A' && c <= 'Z') {
                  c = static_cast<char>(c - 'A' + 'a');
              }
              switch (c) {
                  case 'a': ++cnt[0]; break;
                  case 'e': ++cnt[1]; break;
                  case 'i': ++cnt[2]; break;
                  case 'o': ++cnt[3]; break;
                  case 'u': ++cnt[4]; break;
                  default: break;
              }
          }
      }

      std::printf("%d %d %d %d %d\n", cnt[0], cnt[1], cnt[2], cnt[3], cnt[4]);
      return 0;
  }
  ```
