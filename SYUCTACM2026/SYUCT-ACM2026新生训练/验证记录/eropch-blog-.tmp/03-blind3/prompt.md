# 元音计数

给定一个仅由英文字母组成的字符串 s。元音字母的集合固定为 {a,e,i,o,u}，统计时不区分大小写：例如 A 计入 a 的次数，E 计入 e 的次数，依此类推。注意 y 和 Y 都不是元音。

请统计字符串中五个元音字母各自出现的次数。

## 输入格式

输入一行一个字符串 s（1 <= |s| <= 1,000,000，且 s 仅由英文字母 a-z 与 A-Z 组成），不含空格等空白字符。

## 输出格式

输出一行五个非负整数，依次表示 a、e、i、o、u 在字符串中出现的次数（大小写合并统计），相邻整数之间用一个空格分隔。

## 数据范围

- 字符串长度满足 1 <= |s| <= 1,000,000（|s| 表示字符个数）。
- s 的每个字符都是英文字母：小写 a-z 或大写 A-Z。
- s 中不含空格、制表符、数字和标点，也不含其他任何 ASCII 字符或非 ASCII 字符。
- 输入恰好只有一行，这一行的行末换行之后没有任何内容。
- 五个答案中的每一个都不超过 10^6。

## 样例

样例 1
输入：
HeLloWorld

输出：
0 1 0 2 0

解释：字符串中 e 出现 1 次，o 出现 2 次，其余元音出现 0 次，因此按 a e i o u 的顺序输出 0 1 0 2 0。

样例 2
输入：
AEIOUaeiou

输出：
2 2 2 2 2

解释：每个元音的大小写形式各出现一次，合并后每个元音各出现 2 次。

样例 3
输入：
yes

输出：
0 1 0 0 0

解释：y 不是元音，只有 e 计入 e 的次数，因此输出 0 1 0 0 0。把 y 当成元音的实现会在这个样例上暴露。

## 判题说明

本题答案唯一：输出必须恰好是一行五个非负整数，顺序固定为 a、e、i、o、u，相邻整数之间用一个空格分隔，行末输出一个换行符。

- 官方答案与选手输出都必须在第五个整数后结束，不得有额外的 token。
- 空白只作为 token 之间的分隔符，不接受其他写法的数值，也不接受说明文字或第二行。
- 行结束符可为 LF 或 CRLF。

## 提示

- 答案中的每个数都不超过 |s|，使用 32 位整数存储即可。
- 请仔细阅读输出顺序：第一个数是 a 的次数，最后一个数是 u 的次数。
- y 和 Y 不是元音，不要计入任何一项。
