• # 1. 任务、输入、输出与约束（我的复述）

  **任务**：读入一个 $n$ 行 $m$ 列的整数矩阵 $A$，把它整体顺时针旋转 $90^\circ$，得到 $m$ 行 $n$ 列的矩阵 $B$，并按行输出 $B$。矩阵可以是非方阵；旋转是几何意义上的旋转，不能只交换 $n,m$。

  **输入格式**：
  - 第一行两个整数 $n,m$，用空格分隔；
  - 随后 $n$ 行，每行 $m$ 个整数，第 $i$ 行第 $j$ 个数是 $a_{ij}$，同行用空格分隔；
  - 输入恰好包含一个矩阵，没有多组数据。

  **输出格式**：
  - 恰好 $m$ 行，每行恰好 $n$ 个十进制整数；
  - 同行整数之间用一个空格分隔，行末可以有换行；
  - 不得输出任何其他内容（提示、多余空行、多余或缺失的整数都不允许）。评测按整数个数、数值、先后顺序逐项比较。

  **约束**：
  - $1 \le n \le 500$，$1 \le m \le 500$；
  - $-10^9 \le a_{ij} \le 10^9$（32 位有符号整数足够表示，但读写时用 64 位更稳妥）；
  - 时间 1000 ms，内存 256 MiB，语言标准 gnu++17；
  - 输入总规模最大 $500 \times 500 = 250{,}000$ 个整数。

  **唯一正确的旋转结果**（下文将证明）：以 1 起下标，对任意 $1\le i\le n$、$1\le j\le m$，

  $$B[j][\,n-i+1\,] = A[i][j].$$

  等价地，$B$ 的第 $j$ 行就是原矩阵第 $j$ 列**自下而上**读出：$B[j][1..n] = A[n][j], A[n-1][j], \dots, A[1][j]$。

  # 2. 算法

  1. 读入 $n,m$，把整个矩阵按行优先存入一维数组 `a[i*m + j]`（0 起下标），规模 $nm \le 250{,}000$，占用约 1 MB。
  2. 按输出行号 $r = 0,1,\dots,m-1$（对应原列 $j = r$）和输出列号 $c = 0,1,\dots,n-1$ 双重循环：
     - 由映射 $c = n - i$（1 起）反解出原行号 $i_0 = n-1-c$（0 起），原列号 $j_0 = r$；
     - 输出 `a[i0*m + j0]`，同一行内除首个元素外先输出一个空格，行末输出一个 `\n`。
  3. 使用 `fread`/`fwrite` 缓冲的快速输入输出（250k 个整数，缓冲 I/O 远在 1000 ms 内）。

  也就是说：**不构造新矩阵，直接按 $B$ 的行优先顺序去原矩阵取数**，取数下标就是上面那条映射的逆映射。

  # 3. 正确性证明（逐步、闭合）

  **定义映射**。令 $\varphi(i,j) = (j,\; n-i+1)$，其中 $(i,j)$ 是原矩阵位置（1 起），$\varphi(i,j)$ 是它在旋转结果中的位置。

  **引理 1（定义域与值域，良定义）**：若 $1\le i\le n$、$1\le j\le m$，则第一分量 $j\in[1,m]$，第二分量 $n-i+1$：由 $1\le i\le n$ 得 $0\le i-1\le n-1$，故 $1\le n-i+1\le n$。所以 $\varphi(i,j)\in[1,m]\times[1,n]$，即旋转结果的合法位置，不会越界。

  **引理 2（单射）**：设 $\varphi(i,j)=\varphi(i',j')$，即 $j=j'$ 且 $n-i+1=n-i'+1$。第二式两边减 $n+1$ 得 $-i=-i'$，故 $i=i'$。因此 $\varphi$ 是单射——**任何两个不同位置不会被送到同一个输出位置**，即输出不会重复。

  **引理 3（满射）**：任取输出位置 $(r,c)\in[1,m]\times[1,n]$，令 $i=n-c+1$，$j=r$。由 $1\le c\le n$ 得 $1\le n-c+1\le n$，所以 $(i,j)$ 是合法原位置；并且
  $$\varphi(i,j)=\bigl(r,\; n-(n-c+1)+1\bigr)=(r,\;c).$$
  故每个输出位置都有原像——**旋转后矩阵的每个位置都被覆盖，不会缺失**。

  **定理（双射与计数）**：由引理 1–3，$\varphi$ 是 $[1,n]\times[1,m]$ 到 $[1,m]\times[1,n]$ 的双射。定义域和值域的基数都是 $nm$。因此：
  - 旋转结果恰好 $m$ 行、每行 $n$ 列，共 $nm$ 个数（个数正确）；
  - 每个输出位置恰有一个原元素落入（不重复、不遗漏）；
  - 反之每个原元素恰被输出一次（不丢失、不复制）。

  逐行输出时，外层循环 $r=1..m$ 与内层 $c=1..n$ 恰好按 $B$ 的行优先顺序遍历全部 $nm$ 个位置，每个位置恰好访问一次，所以输出序列就是 $B$ 的行优先展开，个数、数值、顺序都与唯一正确答案一致。

  **方向性校验（为什么是顺时针）**：把 $A$ 放入平面，格 $(i,j)$ 的坐标取 $x=j,\ y=-i$（行向下增长）。顺时针旋转 $90^\circ$ 是 $(x,y)\mapsto(y,-x)$，于是 $(j,-i)\mapsto(-i,-j)$。新坐标为 $x'=-i,\ y'=-j$，而新矩阵的行号满足 $y'=-r$，故 $r=j$；列号由 $x'=-i$ 平移到 $1..n$ 得 $c=n+1-i$。这正是 $\varphi$。若换成逆时针，映射会是 $(i,j)\mapsto(m-j+1,\,i)$，与样例 1 的输出（$4\,1/5\,2/6\,3$，而逆时针应为 $3\,6/2\,5/1\,4$）不符，故本映射确为顺时针。

  **四角校验**（与题面描述一致）：
  - 原左上 $A[1][1]\mapsto B[1][n]$（新右上）；
  - 原左下 $A[n][1]\mapsto B[1][1]$（新左上）；
  - 原右上 $A[1][m]\mapsto B[m][n]$（新右下）；
  - 原右下 $A[n][m]\mapsto B[m][1]$（新左下）。
  题面“原左上角到新右上角、原左下角到新左上角”被满足。

  **样例 2 逐点校验**：$A_{3\times2}$，$B$ 为 $2\times3$。$B[1][1]=A[3][1]=-5$，$B[1][2]=A[2][1]=3$，$B[1][3]=A[1][1]=1$；$B[2][1]=A[3][2]=6$，$B[2][2]=A[2][2]=4$，$B[2][3]=A[1][2]=-2$，与期望输出完全一致。

  **程序与公式的一致性**：代码用 0 起下标，$i_0=i-1,\ j_0=j-1,\ r=j_0,\ c=(n-i+1)-1=n-i_0-1$，故 $i_0=n-1-c$、$j_0=r$，与上面的 1 起公式互为改写，不改变语义。

  # 4. 复杂度

  - **时间复杂度**：$O(nm)$。读入 $nm$ 个整数一次，输出 $nm$ 个整数一次，每个元素常数次算术与缓冲写，总计 $\Theta(nm)$，上限约 $2.5\times10^5$ 次读写，远低于 1000 ms。
  - **额外空间复杂度**：$\Theta(nm)$ 存储原矩阵（$500\times500\times4\text{ B}=1\text{ MB}$），外加两个 $64$ KiB 的 I/O 缓冲区（合计 $128$ KiB）与 $O(1)$ 的循环变量，峰值内存约 $1.2$ MB，远低于 256 MiB。
  - 该 $\Theta(nm)$ 是必要的：输出第 1 行需要 $A[n][1],A[n-1][1],\dots,A[1][1]$，这些数分布在整个输入中且顺序与输入相反；在单向、不可回退的标准输入下，开始输出前必须把已读数据全部保留，故任何正确实现都需 $\Omega(nm)$ 存储。

  # 5. 边界情况与高风险用例清单

  | 用例 | 输入 | 期望输出 |
  |---|---|---|
  | $1\times1$ | `1 1` / `-1000000000` | `-1000000000`（1 行 1 个数） |
  | 只有 1 行 ($n=1,m=3$) | `1 3` / `1 2 3` | `1`⏎`2`⏎`3`（3 行，每行 1 个数，原样自上而下） |
  | 只有 1 列 ($n=3,m=1$) | `3 1` / `1 2 3` | `3 2 1`（1 行 3 个数，列反转） |
  | 非方阵 $n<m$ | 样例 1 | `4 1`⏎`5 2`⏎`6 3` |
  | 非方阵 $n>m$ + 负数 | 样例 2 | `-5 3 1`⏎`6 4 -2` |
  | 全相同元素 | `2 3` / `7 7 7` / `7 7 7` | 3 行，每行 `7 7`（形状仍必须变成 $m\times n$） |
  | 含 $0$ 与 $\pm10^9$ | 含 `0`、`1000000000`、`-1000000000` | 原值原样出现在对应位置，不得溢出、不得丢负号、`0` 只输出一个 `0` |
  | 上限规模 $n=m=500$ | $250{,}000$ 个整数 | 500 行 × 500 个数，约 3.3 MB 文本，需保证末尾刷新缓冲 |

  高风险点：
  1. **行列数互换错误**：输出必须是 $m$ 行、每行 $n$ 个数。$n=1$ 或 $m=1$ 时这一错误最容易暴露。
  2. **方向搞反**：逆时针会得到完全不同的矩阵（样例可区分）。
  3. **只交换 $n,m$ 而不动元素**：非方阵时形状对但内容错。
  4. **行末多余空格或末尾空行**：虽然评测把空白当分隔符，仍按“单个空格分隔 + 每行一个换行”严格输出，最后一行后不再追加空行。
  5. **输出未刷新**：程序末尾必须 `fflush`/`fwrite` 刷新缓冲区，否则大数据量下会截断输出。
  6. **`-0` 或符号处理**：读入 `-` 后必须跟数字，写负数只在真正 $<0$ 时输出 `-`；本程序 `0` 只输出 `0`。
  7. **整数溢出**：值域 $[-10^9,10^9]$ 在 `int` 内；本程序读写用 `long long` 中间量，避免任何边界争议。

  # 6. 完整、可直接编译的 C++17 程序

  ```cpp
  #include <cstdio>
  #include <vector>

  namespace io {

  constexpr int BUFSZ = 1 << 16;

  char inbuf[BUFSZ];
  int inpos = 0, inlen = 0;

  inline int gc() {
      if (inpos == inlen) {
          inlen = (int)std::fread(inbuf, 1, BUFSZ, stdin);
          inpos = 0;
          if (inlen <= 0) return -1;
      }
      return (unsigned char)inbuf[inpos++];
  }

  bool readInt(long long &out) {
      int c = gc();
      while (c != -1 && (c < '0' || c > '9') && c != '-') c = gc();
      if (c == -1) return false;
      bool neg = false;
      if (c == '-') {
          neg = true;
          c = gc();
      }
      long long v = 0;
      while (c >= '0' && c <= '9') {
          v = v * 10 + (c - '0');
          c = gc();
      }
      out = neg ? -v : v;
      return true;
  }

  char outbuf[BUFSZ];
  int outpos = 0;

  inline void flushOut() {
      if (outpos > 0) {
          std::fwrite(outbuf, 1, (size_t)outpos, stdout);
          outpos = 0;
      }
  }

  inline void putChar(char ch) {
      if (outpos == BUFSZ) flushOut();
      outbuf[outpos++] = ch;
  }

  void writeInt(long long v) {
      if (v == 0) {
          putChar('0');
          return;
      }
      if (v < 0) {
          putChar('-');
          v = -v;
      }
      char tmp[24];
      int t = 0;
      while (v > 0) {
          tmp[t++] = (char)('0' + (int)(v % 10));
          v /= 10;
      }
      while (t > 0) putChar(tmp[--t]);
  }

  }  // namespace io

  int main() {
      long long nll = 0, mll = 0;
      if (!io::readInt(nll) || !io::readInt(mll)) return 0;

      const int n = (int)nll;
      const int m = (int)mll;

      std::vector<int> a(static_cast<size_t>(n) * static_cast<size_t>(m));
      for (int i = 0; i < n; ++i) {
          for (int j = 0; j < m; ++j) {
              long long v = 0;
              io::readInt(v);
              a[static_cast<size_t>(i) * static_cast<size_t>(m) +
                static_cast<size_t>(j)] = (int)v;
          }
      }

      // B[r][c] = A[n-1-c][r]  (0-based)
      for (int r = 0; r < m; ++r) {
          for (int c = 0; c < n; ++c) {
              const int i = n - 1 - c;
              const int j = r;
              if (c > 0) io::putChar(' ');
              io::writeInt(a[static_cast<size_t>(i) * static_cast<size_t>(m) +
                            static_cast<size_t>(j)]);
          }
          io::putChar('\n');
      }

      io::flushOut();
      return 0;
  }
  ```

  编译：`g++ -std=gnu++17 -O2 -o main main.cpp`。

  # 7. 假设、无法证明之处与实现风险

  **假设**（均来自题面，不需额外证明）：
  1. 输入恰好一个矩阵，格式如题面所述，不缺少整数；
  2. $1\le n,m\le 500$，$|a_{ij}|\le 10^9$，故元素可以用 `int` 存储、用 `long long` 中转，不会溢出；
  3. 标准输入单向不可回退（故采用“全部读入再按输出顺序取数”的策略）；
  4. 评测按空白分隔整数比较，但仍严格按“$m$ 行、每行 $n$ 个数、单个空格分隔、行末换行”输出，因此任何合理评测语义下都合法。

  **实现风险**：
  - 快速读入在跳过非数字字符时也会吞掉 `-`，但仅当 `-` 后紧跟数字时才正确解析；题面保证负数格式规范，故无风险。若输入末尾缺少换行，`gc()` 返回 $-1$ 时循环正常终止，不会越界读。
  - `writeInt` 中 `v = -v` 仅对 $|v|\le10^9$ 使用，不存在 `LLONG_MIN` 取反的未定义行为。
  - 输出量最大约 3.3 MB，依赖 `flushOut()` 在 `return` 前被调用（已显式调用），不会截断。

  **无法证明之处 / 未覆盖之处**：关于题面之外的评测细节（例如是否忽略行末空格）无需假设，因为本程序输出严格符合题面要求的规范格式，不依赖任何宽容语义。除此之外，**无**。
