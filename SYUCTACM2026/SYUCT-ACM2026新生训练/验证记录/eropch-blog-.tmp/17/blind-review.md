# 1. 任务复述（输入、输出、约束，用自己的话）

- **输入**：
  - 第一行：两个正整数 `n` 和 `m`（`1 <= n <= 100`, `1 <= m <= 100`）
  - 接下来 `n` 行：每行 `m` 个整数 `a_{ij}`（`-1000 <= a_{ij} <= 1000`），表示矩阵第 `i` 行第 `j` 列的元素，同一行内用空格分隔
- **输出**：
  - 输出 `n` 行，每行 `m` 个整数。第 `i` 行是原矩阵第 `i` 行**左右逆序**后的结果，整数之间用一个空格分隔。**行与行之间的顺序保持不变**。
- **约束**：`1 <= n <= 100`, `1 <= m <= 100`, `-1000 <= a_{ij} <= 1000`。时间 `1000ms`，内存 `256MiB`，编译标准 `gnu++17`。评测机逐 token 比较，忽略行尾空白差异，但**整数个数与顺序必须完全一致**。
- **说明**：每一行**独立**地左右逆序（例如 `1 2 3 4` -> `4 3 2 1`）。当一行只有一个元素时，逆序后保持不变。答案唯一。

# 2. 算法思路

本题是对矩阵的“逐行逆序”。思路极为直接：

1. **按行读取**：从标准输入读入 `n,m` 后，依次读入 `n` 行，每行读入 `m` 个整数，得到第 `i` 行的序列 `A_i = (a_{i1}, a_{i2}, ..., a_{im})`。
2. **逐行左右逆序**：对于每个序列 `A_i`，生成其左右逆序序列 `B_i = (a_{im}, ..., a_{i2}, a_{i1})`。该操作只针对当前行，不影响其他行。
3. **按原行顺序输出**：依次输出 `B_1, B_2, ..., B_n`，每行输出 `m` 个整数，整数间用空格分隔，每行结束用换行。

实现方式可以任选其一：
- **双指针原地逆序**：用数组存储当前行，用 `l = 0, r = m-1` 交换 `array[l]` 和 `array[r]`，`l++ , r--` 直到 `l >= r`，再顺序输出。
- **从后向前遍历输出**：直接用索引 `j = m-1` 到 `0` 遍历原数组并输出，不强制修改原数组结构也同样正确。
- **读取即处理**：每读完一整行（或读入 `m` 个元素）后立即逆序并输出，避免额外保留整个 `n*m` 矩阵的长期持有（对 `n,m<=100` 并非必要，但足够简洁且节省心智）。

以上均等价，且都能满足“行与行之间的先后顺序保持不变”的要求。

# 3. 逐步正确性证明

令原矩阵第 `i` 行为序列
$$
X_i = (x_{i,1}, x_{i,2}, ..., x_{i,m}),\quad x_{i,j} = a_{ij}.
$$
定义左右逆序算子 $Rev$ 为：
$$
Rev(X_i) = (x_{i,m}, x_{i,m-1}, ..., x_{i,1}).
$$

证明如下：

- **符合题意定义**：题目要求“把每一行独立地左右逆序：第 i 行的输出是原第 i 行从右到左的元素，行与行之间的先后顺序保持不变。”$Rev(X_i)$ 正是“从右到左”的元素顺序，且未对行索引 `i` 做任何重排，故行顺序保持不变。
- **逐行独立性**：操作仅作用于单个序列 $X_i$，不读取、不改动、不依赖 $X_k (k \neq i)$，因此符合“每一行独立地”这一要求。
- **边界情况正确**：若 $m == 1$，$Rev((x)) = (x)$，与样例 3 一致。若 $m == 0$（但约束中 $m>=1$）无需考虑。
- **元素保持**：逆序是 $X_i$ 元素的顺序置换，所有元素 $x_{i,j}$ 均恰好出现一次，且值不变，仅位置逆转。
- **样例验证**：
  - 样例 1：`1 2 3 4` -> `4 3 2 1`，`5 6 7 8` -> `8 7 6 5`，`9 10 11 12` -> `12 11 10 9`，行顺序不变，完全吻合。
  - 样例 2：第二行 `0 0 5` -> `5 0 0`，第一行全对称 `7 -1 7` -> `7 -1 7`，吻合。
- **唯一性与完备性**：对于每个长度为 $m$ 的序列，左右逆序是唯一确定的函数 $Rev$。算法对每行都精确计算 $Rev(X_i)$ 并按原顺序输出 $n$ 个结果，覆盖全部输入，且与题目“答案唯一”一致。

因此，该算法对于所有合法输入（$1<=n,m<=100, -1000<=a_{ij}<=1000$）都是正确的。

# 4. 时间复杂度与空间复杂度

- **时间复杂度**：$O(nm)$。读取 $nm$ 个元素花费 $O(nm)$，对每个元素至多访问/交换一次以完成行内逆序花费 $O(nm)$，输出 $nm$ 个元素花费 $O(nm)$。
- **空间复杂度**：$O(m)$ 额外空间。我们只需为**当前正在处理的这一行**准备一个长度为 $m$ 的数组（或向量）来存放该行的 $m$ 个元素，处理完当前行后即可复用。输入缓冲和输出缓冲不计入“额外”算法空间；若选择“从后向前”直接输出也可以做到 $O(1)$ 额外（不计 I/O 缓冲）。在 $n,m<=100$ 的前提下两者都远低于 $256MiB$。

# 5. 边界情况与风险清单

| 边界/风险 | 分析 | 对策 |
|---|---|---|
| $n=1, m=1$ | 单个元素 | 正确返回该元素（样例思路一致） |
| $m=1$ 的多行 | 每行只有一个元素，逆序不变 | 按正常流程处理即可 |
| 全负数（如 `-1 -2 -3`） | 符号不影响“位置逆序”这一操作 | 仅改变顺序，不改变数值本身，照常输出负数 |
| 零与负数混合（样例 2） | `7 -1 7` 对称，`0 0 5` -> `5 0 0` | 正确处理即可 |
| $n=100, m=100$（最大规模） | $10^4$ 个整数，极小 | $O(nm)$ 足够（远低于 1000ms），数组仅长 100 |
| 整数类型 | 范围 $-1000..1000$（`int` 足够） | 使用 `int` 读写 |
| 输入格式 | 每行 $m$ 个整数，同行空格分隔；题面说明“接下来 n 行，每行 m 个整数...” | 按行读取，若某些环境输入换行有差异也应以空格分隔的 token 为准（用 `cin >>` 最稳健） |
| 输出格式 | 每行 $m$ 个整数，整数间用一个空格分隔。每行逆序结果。行顺序不变。 | 用空格分隔，行与行之间用换行；不要在最后一行多余空格也不要少输出元素（评测忽略行尾空白但元素个数与顺序必须完全一致） |
| 行尾空白 | 评测“忽略行尾空白差异” | 推荐不要在每行末尾输出多余空格（循环到 $j==0$ 时不再输出空格即可） |
| 快速 I/O（C++） | $10^4$ 个 token 很小但养成好习惯 | 建议加 `ios_base::sync_with_stdio(false); cin.tie(NULL);`（对本题非必须，但安全且常用） |

# 6. 完整的 C++17（gnu++17）实现

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);
    
    int n, m;
    cin >> n >> m;
    
    for (int i = 0; i < n; ++i) {
        vector<int> row(m);
        // 读取当前行的 m 个整数
        for (int j = 0; j < m; ++j) {
            cin >> row[j];
        }
        // 左右逆序并输出当前行
        for (int j = m - 1; j >= 0; --j) {
            cout << row[j];
            if (j != 0) {
                cout << ' ';
            }
        }
        // 行间换行
        cout << '\n';
    }
    
    return 0;
}
```
