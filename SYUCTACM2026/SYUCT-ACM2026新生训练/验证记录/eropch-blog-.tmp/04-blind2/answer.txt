• # 盲审作答：大小写互换

  ## 一、任务复述

  - **输入**：标准输入的**一行**内容，即字符串 `s`。`s` 由 `1 ≤ |s| ≤ 1000` 个可打印 ASCII 字符（`32 ≤ code ≤ 126`）组成，可以含空格，首尾可以有空格，可以全是空格，不含制表符。
  - **变换规则**：逐字符、逐个位置替换，`A..Z` → 对应小写，`a..z` → 对应大写，其余一律不动。
  - **输出**：把变换结果原样写回一行，长度必须与 `|s|` 相同，行末恰好一个换行符，不得有任何多余文字、多余空行。当且仅当每个位置的字符都与标准答案一致时，答案才算正确。
  - **关键约束**：空格是“数据”而不是分隔符，读取与输出都不得裁剪首尾空格。

  ## 二、算法设计

  把变换定义成函数 `f`：

  ```
  f(c) = c + 32          当 'A' <= c <= 'Z'
  f(c) = c - 32          当 'a' <= c <= 'z'
  f(c) = c               其他情况（含空格、数字、标点）
  ```

  步骤：

  1. 用 `std::getline(std::cin, s)` 读入**整行**（不跳过空白、不截断尾部空格、丢弃行末 `\n`）。
  2. 对 `s` 中每个字符就地判断：若落在 `'A'..'Z'` 则 `+32`；否则若落在 `'a'..'z'` 则 `-32`；否则不改。
  3. 输出 `s`，再输出一个 `'\n'`。

  伪代码：

  ```
  read_line(s)                  # 读入整行，保留所有空格
  for i = 0 to len(s)-1:
      c = s[i]
      if 'A' <= c <= 'Z': s[i] = c + 32
      else if 'a' <= c <= 'z': s[i] = c - 32
      # else: 保持不变
  print(s + "\n")
  ```

  刻意**不使用** `<cctype>` 的 `isupper/tolower`：这些函数依赖当前 locale，且传入负值 `char` 属于未定义行为；直接用 ASCII 区间判断更稳、更快、无歧义。

  ## 三、正确性证明

  **引理 1（读入无损）。** `std::getline(cin, s)` 读取当前行中从行首到第一个 `'\n'` 之前的全部字符，包括所有空格，并且不做任何空白裁剪。题面保证输入恰为“`s` + 换行”，且 `s` 的字符都属于 `[32,126]`（其中不含 `'\n'` 与 `'\r'`），因此读入结束后 `s` 逐字符等于题面中的字符串，首尾空格、全空格情形均原样保留。
  （实现中额外删除末尾的 `'\r'`：由于 `13 ∉ [32,126]`，该操作在合法输入上是恒等变换，只在判题数据误用 CRLF 行尾时起保护作用。）

  **引理 2（逐字符映射正确）。** 对任意 `c ∈ [32,126]`：
  - 若 `c ∈ [65,90]`，则 `c+32 ∈ [97,122]`，且 `c+32 = c - 'A' + 'a'`，即与 `c` 对应同一字母的小写形式；
  - 若 `c ∈ [97,122]`，则 `c-32 ∈ [65,90]`，即对应的大写形式；
  - 否则 `c` 不属于英文字母，`f(c)=c`，符合“其余字符保持原样”。

  又因 `[65,90]` 与 `[97,122]` 不相交，三分支**互斥**；且并上“其他”后**穷尽**全部 ASCII，故 `f` 是每个字符上都有定义且唯一的函数。

  **引理 3（循环不变式）。** 记原串为 `s₀`，处理到下标 `i`（`0 ≤ i ≤ n`）之前的不变式为：
  > `s[0..i-1] = f(s₀[0]) f(s₀[1]) … f(s₀[i-1])`，且 `s[i..n-1] = s₀[i..n-1]`。

  - 初始化：`i=0` 时两段均为空或整段未改动，成立。
  - 保持：第 `i` 步只把 `s[i]` 改成 `f(s[i]) = f(s₀[i])`（由引理 2），其余下标不变，不变式对 `i+1` 成立。
  - 终止：`i=n` 时得 `s = f(s₀[0]) … f(s₀[n-1])`。

  **引理 4（长度与位置保持）。** 全过程只在原位置赋值，不插入、不删除、不移动，故输出串长度恒为 `n = |s|`，且第 `i` 个输出字符由第 `i` 个输入字符决定。

  **定理。** 由引理 1、3、4，程序输出为 `f(s₀[0])…f(s₀[n-1])` 恰好追加一个 `'\n'`，逐字符等于题目规定的答案；程序不打印任何其他内容，故只输出一行、长度正确、行末恰一个换行符。又因 `f` 是确定的函数，任何合法实现的输出都唯一，本算法即命中该唯一输出。∎

  ## 四、复杂度分析

  - **时间**：读入 `n` 字符 + 一次线性扫描 `n` 次常数时间判断 + 输出 `n+1` 字符，总计 `O(n)`。`n ≤ 1000`，在 1000ms 限时下余量极大。
  - **空间**：存放输入输出串需要 `O(n)`；除该串外只用若干 `char`/下标，**额外辅助空间 `O(1)`**。远低于 256MiB。

  ## 五、边界情况与潜在陷阱

  - **首尾空格 / 全空格行**：用 `cin >> s` 会跳过前导空白并在第一个空格处停止，是全错；用 `scanf(" %[^\n]", buf)` 也因前导空格被吃掉而错。本实现用 `getline` 整行读取，天然保留。
  - **不能多输出空行**：`getline` 已丢弃行末换行，输出时只补一个 `'\n'`。不要用 `while(getline(...))` 逐行处理再拼，也不要 `endl` 打两次。
  - **`'Z'` 与 `'a'` 之间的 6 个字符**：`[ \ ] ^ _ `` ` ``（91–96）以及 `'@'`(64)、`'{'`(123) 等。写成 `if ('A' <= c && c <= 'z')` 是经典错误，会误改这 6 个字符；本实现用两条互不相交的区间判断。
  - **数字与标点**：`0-9 : ! - . , ; ? " '` 等一律不匹配区间，保持原样；样例 1 已覆盖 `0 4 : - !`。
  - **长度边界**：`n=1` 时循环执行一次，正确；长度打印不做任何补齐或截断。
  - **EOF 时无换行符的行**：`getline` 仍返回该行内容，行为正确；若读入彻底失败（违反约束），代码输出一个空行以保证仍是一行一换行，不会崩。
  - **CRLF 行尾风险**：若判题数据用 `\r\n`，`'\r'` 会混入串中并破坏长度判定，故在读取后剔除末尾 `'\r'`（合法输入上恒为空操作）。
  - **`char` 符号性**：本实现只在 `32..126` 上与字面量比较、只加减 32，不会溢出；不使用 `toupper/tolower/isupper`，规避 locale 与负值 UB。
  - **C 风格读入**：`gets` 已在 C++14 移除且溢出；`fgets` 需自行去掉 `'\n'` 并小心缓冲区大小。改用 `std::string` + `getline` 无长度上限风险（即使 `n>1000` 也不越界）。
  - **I/O 混用**：若加 `ios::sync_with_stdio(false)`，必须全程只用 `cin/cout`，不可混入 `printf`。

  ## 六、C++17 参考实现

  ```cpp
  #include <iostream>
  #include <string>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      std::string s;
      if (!std::getline(std::cin, s)) {   // 整行读入，保留全部空格（含首尾空格）
          std::cout << '\n';              // 题面保证不会走到这里；兜底仍保持"一行一换行"
          return 0;
      }

      // 若判题数据误用 CRLF 行尾，则剔除串尾的 '\r'；合法输入（32..126）下此步无操作
      if (!s.empty() && s.back() == '\r') s.pop_back();

      for (char &c : s) {
          if (c >= 'A' && c <= 'Z') {
              c = static_cast<char>(c - 'A' + 'a');   // 大写 -> 小写
          } else if (c >= 'a' && c <= 'z') {
              c = static_cast<char>(c - 'a' + 'A');   // 小写 -> 大写
          }
          // 其余字符（空格、数字、标点）保持原样
      }

      std::cout << s << '\n';             // 恰好一行 + 一个换行符
      return 0;
  }
  ```

  自检两个样例：
  - `SyuctOJ 04: AbZ-z!` → `sYUCToj 04: aBz-Z!`（`S→s, y→Y, u→U, c→C, t→T, O→o, J→j`，`A→a, b→B, Z→z, z→Z`，空格/数字/`: - !` 不变）。
  - `"  Hello World  "` → `"  hELLO wORLD  "`（5 个空格位置与数量均不变，串长不变）。
