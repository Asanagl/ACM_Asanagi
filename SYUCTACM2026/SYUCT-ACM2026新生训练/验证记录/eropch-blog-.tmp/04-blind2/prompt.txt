# 大小写互换

给定一行字符串 s。请逐字符修改：把英文大写字母改成对应的小写字母，把英文小写字母改成对应的大写字母，其余字符保持原样，最后输出修改后的字符串。

英文字母仅指 A 到 Z 以及 a 到 z。字符在字符串中的位置不变，空格、数字和标点都要原样保留，字符串首尾的空格也不能删除。

## 输入格式
输入只有一行，为一个字符串 s（1 <= |s| <= 1000，|s| 表示字符个数）。
s 的每个字符都是可打印 ASCII 字符，可能包含空格，首尾也可能有空格，甚至可能全部由空格组成；s 中不含制表符。

## 输出格式
输出一行，为按要求逐字符修改后的字符串。输出长度必须与 |s| 相同，行末输出一个换行符。不得输出任何额外文字或第二行。

本题答案唯一：输出中的每个字符（包括空格）都必须与标准答案完全一致。

## 数据范围
- 字符串长度（1 <= |s| <= 1000）。
- 每个字符的 ASCII 码（32 <= code <= 126），即可打印 ASCII 字符，包括空格。

## 样例
样例 1
输入：
SyuctOJ 04: AbZ-z!
输出：
sYUCToj 04: aBz-Z!
解释：S 变为 s，y 变为 Y，其余英文字母同样互换大小写；空格、数字 0 和 4、冒号、连字符及感叹号都保持不变。

样例 2
输入（开头和结尾各有 2 个空格，中间 1 个空格）：
"  Hello World  "
输出（同样共有 5 个空格，位置不变）：
"  hELLO wORLD  "

## 评测环境
C++17（gnu++17），时间限制 1000ms，内存限制 256MiB，标准输入/标准输出。
