• ## 1）任务与完整约束复述

  给定一个单测试用例的 \(n\times m\) 二维整数数组，需要分别计算

  \[
  S_j=\sum_{i=1}^{n}a_{i,j}\qquad(1\le j\le m)
  \]

  并按照第 1 列到第 \(m\) 列的顺序输出这 \(m\) 个列和。

  约束如下：

  - \(1\le n,m\le1000\)，二者可以不相等。
  - \(-10^9\le a_{i,j}\le10^9\)，元素可以是负数、零或重复值。
  - 每个最终列和的绝对值不超过 \(10^{12}\)，因此不能使用 32 位 `int` 保存答案。
  - 输入来自标准输入：第一行为 `n m`，随后为 \(n\) 行、每行 \(m\) 个整数。
  - 输出到标准输出：共 \(m\) 个整数，相邻整数用一个空格分隔，不输出提示语等其他内容。
  - Judge 按整数 token 逐一比较，数值、顺序或 token 数量错误均判错；空白差异不影响判定。
  - 没有多解、浮点误差、交互或多测试用例。
  - 使用 GNU C++17，资源限制为 1000 ms、256 MiB。

  ## 2）算法

  不需要保存整个二维数组，可以边读边累加：

  1. 读取 \(n,m\)。
  2. 建立长度为 \(m\) 的 `long long` 数组 `sum`，全部初始化为 0。
  3. 按输入顺序逐行读取元素。读到第 \(i\) 行第 \(j\) 列的元素 \(x\) 时，执行 `sum[j] += x`。
  4. 所有元素读取完毕后，依次输出 `sum[0]` 到 `sum[m-1]`。

  `long long` 足以保存结果：实际上任意部分和的绝对值也不超过 \(1000\times10^9=10^{12}\)，远在 64 位整数范围内。

  ## 3）逐步正确性证明

  使用循环不变量证明。

  **不变量：** 处理完前 \(r\) 行后，对于每一列 \(j\)，都有

  \[
  sum[j]=\sum_{i=1}^{r}a_{i,j}.
  \]

  1. **初始成立：** 尚未处理任何行时，\(r=0\)。所有 `sum[j]` 均为 0，而空和也为 0。
  2. **每行处理后保持：** 假设处理完前 \(r\) 行后不变量成立。处理第 \(r+1\) 行时，程序对每列 \(j\) 恰好读取并加上 \(a_{r+1,j}\)，因此
     \[
     sum[j]\leftarrow\sum_{i=1}^{r}a_{i,j}+a_{r+1,j}
     =\sum_{i=1}^{r+1}a_{i,j}.
     \]
     所以处理完第 \(r+1\) 行后不变量仍成立。
  3. **全部处理完毕：** 当 \(r=n\) 时，由不变量可知 `sum[j]` 正好等于第 \(j\) 列所有元素之和。
  4. **输出正确：** 程序按下标 \(0,1,\ldots,m-1\) 各输出一次，对应第 \(1,2,\ldots,m\) 列，恰好输出 \(m\) 个整数，顺序与题目要求一致。

  因此程序输出的整数序列与唯一官方答案完全一致。

  ## 4）时间与额外空间复杂度

  - **时间复杂度：** \(\Theta(nm)\)。需要读取并处理全部 \(nm\) 个元素，输出 \(m\) 个答案；因为 \(n\ge1\)，输出开销不增加复杂度。最多处理 \(10^6\) 个元素。
  - **额外空间复杂度：** \(\Theta(m)\)。只保存 \(m\) 个列和，不保存整个数组；当 \(m=1000\) 时，列和数组约占 8 KB。

  ## 5）边界条件、常见风险与重点验证用例

  常见风险：

  - 使用 `int` 累加，导致列和溢出。
  - 误以为 \(n=m\)，或在非方形数组中交换行、列循环次数。
  - 按行求和，或按错误顺序输出列和。
  - 多输出、少输出答案，或输出提示文字。
  - 保存整个数组并非必要；流式累加即可。

  建议重点验证：

  - 公开样例 1：应输出 `3 6 -1 13`。
  - 公开样例 2：应输出 `-7`。
  - 非方形数组，例如：
    ```text
    2 3
    1 2 3
    4 5 6
    ```
    应输出 `5 7 9`。
  - 32 位整数溢出边界，例如一列包含三个 \(10^9\)，答案应为 `3000000000`；三个 \(-10^9\) 时答案应为 `-3000000000`。
  - \(n=1000\) 且某列全部为 \(10^9\) 或 \(-10^9\)，答案分别为 \(10^{12}\) 和 \(-10^{12}\)。
  - \(n=1,m=1000\)、\(n=1000,m=1\)、\(n=m=1000\)，检查循环边界和非方形处理。
  - 全零、正负抵消、负数与重复值混合的情况。

  仅假设输入符合题面且标准输入读取成功；在此前提下，上述算法没有未证明之处。

  ## 6）完整可编译的 C++17 程序

  ```cpp
  #include <iostream>
  #include <vector>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      int n, m;
      std::cin >> n >> m;

      std::vector<long long> sum(m, 0);

      for (int i = 0; i < n; ++i) {
          for (int j = 0; j < m; ++j) {
              long long value;
              std::cin >> value;
              sum[j] += value;
          }
      }

      for (int j = 0; j < m; ++j) {
          if (j > 0) {
              std::cout << ' ';
          }
          std::cout << sum[j];
      }
      std::cout << '\n';

      return 0;
  }
  ```
