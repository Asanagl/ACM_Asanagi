# 矩阵加法

给定两个 n 行 m 列的整数矩阵 A 和 B，请计算并输出它们的和矩阵 C。矩阵下标从 1 开始，C 的第 i 行第 j 列元素 c[i][j] 定义为 A、B 在同一位置上的两个元素之和：
    c[i][j] = a[i][j] + b[i][j]   (1 <= i <= n, 1 <= j <= m)

## 输入格式

输入只有一组测试数据。

第一行包含两个正整数 n, m（1 <= n, m <= 300），用一个空格分隔，分别表示矩阵的行数和列数。

接下来 n 行，每行 m 个整数，描述矩阵 A：其中第 i 行第 j 个数是 a[i][j]（-10^6 <= a[i][j] <= 10^6）。

再接下来 n 行，每行 m 个整数，描述矩阵 B：其中第 i 行第 j 个数是 b[i][j]（-10^6 <= b[i][j] <= 10^6）。

矩阵 A 的全部元素写完之后才开始给出矩阵 B。同一行内相邻整数之间恰好有一个空格，每行末尾没有多余空格，整份输入以换行结束。

## 输出格式

输出 n 行，每行 m 个整数，描述矩阵 C：第 i 行第 j 个数是 c[i][j] = a[i][j] + b[i][j]。

同一行内相邻整数之间恰好用一个空格分隔，每行末尾不要输出多余空格。不要输出 n, m，也不要输出任何提示文字。

本题的答案是唯一的：每个 c[i][j] 只由 a[i][j] + b[i][j] 决定，不存在多种合法输出。评测时会按顺序把这 n*m 个整数与标准答案逐个比较，缺少、增加或调换整数都判为错误。

## 数据范围

- 1 <= n, m <= 300。
- -10^6 <= a[i][j] <= 10^6，-10^6 <= b[i][j] <= 10^6（1 <= i <= n, 1 <= j <= m）。
- 因为两个加数都在 [-10^6, 10^6] 内，所以每个答案都落在 [-2*10^6, 2*10^6] 内，32 位有符号 int 足够存放。

## 样例 1

输入：
2 3
1 -2 3
4 5 -6
-1 2 -3
7 -8 9

输出：
0 0 0
11 -3 3

逐位置相加：
- 第一行：1 + (-1) = 0，(-2) + 2 = 0，3 + (-3) = 0；
- 第二行：4 + 7 = 11，5 + (-8) = -3，(-6) + 9 = 3。

## 说明

- A 和 B 是两个先后给出的完整矩阵，不是按行交替给出。
- n 与 m 可以相等，也可以不相等。
- 结果元素允许是 0 或负数。
