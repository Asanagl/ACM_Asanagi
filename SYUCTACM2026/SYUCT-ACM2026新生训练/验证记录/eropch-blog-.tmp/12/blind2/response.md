• ## 1. 任务复述

  **输入**：只有一组测试数据。

  - 第一行两个正整数 `n, m`（`1 ≤ n, m ≤ 300`），用一个空格分隔，表示行数与列数。
  - 随后 `n` 行、每行 `m` 个整数，按行优先（先第 1 行从左到右，再第 2 行……）完整给出矩阵 `A`，元素满足 `-10^6 ≤ a[i][j] ≤ 10^6`。
  - `A` 全部写完之后，再以同样的格式给出 `n` 行、每行 `m` 个整数的矩阵 `B`，元素同样在 `[-10^6, 10^6]`。
  - 行内相邻整数恰好一个空格，行末无多余空格，整份输入以换行结束。

  **输出**：`n` 行，每行 `m` 个整数，第 `i` 行第 `j` 个数为 `c[i][j] = a[i][j] + b[i][j]`。行内相邻整数恰好一个空格分隔，行末无多余空格；不输出 `n, m`，不输出任何提示文字。评测按行优先顺序逐个读入 `n*m` 个整数与标准答案比对，个数必须恰好为 `n*m`，缺失、多余、顺序错误均判错（行内/行间用空格还是换行分隔不影响判定）。

  **数据范围**：`1 ≤ n, m ≤ 300`；`-10^6 ≤ a[i][j], b[i][j] ≤ 10^6`（`1 ≤ i ≤ n, 1 ≤ j ≤ m`）。

  **答案范围**：每个 `c[i][j] ∈ [-2·10^6, 2·10^6]`，32 位有符号 `int` 足够。

  ## 2. 算法

  核心观察：`A` 与 `B` 都以**相同的行优先顺序**给出，且输出也要求行优先顺序。因此把二维下标压平成一维：位置 `k`（从 0 开始）对应矩阵元素 `(i, j) = (k / m + 1, k % m + 1)`，`A` 和 `B` 的第 `k` 个输入值属于同一个格子，可以直接按 `k` 对齐相加。

  伪代码：

  ```
  读入 n, m
  total = n * m
  申请数组 a[0 .. total-1]           // 存矩阵 A，压平存放
  for k = 0 .. total-1:
      读入 a[k]                       // 此时读到的是 A 的第 k 个元素
  for k = 0 .. total-1:
      读入 b                          // 此时读到的是 B 的第 k 个元素
      a[k] = a[k] + b                 // 原地写入 C 的第 k 个元素
  for i = 0 .. n-1:
      for j = 0 .. m-1:
          if j > 0: 输出一个空格
          输出 a[i*m + j]
      输出一个换行
  ```

  因为 `B` 的读入顺序与 `A` 完全一致，不需要先存下 `B` 再相加；边读 `B` 边累加到 `a` 上是安全的。

  ## 3. 逐步正确性证明

  **引理 1（下标对应）**：设 `k ∈ [0, n*m)`，令 `i = k / m + 1`，`j = k % m + 1`。按题面的输入格式，`A` 的第 `k` 个输入整数恰为 `a[i][j]`，`B` 的第 `k` 个输入整数恰为 `b[i][j]`。因为 `B` 是在 `A` 全部 `n*m` 个元素之后才给出的，且同样是「`n` 行、每行 `m` 个、行优先」，所以两组数据在同一下标 `k` 上指向同一格子。

  *证明*：输入描述明确指出 A 的 `n` 行按行优先依次给出、每行 `m` 个；A 写完后 B 以完全相同的结构给出。行优先序列的第 `k` 项正是 `(k/m + 1, k%m + 1)` 位置的元素。

  **引理 2（读入阶段结束后数组内容正确）**：第一个循环结束后，对每个 `k` 有 `a[k] = a[i][j]`；第二个循环中第 `k` 次迭代读取的是 `b[i][j]`（由引理 1），执行 `a[k] += b` 后 `a[k] = a[i][j] + b[i][j] = c[i][j]`。归纳可见第二个循环结束时，对**所有** `k` 都有 `a[k] = c[i][j]`，且每个 `k` 恰好被赋值一次、不被覆盖错位。

  **引理 3（输出阶段正确）**：第三个双重循环按 `i = 1..n`、`j = 1..m` 的顺序输出 `a[i*m + j]`，由引理 2 该值为 `c[i][j]`，所以输出序列恰为
  `c[1][1], c[1][2], …, c[1][m], c[2][1], …, c[n][m]`，
  即行优先的全部 `n*m` 个答案，一个不多、一个不少、顺序正确。格式上，每个元素之间只在 `j > 0` 时输出一个空格，行末不输出空格，每行后输出一个换行，与输出格式要求一致。

  **定理（唯一正确性）**：对任意满足数据范围的合法输入，程序读入的每个元素都在 `int` 范围内，加法结果在 `[-2·10^6, 2·10^6]`（题面已给出）内不发生溢出，由引理 2、3 输出恰为题目定义的 `C`，且按行优先顺序给出全部 `n*m` 个整数、格式符合要求。由于 `c[i][j]` 完全由 `a[i][j] + b[i][j]` 唯一确定，且程序输出恰好是这 `n*m` 个值，故输出与标准答案逐项相等，判定为正确。

  ## 4. 复杂度

  - **时间复杂度**：`O(n*m)`。最多 `90 000` 次加法、`180 000` 次整数读入、`90 000` 次整数输出；即使使用较慢的 IO，也远低于 1 秒。
  - **额外空间**：`O(n*m)` 个 `int`，最大 `90 000 × 4 B = 360 KB`（原地累加，只需一个数组），加常数级变量；远低于 256 MiB。
  - **判定**：在 1 s / 256 MiB 下**非常安全**，有数个数量级的余量。

  ## 5. 边界情况

  | 用例 | 理由 |
  |---|---|
  | `n = m = 1` | 最小规模，检验循环边界、以及单个数字后不能多打空格或空行 |
  | `n = 1, m = 300` | 单行：只有 299 个行内空格、没有行间换行，检验换行逻辑不误加 |
  | `n = 300, m = 1` | 单列：每行只有一个数字，检验不会把各行合并、行末无空格 |
  | `n = m = 300` | 最大规模，检验不越界、性能与内存 |
  | 全 0 | 检验 `0` 的输出（不能是 `-0`、空串或浮点格式） |
  | 全为 `10^6`（两边都是） | 上界答案 `2 000 000`，检验 `int` 上界与不溢出 |
  | 全为 `-10^6`（两边都是） | 下界答案 `-2 000 000`，检验负数格式与无符号回绕 |
  | `10^6` 与 `-10^6` 配对 | 结果恰为 `0`，检验抵消时不出现 `-0` 或空输出 |
  | 正负混杂、结果有正有负 | 检验符号打印与逐元素独立处理 |
  | `n ≠ m`（如 `2×5`、`5×2`） | 题面明说 `n` 与 `m` 可不等，捕获把 `n`、`m` 写反或行列索引混用的错误 |
  | 恰好一组数据且以换行结束 | 检验不会多读一轮、不会因等待更多输入而卡住或重复输出 |
  | 样例 1 | 对照题面，验证逐位置相加与格式 |

  ## 6. 风险

  **题面/判题语义层面**

  - 判题语义说明「行内行间空白不敏感、但整数个数必须恰为 `n*m`」，所以多打一个换行不会错，**多打或少打一个整数一定错**；不要输出 `n m`、不要输出表头、调试信息或末尾多余数字。
  - 题面「输出 `n` 行、行末无多余空格」比判题器宽松；保险起见严格按题面输出（行末不加空格，每行一个换行），即使判题器更宽松也不会有副作用。
  - 题面保证「答案唯一」，不存在多解或特殊判定，无需考虑浮点误差、精度或 `special judge`。
  - 输入只有一组数据。用「读到 EOF 为止」的多组循环虽然本题只跑一轮，但如果把「读一组、输出一组」的逻辑写成循环体之外的重复输出，就会多输出一份矩阵而判错。

  **实现层面的典型错误**

  1. **交错读取**：误以为 A、B 是按行交替给出（读一行 A、读一行 B），这是题面明确排除的陷阱，会整体错位。
  2. **行列写反**：用 `m` 控制外层循环，导致 `n ≠ m` 时错乱。
  3. **数组越界/栈溢出**：在函数内定义 `int a[300][300]`（约 360 KB），再定义 `b[300][300]`，合计约 720 KB，接近部分环境 1 MB 的默认栈；应改为全局数组或 `std::vector`。
  4. **下标从 1 开始**：题面下标从 1 开始是数学描述，C++ 数组从 0 开始，混用会越界。
  5. **类型选择**：`short`/`char`/无符号类型会溢出；用 `int` 即可。`n*m` 最大 90 000，`int` 乘法不溢出，但用 `size_t` 更稳妥。
  6. **格式化输出**：用 `printf("%d")` 与 `int` 匹配，不要用 `%u`、`%ld` 等不匹配的格式说明符（未定义行为）。
  7. **按行字符串解析**：若用 `getline` 再手工 `split`，Windows 风格 CRLF 的 `\r` 可能残留在最后一个数字上导致解析失败；用 `>>` 或 `scanf("%d")` 自动跳过任意空白最稳妥。
  8. **忘记换行**：最后一行后是否换行通常不影响判定，但按题面加一个 `\n` 最规范。
  9. **性能误区**：本题规模极小，无需卡常；即使 `cin/cout` 不加 `sync_with_stdio(false)` 也能通过，不必为此引入复杂优化。

  ## 7. 完整 C++17 实现

  ```cpp
  #include <cstddef>
  #include <cstdio>
  #include <vector>

  int main() {
      int n = 0, m = 0;
      if (std::scanf("%d %d", &n, &m) != 2) return 0;

      const std::size_t total =
          static_cast<std::size_t>(n) * static_cast<std::size_t>(m);
      const std::size_t cols = static_cast<std::size_t>(m);

      std::vector<int> a(total);

      // 读入矩阵 A（行优先）
      for (std::size_t k = 0; k < total; ++k) {
          if (std::scanf("%d", &a[k]) != 1) return 0;
      }

      // 读入矩阵 B（同样的行优先顺序），原地累加得到 C
      for (std::size_t k = 0; k < total; ++k) {
          int b = 0;
          if (std::scanf("%d", &b) != 1) return 0;
          a[k] += b;
      }

      // 按行优先输出 n 行、每行 m 个整数，行内单空格、行末无空格
      for (int i = 0; i < n; ++i) {
          for (int j = 0; j < m; ++j) {
              if (j > 0) std::putchar(' ');
              const std::size_t idx =
                  static_cast<std::size_t>(i) * cols + static_cast<std::size_t>(j);
              std::printf("%d", a[idx]);
          }
          std::putchar('\n');
      }

      return 0;
  }
  ```

  对样例 1 的验证：`A` 读入为 `1 -2 3 4 5 -6`，与 `B` 的 `-1 2 -3 7 -8 9` 逐项相加得到 `0 0 0 11 -3 3`，按 `2` 行 `3` 列输出即

  ```
  0 0 0
  11 -3 3
  ```

  与题面输出完全一致，且恰好 `6` 个整数 token、无多余空格、无多余文字。
