# 矩阵加法

给定两个 $n$ 行 $m$ 列的整数矩阵 $A$ 和 $B$，请计算它们的和 $C=A+B$：结果矩阵 $C$ 的第 $i$ 行第 $j$ 列元素为 c_ij = a_ij + b_ij。

## 输入格式

第一行输入两个正整数 n, m（1 <= n, m <= 300）。

接下来 n 行，每行 m 个整数，表示矩阵 A；其中第 i 行第 j 个数为 a_ij（-10^6 <= a_ij <= 10^6）。

再接下来 n 行，每行 m 个整数，表示矩阵 B；其中第 i 行第 j 个数为 b_ij（-10^6 <= b_ij <= 10^6）。

## 输出格式

输出 n 行，每行 m 个整数，表示矩阵 C；第 i 行第 j 个数为 c_ij = a_ij + b_ij。每行内相邻整数之间用一个空格分隔。

本题答案唯一。题目保证每个输出元素都满足 -2*10^6 <= c_ij <= 2*10^6，可以用 32 位有符号整数表示。

## 数据范围

- 1 <= n, m <= 300。
- -10^6 <= a_ij, b_ij <= 10^6。
- -2*10^6 <= c_ij <= 2*10^6。

## 样例 1

输入
2 3
1 -2 3
4 5 -6
-1 2 -3
7 -8 9

输出
0 0 0
11 -3 3

第一行：1+(-1)=0，-2+2=0，3+(-3)=0；第二行：4+7=11，5+(-8)=-3，-6+9=3。
