• ## 1. 任务复述

  输入只有一组数据：

  - 第一行为两个正整数 \(n,m\)，满足 \(1\le n,m\le 300\)。
  - 接下来 \(n\) 行输入矩阵 \(A\)，每行 \(m\) 个整数；第 \(i\) 行第 \(j\) 列为 \(a_{i,j}\)。
  - 再接下来 \(n\) 行输入矩阵 \(B\)，格式相同，其元素为 \(b_{i,j}\)。
  - 对所有位置均有
    \[
    -10^6\le a_{i,j},b_{i,j}\le 10^6.
    \]

  需要输出矩阵 \(C=A+B\)，其中
  \[
  c_{i,j}=a_{i,j}+b_{i,j}\qquad(1\le i\le n,\ 1\le j\le m).
  \]

  输出共 \(n\) 行，每行恰好 \(m\) 个整数，同一行相邻整数之间用一个空格分隔。题目保证
  \[
  -2\times10^6\le c_{i,j}\le 2\times10^6,
  \]
  因此每个结果都能用 32 位有符号整数表示。每个位置的结果都由对应加法唯一确定。

  ## 2. 算法

  采用直接逐元素相加：

  1. 读入 \(n,m\)，用一个大小为 \(n\times m\) 的数组保存矩阵 \(A\)。
  2. 按输入顺序读入 \(A\) 的全部元素，将 \(a_{i,j}\) 保存到对应位置。
  3. 按行优先顺序依次读入 \(B\) 的每个元素 \(b_{i,j}\)。
  4. 每读入一个 \(b_{i,j}\)，立即计算已保存的 \(a_{i,j}\) 与它之和，并输出到第 \(i\) 行第 \(j\) 列。
  5. 每行输出 \(m\) 个结果后换行。

  无需保存完整的 \(B\) 或 \(C\)。

  ## 3. 逐步正确性证明

  设算法保存的 \(A\) 中对应第 \(i\) 行第 \(j\) 列的值为 \(S_{i,j}\)。

  1. **矩阵 \(A\) 保存正确。**  
     输入中 \(A\) 按行优先顺序给出，算法也使用相同的行、列循环顺序读取。因此读完 \(A\) 后，对任意 \(i,j\)，都有 \(S_{i,j}=a_{i,j}\)。

  2. **矩阵 \(B\) 的对应关系正确。**  
     合法输入中，\(A\) 的全部元素之后依次是 \(B\) 的全部元素，同样按行优先排列。算法读完 \(A\) 后，以相同顺序执行读取 \(B\) 的循环，所以处理第 \(i\) 行第 \(j\) 列时，读到的下一个整数恰好是 \(b_{i,j}\)，不会错位或遗漏。

  3. **每个输出的数值正确。**  
     算法在该位置输出
     \[
     S_{i,j}+b_{i,j}=a_{i,j}+b_{i,j}=c_{i,j}.
     \]
     题目保证该结果处于 32 位有符号整数范围内，因此计算不会发生整数溢出。

  4. **每个位置恰好输出一次。**  
     外层循环枚举全部 \(n\) 行，内层循环枚举每行的全部 \(m\) 列，总共执行 \(nm\) 次。每个有序位置 \((i,j)\) 恰好出现一次，因此所有 \(c_{i,j}\) 都被输出，且没有多余数字。

  5. **输出顺序和格式正确。**  
     算法按行优先顺序输出，每行输出 \(m\) 个整数，仅在同行相邻整数之间输出一个空格，并在每行结束后换行。因此输出正好是题目要求的 \(n\) 行、每行 \(m\) 个整数。

  综上，算法对任意合法输入都会终止，并输出唯一正确的矩阵 \(C\)。

  ## 4. 复杂度

  令 \(N=nm\)，则 \(N\le 300\times300=90000\)。

  - **时间复杂度：** \(\Theta(nm)\)。  
    共读取 \(2N\) 个矩阵元素，执行 \(N\) 次加法并输出 \(N\) 个整数，每个元素只被常数次处理。
  - **额外空间复杂度：** \(\Theta(nm)\)。  
    只保存矩阵 \(A\)；矩阵 \(B\) 的元素逐个读取，其他变量只使用常数空间。

  按每个整数占 4 字节计算，保存 \(A\) 最多需要
  \[
  4\times90000=360000\text{ 字节}\approx0.35\text{ MiB},
  \]
  加上很小的固定开销，远低于 256 MiB。最多只需进行 18 万次矩阵元素输入和 9 万次结果输出，使用关闭同步的 C++ 标准流后，对 1000 ms 时限非常安全。

  ## 5. 边界情况

  - **最小规模 \(n=m=1\)：** 检查单行单列、无需行间或列间分隔符的情况。
  - **数值极值：** 分别测试 \(10^6+10^6=2\times10^6\)、\((-10^6)+(-10^6)=-2\times10^6\)，以及 \(10^6+(-10^6)=0\)，检查上下界、负号和整数范围。
  - **最大规模 \(n=m=300\)：** 检查 90000 个结果是否全部输出，同时验证时间、内存和输出数量。
  - **单行与单列：** 测试 \(n=1,m=300\) 和 \(n=300,m=1\)，检查换行位置及行、列循环边界。
  - **非方形矩阵：** 测试如 \(2\times3\)、\(3\times2\) 的数据，防止误将 \(n,m\) 当作相同值或交换行列。
  - **正负数与零混合：** 覆盖正加正、负加负、正加负、与零相加，检查结果符号及取消为普通十进制整数。
  - **各位置取值明显不同的小型数据：** 让 \(A,B\) 不使用对称或全相同元素，以发现下标错位、错误地把 \(A\) 和 \(B\) 交替读取等问题。
  - **输出格式检查：** 对上述用例确认总共恰有 \(nm\) 个数字，每行恰有 \(m\) 个数字，没有调试信息、多余数字或遗漏。

  ## 6. 风险

  题面对合法输入的定义没有实质歧义，主要实现风险如下：

  - **输入分块顺序：** 必须先读完整个 \(A\)，再读整个 \(B\)；不能误认为 \(A\) 和 \(B\) 的行交替出现。
  - **数据组数：** 题面只有一组数据，不应自行增加多组数据循环或测试组数 \(T\)。
  - **行列不一定相等：** \(n\) 和 \(m\) 是独立维度，数组下标和循环不能混用。
  - **判题按数字逐个比较：** 行首行尾空白虽不敏感，但多余或缺失数字会判错；不能输出提示语、调试信息或额外结果。
  - **空白处理：** 虽然判题对某些空白不敏感，实现仍应直接满足规定格式，不必依赖 trailing space 等容差。
  - **整数范围：** 使用 32 位有符号 `int` 即可；不能使用更小整数类型。结果保证在范围内，直接相加即可，不需要也不应进行截断、取模或饱和处理。
  - **无需处理非法输入：** 元素数量不足、维度越界等情况不属于题面保证的合法输入，不应为此改变正常算法。

  ## 7. 完整 C++17 实现

  ```cpp
  #include <iostream>
  #include <vector>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      int n, m;
      std::cin >> n >> m;

      std::vector<int> a(n * m);

      for (int i = 0; i < n; ++i) {
          for (int j = 0; j < m; ++j) {
              std::cin >> a[i * m + j];
          }
      }

      for (int i = 0; i < n; ++i) {
          for (int j = 0; j < m; ++j) {
              int b;
              std::cin >> b;

              if (j > 0) {
                  std::cout << ' ';
              }
              std::cout << a[i * m + j] + b;
          }
          std::cout << '\n';
      }

      return 0;
  }
  ```
