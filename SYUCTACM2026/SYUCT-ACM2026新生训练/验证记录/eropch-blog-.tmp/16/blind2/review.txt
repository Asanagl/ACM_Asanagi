• ## 1. 任务与完整约束（独立复述）

  给定一个 n×n 的整数方阵（行、列均从 1 开始编号），分别求：

  - 主对角线之和：所有满足「行号 = 列号」的元素 a[1,1], a[2,2], …, a[n,n] 之和；
  - 副对角线之和：所有满足「行号 + 列号 = n+1」的元素 a[1,n], a[2,n-1], …, a[n,1] 之和。

  输入：第一行是整数 n（1 ≤ n ≤ 200）；随后 n 行，每行 n 个整数，行内以空格分隔，第 i 行给出 a[i,1..n]。元素范围 −10⁹ ≤ a[i,j] ≤ 10⁹，允许负数和零，允许重复值。

  输出：恰好两行，第一行主对角线之和，第二行副对角线之和。顺序固定，不可交换、不可增减数字；两数之间的空白可以是空格、制表符或换行。

  关键语义：当 n 为奇数时，中心元素 a[m,m]（m = (n+1)/2）同时属于两条对角线，**必须各计一次**，不做任何去重或扣除（样例 1 中 5 被加了两次，正是如此）。两答案绝对值不超过 200 × 10⁹ = 2×10¹⁴，可用 64 位有符号整数承载。

  ## 2. 算法

  流式读入，不存储矩阵。在 0-based 下标下，把题面的 1-based 下标 (i₁, j₁) 映射为 (i, j) = (i₁−1, j₁−1)：

  - 主对角线条件 i₁ = j₁ ⇔ `j == i`；
  - 副对角线条件 i₁ + j₁ = n+1 ⇔ (i+1) + (j+1) = n+1 ⇔ `j == n-1-i`。

  循环结构：

  ```
  s1 = s2 = 0
  for i = 0 .. n-1:            // 第 i 行（对应题面第 i+1 行）
      for j = 0 .. n-1:        // 行内第 j 个 token（对应题面第 j+1 列）
          read x
          if (j == i)         s1 += x    // 主对角线
          if (j == n-1-i)     s2 += x    // 副对角线
  输出 s1 换行 s2
  ```

  要点：行内 token 按列自然顺序到达，因此 `j` 就是列下标，与读入顺序一一对应；两条对角线的判断是两个**彼此独立**的 `if`（不是 `else if`），这样 n 为奇数时中心位置在一行内会同时命中两个条件，被两个累加器各加一次。

  ## 3. 正确性证明

  记目标值 S₁ = Σ_{i=1..n} a[i,i]，S₂ = Σ_{i=1..n} a[i,n+1−i]。题面以显式求和式定义二者，故答案 (S₁,S₂) 存在且唯一。

  **引理 1（主对角线累加正确）**：处理完前 k 行后，`s1 = Σ_{i=1..k} a[i,i]`（k=0 时为空和 0）。
  证明（对 k 归纳）：k=0 显然。设处理完 k−1 行成立。第 k 行内，`j` 从 0 遍历到 n−1，各列恰好被访问一次；`j == i`（i = k−1，即题面行号 k）当且仅当该 token 是行内第 k 个，即列号 k 的元素 a[k,k]，条件恰好对这一个元素成立，其余元素不贡献。故 `s1` 恰好增加 a[k,k]，归纳成立。取 k=n 得 `s1 = S₁`。

  **引理 2（副对角线累加正确）**：处理完前 k 行后，`s2 = Σ_{i=1..k} a[i,n+1−i]`。
  证明：同上归纳。第 k 行内 `j == n-1-i`（i = k−1）等价于列号 n+1−k；因 1 ≤ k ≤ n，有 1 ≤ n+1−k ≤ n，该列在行内存在且唯一，故本行恰好有一个元素被加入，且正是 a[k, n+1−k]。取 k=n 得 `s2 = S₂`。

  **引理 3（中心元素各计一次）**：若 n 为奇数，令 m = (n+1)/2（0-based 为 i = m−1）。在第 m 行内，该元素所在列 j = m−1 同时满足 `j == i` 与 `j == n-1-i`（因为 n−1−(m−1) = n−m = m−1）。由于是两个独立判断，它被加入 `s1` 一次、加入 `s2` 一次，合计在两条对角线中各出现一次，未去重也未漏算。若 n 为偶数，两条件不可能在同一行同时成立（m−1 = n−m 无整数解），故无公共元素，符合题面。

  **定理**：程序输出的第一个数等于 `s1` 的终值 = S₁（引理 1），第二个数等于 `s2` 的终值 = S₂（引理 2），顺序与题面要求一致，两数各占一行、不缺不多。而 (S₁,S₂) 是题面定义的唯一答案，故算法输出等于目标答案。

  ## 4. 复杂度

  - 时间：O(n²)，恰好读入 n² 个整数、做 n² 次常数判断与 O(n) 次加法；n ≤ 200 时为 4×10⁴ 次读入，远低于 1000ms。
  - 额外空间：O(1)（只用了 n、两个 64 位累加器和一个临时变量，不存储矩阵），远低于 256MiB。

  ## 5. 边界情况、常见错误、假设

  边界与易错点：

  - **n = 1**：i=0, j=0，`j==i` 与 `j==n-1-i=0` 同时成立，两个和都等于该元素（样例 3）。
  - **n 为奇数**：中心元素必须被两条对角线各算一次；写成 `else if` 会漏掉一次，写成「去重」逻辑会少加一次，二者都错。
  - **n 为偶数**：两条对角线无公共元素，独立 `if` 也不会误加。
  - **溢出**：必须用 `long long`（题面最大值 2×10¹⁴ 超出 32 位 int 约 2.1×10⁹）；读入也要读进 `long long`，否则单个 −10⁹ 尚可但累加必溢出。`long long` 上限约 9.22×10¹⁸，安全。
  - **下标错位**：副对角线写成 `n - i`（0-based）会越界/错位，正确是 `n - 1 - i`；对应 1-based 是 `n + 1 - i`。
  - **输出顺序**：先主后副，交换即错；用两行输出满足「空白可为换行」的规则。
  - **读入方式**：用 `cin >>` 逐 token 读取，不依赖行边界，天然容忍任意空白分布；关闭同步以加速。
  - **负数与零**：不加任何绝对值或取模处理。
  - **未初始化累加器**：必须初始化为 0。

  假设：输入严格符合题面（n 合法、恰好 n² 个整数、无多余数据需要校验）；n ≥ 1，无需处理 n ≤ 0；结果在 64 位内（题面已保证）。代码对读入失败做了温和返回，不影响合法输入的判定。

  ## 6. 参考代码（gnu++17，独立可编译）

  ```cpp
  #include <iostream>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      int n;
      if (!(std::cin >> n)) return 0;

      long long s1 = 0;   // 主对角线之和
      long long s2 = 0;   // 副对角线之和

      for (int i = 0; i < n; ++i) {
          for (int j = 0; j < n; ++j) {
              long long x;
              std::cin >> x;
              if (j == i)         s1 += x;   // 主对角线：列 == 行
              if (j == n - 1 - i) s2 += x;   // 副对角线：列 == n-1-行
              // 两个 if 相互独立：n 为奇数时中心元素在此被两条对角线各计一次
          }
      }

      std::cout << s1 << '\n' << s2 << '\n';
      return 0;
  }
  ```

  自检结论：下标 `j == i` 与 `j == n-1-i` 在 i,j ∈ [0, n−1] 内恒合法，不会越界；求和全程 `long long`，最大 2×10¹⁴ 无溢出；n 为奇数时中心元素由两个独立 `if` 各加一次；n=1 时两和均为唯一元素本身，输出两行相同值。样例 1 得 `-3` / `15`，样例 2 得 `3` / `5`，样例 3 得 `-1000000000` / `-1000000000`。
