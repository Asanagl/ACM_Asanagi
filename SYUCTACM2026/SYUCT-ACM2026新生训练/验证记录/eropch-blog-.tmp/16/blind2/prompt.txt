# 两条对角线

给定一个 n 行 n 列的整数方阵，请分别计算它的主对角线元素之和与副对角线元素之和。

方阵的行从 1 到 n 自上而下编号，列从 1 到 n 自左向右编号。主对角线由所有满足「行号等于列号」的元素组成，即 a[1,1], a[2,2], ..., a[n,n]；副对角线由所有满足「行号加列号等于 n+1」的元素组成，即 a[1,n], a[2,n-1], ..., a[n,1]。

当 n 为奇数时，两条对角线共享正中心的那个元素。这个中心元素应当分别计入两条对角线的和：它在主对角线上出现一次，在副对角线上也出现一次，不要因为它在两条对角线里都出现而做任何去重或扣除。

## 输入格式

第一行输入一个整数 n（1 <= n <= 200），表示方阵的行数与列数。

接下来 n 行，第 i 行输入 n 个整数 a[i,1], a[i,2], ..., a[i,n]（-10^9 <= a[i,j] <= 10^9），表示方阵第 i 行的第 1 到第 n 个元素。同一行内相邻的两个整数之间用一个空格分隔。

## 输出格式

输出两行，每行一个整数：
- 第一行输出主对角线元素之和；
- 第二行输出副对角线元素之和。

两个和分别独立计算，并且都包含中心元素（如果它存在）。本题答案唯一，评测器依次读取这两个整数并与唯一答案比较；两个整数之间的空白字符可以是空格、制表符或换行，但不得缺少、增加或交换这两个数。

## 数据范围

- 1 <= n <= 200；
- -10^9 <= a[i,j] <= 10^9；
- 元素可以是负数、零或正数，不同位置的元素允许相同；
- 两个答案都可以用有符号 64 位整数表示（最坏情况下绝对值不超过 200 * 10^9 = 2 * 10^14）。

## 样例

样例 1 输入：
3
1 -2 3
4 5 6
7 8 -9

样例 1 输出：
-3
15

解释：主对角线元素是 1, 5, -9，和为 -3；副对角线元素是 3, 5, 7，和为 15。中心元素 5 在两条对角线里各算一次。

样例 2 输入：
2
-1 2
3 4

样例 2 输出：
3
5

解释：n=2 时主对角线元素是 -1, 4，和为 3；副对角线元素是 2, 3，和为 5。此时两条对角线没有公共元素。

样例 3 输入：
1
-1000000000

样例 3 输出：
-1000000000
-1000000000

解释：n=1 时方阵只有一个元素，它同时是主对角线元素和副对角线元素，因此两个答案都等于这个元素本身。

## 说明

- 主对角线上第 i 行的元素是 a[i,i]，副对角线上第 i 行的元素是 a[i,n+1-i]。
- 两行的输出顺序固定：先主对角线之和，后副对角线之和；交换顺序会被判为错误。
- 答案可能为负数，注意使用能存放 64 位整数的类型求和。
