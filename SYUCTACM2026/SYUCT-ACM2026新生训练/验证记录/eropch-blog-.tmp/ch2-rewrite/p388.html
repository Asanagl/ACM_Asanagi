幸运UID

Description

一款跨时代游戏即将开服，小K学长认为6个位置上的数字之和可以刚好被他的幸运数字n整除的UID会给他带来幸运

请问，6位数字的UID中，有多少个UID是小K学长的幸运UID呢？

Format

Input

输入一个整型数字n(1<=n<=100)

Output

输出6位UID中有多少个小K学长的幸运UID

Samples

55

0

1

999999

Hint

UID的编号是从1开始的哦
