小明的口袋

Description

小明有一个质数口袋，里面可以装各个质数。他从 222 开始，依次判断各个自然数是不是质数，如果是质数就会把这个数字装入口袋。

口袋的负载量就是口袋里的所有数字之和。

但是口袋的承重量有限，装的质数的和不能超过 LLL。给出 LLL，请问口袋里能装下几个质数？将这些质数从小往大输出，然后输出最多能装下的质数的个数，数字之间用换行隔开。

Format

Input

一行一个正整数 LLL。1≤L≤1051 \le L \le {10}^51≤L≤105。

Output

将这些质数从小往大输出，然后输出最多能装下的质数个数，所有数字之间有一空行。
