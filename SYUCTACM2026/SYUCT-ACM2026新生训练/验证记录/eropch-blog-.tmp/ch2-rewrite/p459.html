数字翻转

Description

12翻一下是21，34翻一下是43，12+34是46，46翻一下是64，现在有任意两个正整数，问他们两个数反转的和是否等于两个数的和的反转。

Format

Input

输入包含多组测试数据,当a,b都为0时输入结束

每组数据占一行，包含两个整数a(1<a<10000)a(1 < a < 10000)a(1<a<10000)和b(1<b<10000) b(1 <b <10000)b(1<b<10000)

Output

每组数据输出一行一个结果，如果 a+ba+ba+b的反转的和等于 a+ba+ba+b的和的反转，则输出 a+ba+ba+b，否则输出NO。

Samples

12 34
99 1
0 0

46
NO
