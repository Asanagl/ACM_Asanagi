#P0725. 水仙花数

    ID: 97 传统题 1000ms 256MiB 尝试: 409 已通过: 204 难度: 5 上传者: zine 标签>SYUCT枚举

水仙花数

Description

输出100 ～ 999 中的所有水仙花数. 若 3 位数 ABC 满足 ABC = A3A^3A3+ B3B^3B3+ C3C^3C3,则称这个数为水仙花数.例如153 = 131^313 + 535^353 + 333^333 ,所以 153 是水仙花数.

Format

Input

该题没有输入

Output

输出所有的水仙花数,每个水仙花数独占一行.

Samples

无

370
371
407
