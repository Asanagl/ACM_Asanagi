• ## 1. 任务与规格复述

  **任务**：给定一个只含小写英文字母的非空字符串 $s$，判定它是否为回文串（正读与反读完全相同），输出唯一答案 `YES` / `NO`。

  **输入格式**：仅一行，一个字符串 $s$；长度 $|s|$ 满足 $1 \le |s| \le 100000$；字符集为 `a`–`z`；不含空格、制表符等任何空白字符；不会是空串；只有这一组数据，没有多测，也没有前导/尾随的多余内容。

  **输出格式**：一行，输出 `YES`（是回文）或 `NO`（不是回文）。按 Judge 语义：评测程序取输出中**第一个空白分隔的单词**，它必须恰好是大写 `YES` 或 `NO`，且与唯一正确答案一致；该单词之后不得再出现任何非空白内容；行末空白不计。因此最稳妥的输出就是单个单词加一个换行。

  **约束汇总**：$1 \le |s| \le 100000$；字符均为 `a`–`z`；单组数据；时间 1000 ms，内存 256 MiB，语言标准 gnu++17，仅标准库。

  **样例**：`a`→YES；`ababa`→YES；`abba`→YES；`abcab`→NO；`abxbba`→NO（最外层两对相同，仅最内层 `x`/`b` 不同，必须检查到最内层才能定论）。

  ## 2. 算法（双指针向中间收缩）

  设 $n=|s|$，使用 0 起始下标。回文的定义等价于：对所有 $0 \le k \le n-1$，都有 $s[k] = s[n-1-k]$。只需把 $k$ 限制在前半部分比较即可（后半部分是对称重复的）。

  步骤：

  1. 读入 $s$（按空白分隔的单词读入），令 $n = |s|$（$n \ge 1$）。
  2. 令 `l = 0`，`r = n - 1`，布尔量 `ok = true`。
  3. 当 `l < r` 时循环：
     - 若 `s[l] != s[r]`，令 `ok = false` 并跳出循环；
     - 否则 `++l`，`--r`。
  4. 输出 `ok ? "YES" : "NO"` 加换行。

  关键不变量：循环中始终有 `r = n - 1 - l`，所以每次比较的正是镜像位置对 $(l, n-1-l)$；当 `l >= r` 时，所有配对都已检查完毕（奇数长度时中心字符不与任何字符配对）。

  C++17 核心代码：

  ```cpp
  int n = (int)s.size();
  int l = 0, r = n - 1;
  bool ok = true;
  while (l < r) {
      if (s[l] != s[r]) { ok = false; break; }
      ++l; --r;
  }
  std::cout << (ok ? "YES" : "NO") << '\n';
  ```

  ## 3. 正确性证明

  **约定**：$s$ 是回文串 $\iff$ 对所有 $0\le k\le n-1$ 有 $s[k]=s[n-1-k]$。这是题面定义的直接形式化（“从左到右读和从右到左读完全相同”）。

  **引理 1（下标不变式）**：在第 $t$ 次循环开始时（$t=0$ 为进入循环前），`l = t` 且 `r = n-1-t`。
  *证明*：$t=0$ 时 `l=0`，`r=n-1=n-1-0`，成立。若第 $t$ 次迭代未跳出，则执行 `++l; --r`，于是第 $t+1$ 次开始时 `l=t+1`、`r=(n-1-t)-1=n-1-(t+1)`，成立。归纳完毕。∎

  **引理 2（不提前退出则前缀配对全等）**：若循环执行了 $t$ 次且从未跳出，则对所有 $0\le k<t$ 有 $s[k]=s[n-1-k]$。
  *证明*：对 $t$ 归纳。$t=0$ 时空真。第 $t$ 次迭代（下标从 0 计）比较了 $s[t]$ 与 $s[n-1-t]$（引理 1），未跳出意味着二者相等；结合归纳假设即覆盖 $0\le k\le t$。∎

  **引理 3（终止性）**：循环必然终止，且至多执行 $\lceil n/2 \rceil$ 次。
  *证明*：每次迭代 `l` 严格加一、`r` 严格减一，两者之差 `r-l` 每轮减少 2，初始为 $n-1$，故至多 $\lceil (n-1+1)/2\rceil = \lceil n/2\rceil$ 次后 `l >= r`。∎

  **定理（输出正确）**：算法输出 `NO` 当且仅当 $s$ 不是回文串。

  （⇒，输出 `NO` 的正确性）设算法在第 $t$ 次迭代跳出，则 $s[t] \ne s[n-1-t]$，且由循环条件 $t < n-1-t$ 知 $0 \le t \le n-1$、镜像位置合法且 $t \ne n-1-t$。取 $k=t$ 即违反回文定义，故 $s$ 不是回文串。∎

  （⇐，输出 `YES` 的正确性）设循环正常结束（`l >= r`）而未跳出，执行了 $t$ 次迭代。由引理 2，对所有 $k<t$ 有 $s[k]=s[n-1-k]$。任取 $0\le k\le n-1$，分三种情况：

  - 若 $k<t$：由引理 2 直接得 $s[k]=s[n-1-k]$。
  - 若 $n-1-k<t$：对下标 $n-1-k$ 用引理 2 得 $s[n-1-k]=s[n-1-(n-1-k)]=s[k]$，结论相同。
  - 否则 $k\ge t$ 且 $n-1-k\ge t$。由 $n-1-k\ge t$ 得 $k \le n-1-t$，而由引理 1 及终止条件 `l >= r` 有 $t = l \ge r = n-1-t$，故 $n-1-t \le t$，于是 $t \le k \le n-1-t \le t$，即 $k = t = n-1-t$。此时 $s[k]=s[n-1-k]$ 是同一位置与自身相等，平凡成立（这正对应奇数长度的中心字符）。

  三种情况穷尽全部 $k$，故 $s$ 满足回文定义。∎

  综合：输出 `NO` ⟺ 非回文，输出 `YES` ⟺ 回文，二者互斥且穷尽，与题面的唯一答案一致。另外注意偶数长度时 `l` 与 `r` 会交错（不重合），奇数长度时二者在中心重合后立即退出，中心字符从不与异位字符比较——这与“中心字符无配对对象”的语义一致。

  ## 4. 复杂度

  - **时间**：$O(n)$。每次迭代做一次字符比较并把区间长度减 2，最多 $\lceil n/2\rceil \le 50000$ 次迭代；加上读入 $O(n)$。$n\le 10^5$ 时远低于 1000 ms。
  - **空间**：$O(n)$ 用于存储输入字符串（不超过 $10^5$ 字节）；**额外辅助空间 $O(1)$**（两个下标加一个布尔量）。总计远低于 256 MiB。

  ## 5. 边界情况与高风险用例清单

  | # | 类别 | 输入（注意无引号、无空格） | 期望输出 | 考察点 |
  |---|---|---|---|---|
  | 1 | 长度为 1（最小值） | `a` | YES | 循环体零次执行，必须直接判 YES；`n-1=0` 不能让下标越界 |
  | 2 | 长度为 1，边界字母 | `z` | YES | 字符集端点 |
  | 3 | 长度 2，相同 | `aa` | YES | 最外层即最内层 |
  | 4 | 长度 2，不同 | `ab` | NO | `l=0<r=1` 比较后立即失败 |
  | 5 | 偶数长度，回文 | `abba` | YES | 样例 3；`l`/`r` 交错退出（`l=2>r=1`） |
  | 6 | 偶数长度，非回文 | `abca` | NO | 首尾相同但内层不同，不能只看外层 |
  | 7 | 奇数长度，回文 | `ababa` | YES | 样例 2；中心 `l=r` 退出，中心不参与比较 |
  | 8 | 奇数长度，非回文 | `abcab` | NO | 样例 4；第一对即失败 |
  | 9 | 奇数长度，仅最内层一对不同 | `aabca` | NO | 外层 `a`/`a` 相同、内层 `a`/`c` 不同，必须走到第 2 轮 |
  | 10 | 偶数长度，仅最内层一对不同 | `abxbba` | NO | 样例 5（强样例），`x` vs `b` |
  | 11 | 整串同一字符，长度上限 | 100000 个 `a` | YES | 最坏时间：无早期失败，需比较 50000 对，且验证不会因“全部相同”而误判 |
  | 12 | 长度上限，奇数 | 99999 个 `a` | YES | 奇数上界 + 中心重合退出 |
  | 13 | 长度上限，由 `X+reverse(X)` 构造（$|X|=50000$） | 长度 100000 | YES | 长回文、跨中点的镜像一致性 |
  | 14 | 长度上限，错配在正中心 | 49999 个 `a` + `b` + 50000 个 `a`（长 100000） | NO | 最坏时间的 NO：49999 轮后才失败，压测 1000 ms 与无越界 |
  | 15 | 首对即不同（超长） | `a` + 99998 个 `a` + `b`（长 100000） | NO | 早期退出路径；也验证首尾比较没错位 |
  | 16 | 输入带 CRLF 行尾 | `abba\r\n` | YES | 用 `cin >> s` 时 `\r` 被当作空白跳过；若用 `getline` 会把 `\r` 计入串长而误判 NO（高风险陷阱） |
  | 17 | 文件末尾无换行 | `abba`（EOF 紧跟） | YES | 不能依赖“一定读到换行” |
  | 18 | 仅中间一字符是分界 | `aba` | YES | 最短的“奇数 + 中心无关”用例 |

  YES 类（1、2、3、5、7、11、12、13、16、17、18）与 NO 类（4、6、8、9、10、14、15）均已覆盖；长度 1、偶数、奇数、整串同字符、仅最内层不同、长度上限也全部覆盖。

  ## 6. 题面歧义、误读风险与评测语义争议

  1. **输出必须是单个单词**。“第一个空白分隔的单词”配合“该单词之后不得再出现其他非空白内容”，实际效果是：整个输出中只能有一个非空白 token。写成 `YES.`、`yes`、`YES 1`、`YES\nNO` 全部错误；输出多个空行虽符合描述但无必要。最保险就是 `YES\n` / `NO\n`。
  2. **大小写敏感**。题面明确“全大写”，小写 `yes` 视为错误答案，不存在大小写不敏感的解释空间。
  3. **行尾空白不计**，所以 `YES ` 或 `YES\r\n` 都安全；但若实现把 `\r` 读进字符串，会污染**输入**而非输出，可能把 `abba\r`（长度为 5）判成 NO —— 这是最容易被忽视的误读风险，必须用按空白分词的读入方式（`cin >> s`）或显式去掉 `\r`。
  4. **“输入只有这一行”**容易被误读为“必须用 `getline` 读整行”。题面已保证串内无任何空白，用 `cin >> s` 语义等价且更鲁棒；用 `getline` 反而引入 `\r` 风险。
  5. **空串语义被排除**。数学上常把空串视为回文，容易写出形如“`n==0` 时输出 NO”的分支；题面保证 $|s|\ge1$，该分支不可达，但若要保留，输出 YES 更符合惯例——不过更简单的做法是根本不为它写分支。
  6. **奇数长度的中心字符**：题面明确“没有配对对象”。若实现写成 `while (l <= r)` 并照常比较 `s[l]` 与 `s[r]`，在 `l==r` 时是自我比较，结果仍正确，只是多做一次无意义比较——这不算错，但须确保不会因此写出 `r = n-1-l` 之外的错位下标。
  7. **“答案唯一”**：本题判定是确定的（非 YES 即 NO），不存在多解或并列，因此上面第 1 条的 token 规则不会有二义性。
  8. **潜在评测争议**：若评测实现改为逐行严格比较，则多余空白可能被判错。本解只输出一个单词加换行，在两种口径下都安全。
  9. **时间限制 1000 ms**：$n=10^5$ 的 $O(n)$ 比较毫无压力，真正的风险只来自 I/O（`cin >> s` 已足够快；加 `sync_with_stdio(false)` 更稳），不存在需要哈希或 `std::reverse` 的技术点。

  ## 7. 完整 C++17 程序

  ```cpp
  #include <iostream>
  #include <string>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      std::string s;
      if (!(std::cin >> s)) {
          return 0;  // 题面保证非空输入，此分支不可达
      }

      const int n = static_cast<int>(s.size());
      int l = 0;
      int r = n - 1;
      bool ok = true;

      while (l < r) {
          if (s[l] != s[r]) {
              ok = false;
              break;
          }
          ++l;
          --r;
      }

      std::cout << (ok ? "YES" : "NO") << '\n';
      return 0;
  }
  ```

  ## 8. 假设、无法证明之处与实现风险

  **假设**：输入严格满足题面（单行、非空、仅 `a`–`z`、无内嵌空白、长度不超过 $10^5$）；评测按题面所述“取第一个空白分隔 token，大小写敏感、不得有后续非空白内容”执行。

  **依赖题面但无法自行验证的部分**：测试数据的实际行尾符（LF/CRLF）、文件末尾是否有换行、判题器是否为 token 级比较。这些都不影响本程序：`cin >> s` 对 `\r` 和缺失行尾换行均免疫；输出只有 `YES`/`NO` 加一个换行，在最严格的逐行口径下也合规。

  **实现风险**：均已被规避或影响可忽略。

  - 下标用 `int`，$n \le 10^5$，不会溢出；不使用 `size_t`，避免 `r--` 到 $-1$ 的无符号回绕。
  - `n-1` 在 $n=1$ 时为 0，循环条件 `0 < 0` 为假，无越界。
  - `cin >> s` 在“串内无空白”的前提下与整行读入等价；若题面被违反（串内出现空格），它会静默截断——属于规格外输入，不视为缺陷。
  - 读入失败分支仅作防御，不影响任何合法输入，也永不输出非法 token。

  其余无。
