# 回文判断

如果一个字符串正着读和反着读完全相同，就称它是**回文串**。例如，`abba` 和 `ababa` 是回文串，而 `abcab` 不是。

请判断给定的字符串是否为回文串。

## 输入格式

输入一行一个字符串 $s$（$1\le |s|\le 100000$），其中 $|s|$ 表示字符串长度。

$s$ 仅由小写英文字母 `a` 到 `z` 组成，保证不是空串。

## 输出格式

输出一行一个字符串：如果 $s$ 是回文串，输出 `YES`；否则输出 `NO`。

答案唯一，必须使用大写字母，不输出其他内容。

## 样例 1

### 输入

~~~text
ababa
~~~

### 输出

~~~text
YES
~~~

首尾字符相同，继续向中间比较，第二对字符也相同，正中间的字符不需要配对。

## 样例 2

### 输入

~~~text
abba
~~~

### 输出

~~~text
YES
~~~

字符串长度为偶数，所有字符都能两两配对，且每一对字符都相同。

## 样例 3

### 输入

~~~text
abcab
~~~

### 输出

~~~text
NO
~~~

首字符是 `a`，尾字符是 `b`，二者不同，所以该字符串不是回文串。

## 提示

可以令左下标指向字符串开头、右下标指向字符串结尾。每次比较两个下标处的字符，然后让两个下标同时向中间移动，直到它们相遇或交错。
