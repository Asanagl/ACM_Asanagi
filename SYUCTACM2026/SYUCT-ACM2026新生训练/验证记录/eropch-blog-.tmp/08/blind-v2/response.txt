  ## 一、任务与约束复述

  - 输入：两个非空的小写字母串 `s`、`t`；`1 ≤ |s| ≤ 100000`，`1 ≤ |t| ≤ |s|`。两行各一个串，行内无空白，行末换行不属于串内容。
  - 求：满足 `s[i..i+|t|-1] == t` 的最小下标 `i`（`0 ≤ i ≤ |s|-|t|`，下标从 0 起）。
  - 输出：该最小 `i`；若不存在则输出 `-1`。只输出这一个整数。
  - 出现可重叠（`s=aaaaa, t=aaa` 的答案是 `0`，而非若干次出现中的别的值）。
  - 资源与判定要求：gnu++17 编译，1000 ms，256 MiB；答案唯一。

  关键点：找的是**最左**出现，不是最右，也不是计数；需要考虑 `t == s`、`t` 是前缀、`t` 只在末尾出现、完全不出现这几种形态。

  ## 二、算法与正确性证明

  ### 2.1 算法选择

  朴素双重循环在本题最坏情况下不可接受：取 `s = a^100000`、`t = a^49999 + "b"`（`|t| = 50000`），每个起点都要比较约 5 万次才失败，共约 2.5×10⁹ 次字符比较，1000 ms 内无法完成。因此采用 **KMP（前缀函数）**，最坏线性。

  ### 2.2 定义

  对串 `x`，记 `π[i]` 为 `x[0..i]` 的**最长真前缀**长度 `k`（`0 ≤ k ≤ i`），满足 `x[0..k-1] == x[i-k+1..i]`；`k = 0` 恒可取。

  ### 2.3 步骤

  1. 读入 `s`、`t`，取 `n = |s|`、`m = |t|`。
  2. 在 `t` 上自左向右计算 `π[0..m-1]`：`π[0] = 0`；对 `i = 1..m-1`，令 `k = π[i-1]`，当 `k > 0 && t[i] != t[k]` 时令 `k = π[k-1]`；若 `t[i] == t[k]` 则 `++k`；置 `π[i] = k`。
  3. 在 `s` 上扫描：维护 `k` 表示"当前已与 `t` 前缀匹配的长度"，初值 0。对 `i = 0..n-1`：当 `k > 0 && s[i] != t[k]` 时令 `k = π[k-1]`；若 `s[i] == t[k]` 则 `++k`；一旦 `k == m`，立即输出 `i - m + 1` 并结束程序。
  4. 扫描结束仍未命中，输出 `-1`。

  **为什么"立即返回"就得到最左解**：命中发生在 `i` 处，意味着 `t` 是 `s[0..i]` 的后缀，即出现起点为 `i-m+1`。`i` 是自小到大枚举的，故第一个命中的 `i` 给出最小的起点。

  ### 2.4 正确性证明

  **引理 1（前缀函数递推正确）**：算法算出的 `π[i]` 等于定义值。

  *证*：设 `i ≥ 1`。若 `k > 0` 是 `t[0..i]` 的 border（真前缀兼后缀）长度，则去掉最后一个字符后，`k-1` 是 `t[0..i-1]` 的 border 长度，且 `t[i] == t[k-1]`（这里用 0 起下标写法：`t[i] == t[k]`，其中 `k` 为延伸后的长度减一前的候选）。反之，若 `k'` 是 `t[0..i-1]` 的 border 长度且 `t[i] == t[k']`，则 `k'+1` 是 `t[0..i]` 的 border 长度。于是
  `π[i] = 1 + max{ k' : k' 是 t[0..i-1] 的 border 长度且 t[i] == t[k'] }`（无可取者时为 0）。
  而 `t[0..i-1]` 的全部 border 长度恰为递降链 `π[i-1], π[π[i-1]-1], π[π[π[i-1]-1]-1], …`（这是 border 的基本性质：任何 border 的 border 仍是 border，且该链穷尽所有 border 长度）。`while` 循环正是沿此链从大到小枚举，遇到第一个可延伸者即停，故取到的正是最大值，`π[i]` 正确。∎

  **引理 2（扫描不变量）**：在第 `i` 轮循环开始前，`k = K_i := max{ L : 0 ≤ L ≤ m, t[0..L-1] == s[i-L..i-1] }`（`L = 0` 恒可行；由于一达 `m` 就返回，循环内恒有 `k ≤ m-1`，故 `t[k]` 访问合法）。

  *证（对 `i` 归纳）*：`i = 0` 时为空串后缀，`K_0 = 0`，成立。设第 `i` 轮开始前 `k = K_i`。结束于 `i` 的候选长度 `L ≥ 1` 满足：`t[0..L-2]` 是 `s[0..i-1]` 的后缀（即 `L-1` 属于可行集合，故 `L-1 ≤ K_i`），且 `t[L-1] == s[i]`。又因 `t[0..K_i-1]` 也是 `s[0..i-1]` 的后缀，所以"`L-1` 是 `s[0..i-1]` 的后缀且是 `t` 的前缀"等价于"`L-1` 是 `t[0..K_i-1]` 的 border 长度"，即候选恰为链 `K_i, π[K_i-1], π[π[K_i-1]-1], …`。`while` 沿链递降、取第一个可延伸者，所得即最大值 `K_{i+1}`。∎

  **定理（输出正确）**：
  - 若 `t` 在 `s` 中出现在起点 `p`，则该次出现结束于 `i = p+m-1`。此时 `t` 是 `s[0..i]` 的后缀，且任何 `t` 的前缀长度不超过 `m`，故由引理 2，第 `i` 轮结束时 `k = m`，程序必在该轮返回，返回值为 `i-m+1 = p`。
  - 反之若程序在某轮返回，由引理 2 得 `k = m` 即 `t == s[i-m+1..i]`，确为一次真实出现。
  - 由于 `i` 单调递增、且首个命中即返回，返回的起点是所有出现起点中的最小值；若扫描完 `n` 个位置都没有 `k == m`，则任何结束位置都没有出现，`t` 不是 `s` 的子串，输出 `-1` 正确。∎

  `s`、`t` 长度相同时（`m == n`）上述论证无变化：唯一可能的起点是 `0`，扫描到 `i = n-1` 时 `k` 要么是 `m` 要么小于 `m`，分别给出 `0` 或 `-1`。

  ## 三、复杂度

  - **时间**：前缀函数阶段 `O(m)`——每次循环 `k` 至多 +1，`while` 每轮至少让 `k` 减 1，总下降次数不超过总上升次数，摊还线性；扫描阶段同理 `O(n)`。合计 `O(n+m)`，即 `n, m ≤ 10⁵` 时约 2×10⁵ 次量级操作，远低于 1000 ms。
  - **额外空间**：`π` 数组 `O(m)`，最大 100000 个 `int` ≈ 400 KB；存串本身 `O(n+m)` ≈ 200 KB。合计远小于 256 MiB。无递归，无栈风险。

  ## 四、边界条件、实现风险与高风险用例

  **必须覆盖的边界**

  1. `|s| = |t| = 1` 且相等 → `0`（`π` 长度为 1，循环体不执行，需保证不越界）。
  2. `|s| = |t|` 但不等 → `-1`（不能读到 `s` 之外）。
  3. `t` 恰是 `s`（如 `s = t = "abc"`）→ `0`。
  4. `t` 只出现在末尾：`s = "xxabc"`, `t = "abc"` → `2`。
  5. 完全不存在：`s = "aaaa"`, `t = "aab"` → `-1`。
  6. 重叠出现：`s = "aaaaa"`, `t = "aa"` → `0`（不能返回 `3`，也不能计数）。
  7. `|t| = 1`：`s = "ba"`, `t = "a"` → `1`。
  8. 首次出现恰在 `i = 0` 与恰在 `i = n-m` 两端。
  9. 周期串导致大量失配回溯：`s = a^100000`, `t = a^99999` → `0`；`s = a^99999 + "b"`, `t = a^50000` → `-1`（此例是朴素算法的主要杀手）。
  10. 大小写、空格、空行：题面保证不会出现；代码用 `>>` 读入，天然跳过空白，对 `\r\n` 行尾也安全（`\r` 属于空白，会被吃掉），对末尾无换行同样安全。

  **实现风险**

  - **下标换算错误**：命中时起点是 `i - m + 1`，不是 `i`、不是 `i - m`。若用无符号类型计算，未命中分支下会下溢；本实现只在命中分支计算且用 `int`，安全。
  - **返回时机**：若命中后不立即返回而继续扫描，`k` 会变成 `m` 并访问 `t[m]`（越界）；要继续扫描必须先把 `k` 置为 `π[m-1]`。本实现直接返回，规避了该分支。
  - **`t[k]` 越界**：`while` 条件与 `if` 都要求此刻 `k ≤ m-1`，由"`k == m` 即返回"保证；改代码时务必保持这一不变式。
  - **读入方式**：若用 `getline` 且数据是 CRLF，`t` 会带一个 `'\r'`，长度和比较全错，进而答案错误。用 `cin >>` 或手动去 `\r`。
  - **输出格式**：只输出整数与一个换行，不加任何提示文字、不加多余空格。
  - **复杂度退化**：不要用朴素 `O(nm)`，也不要把 `std::string::find` / `strstr` 当作"必然线性"来论证——C++ 标准只规定语义、不规定复杂度，最坏情况视实现而定；KMP 是本题可严格保证的选择。
  - **实现细节**：只用 `<iostream>/<string>/<vector>`，避免 `bits/stdc++.h` 对编译器实现的依赖（虽在 gnu++17/GCC 下也可用）。
  - **快读**：`sync_with_stdio(false)` 后 cin 足够快，本题输入量仅 200 KB。

  **我认为风险最高的用例**（自测优先）

  - `s = "a"×100000`，`t = "a"×50000`：验证不越界、答案 `0`、耗时恒定。
  - `s = "a"×99999 + "b"`，`t = "a"×50000`：验证全串扫描 + 大量回溯仍为线性，输出 `-1`。
  - `s = "abababab"`, `t = "abab"`：重叠 + 前缀性质，答案 `0`；把 `s` 改成 `"bbababab"` 得 `2`。
  - `s = "abc"`, `t = "abc"` 与 `s = "abc"`, `t = "abd"`：等长两侧。
  - 输入用 CRLF 保存一份，确认答案不变。

  ## 五、完整程序（C++17，stdin/stdout）

  ```cpp
  #include <iostream>
  #include <string>
  #include <vector>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      std::string s, t;
      if (!(std::cin >> s >> t)) return 0;

      const int n = static_cast<int>(s.size());
      const int m = static_cast<int>(t.size());
      if (m > n) {                       // 题面保证不会发生，防御性处理
          std::cout << -1 << '\n';
          return 0;
      }

      // pi[i] = t[0..i] 的最长真前缀长度，且该前缀同时是后缀
      std::vector<int> pi(m, 0);
      for (int i = 1; i < m; ++i) {
          int k = pi[i - 1];
          while (k > 0 && t[i] != t[k]) k = pi[k - 1];
          if (t[i] == t[k]) ++k;
          pi[i] = k;
      }

      // k = 当前已匹配的 t 的前缀长度
      int k = 0;
      for (int i = 0; i < n; ++i) {
          while (k > 0 && s[i] != t[k]) k = pi[k - 1];
          if (s[i] == t[k]) ++k;
          if (k == m) {                  // 首次命中即最左出现，立即返回
              std::cout << (i - m + 1) << '\n';
              return 0;
          }
      }

      std::cout << -1 << '\n';
      return 0;
  }
  ```

  对样例的手工核对：样例 1 在 `i = 4` 命中，输出 `4-3+1 = 2`；样例 2 扫描完 `k` 未达 3，输出 `-1`；样例 3 在 `i = 2` 命中，输出 `0`。
