# 子串在哪里

给定两个仅由小写英文字母组成的字符串 $s$ 和 $t$，请求出 $t$ 在 $s$ 中**第一次**出现的位置。

具体地，如果存在整数 $i$（$0\le i\le |s|-|t|$）使得 $s$ 中从下标 $i$ 的字符开始、连续 $|t|$ 个字符按原顺序连起来恰好等于 $t$（字符串的字符下标从 $0$ 开始编号，第一个字符的下标是 $0$），则输出最小的这样的 $i$；如果不存在这样的 $i$，输出 `-1`。

匹配允许重叠：例如 $s=\texttt{aaaa}$、$t=\texttt{aa}$ 时，$t$ 从下标 $0$ 开始出现过，从下标 $1$ 开始也出现过，从下标 $2$ 开始还出现过，其中最小的是 $0$，所以答案是 $0$。

## 输入格式

输入共两行。

第一行一个字符串 $s$（$1\le |s|\le 100\,000$，仅由小写英文字母 `a` 到 `z` 组成，不含空格等任何空白字符）。

第二行一个字符串 $t$（$1\le |t|\le |s|$，仅由小写英文字母 `a` 到 `z` 组成，不含空格等任何空白字符）。

两行都非空，行末的换行符不属于字符串内容。

## 输出格式

输出一行一个整数，表示 $t$ 在 $s$ 中第一次出现的起始下标（下标从 $0$ 开始）；若 $t$ 不是 $s$ 的子串，则输出 `-1`。

对每组输入，符合要求的答案唯一确定，因此本题只有一个正确答案，请不要输出除这个整数以外的任何内容。

## 数据范围

- $1\le |s|\le 100\,000$。
- $1\le |t|\le |s|$。
- $s$ 与 $t$ 的每个字符都是小写英文字母 `a` 到 `z`。

## 样例

### 样例 1

输入：
```text
ababcabc
abc
```
输出：
```text
2
```
$t=\texttt{abc}$ 在 $s$ 中出现了两次：一次从下标 $2$ 开始（`abc`），一次从下标 $5$ 开始（`abc`）。第一次出现的下标是 $2$，所以输出 $2$。

### 样例 2

输入：
```text
aaaa
aab
```
输出：
```text
-1
```
$s$ 中所有长度为 $3$ 的连续片段只有 `aaa`，它不等于 `aab`，所以 $t$ 不是 $s$ 的子串，输出 `-1`。

### 样例 3

输入：
```text
aaaaa
aaa
```
输出：
```text
0
```
$t=\texttt{aaa}$ 从下标 $0$、$1$、$2$ 开始都能匹配（这些出现互相重叠），其中最小的是 $0$，所以输出 $0$。

## 说明

- 下标从 $0$ 开始编号，第一个字符的下标是 $0$，最后一个字符的下标是 $|s|-1$。
- 匹配允许重叠，要找的是**第一次**出现的位置，而不是最后一次，也不是出现的次数。
- 请注意 $t$ 与 $s$ 完全相等、$t$ 是 $s$ 的前缀、$t$ 只出现在 $s$ 的末尾、$t$ 根本不出现这几种情况。
