# 8. 子串在哪里

给定两个仅由小写英文字母组成的字符串 $s$ 和 $t$，请求出 $t$ 在 $s$ 中**第一次**出现的位置。

具体地，如果存在整数 $i$（$0\le i\le |s|-|t|$）使得 $s$ 中从第 $i$ 个字符开始的连续 $|t|$ 个字符恰好组成 $t$（字符下标从 $0$ 开始编号），则输出最小的这样的 $i$；如果不存在这样的 $i$，输出 `-1`。

注意匹配可以重叠：例如 $s=\texttt{aaaa}$，$t=\texttt{aa}$ 时，$t$ 既从位置 $0$ 也从位置 $1$、$2$ 开始出现，答案为 $0$。

## 输入格式

输入共两行。

第一行一个字符串 $s$（$1\le |s|\le 100\,000$），仅由小写英文字母组成。

第二行一个字符串 $t$（$1\le |t|\le |s|$），仅由小写英文字母组成。

## 输出格式

输出一个整数：$t$ 在 $s$ 中第一次出现的起始下标（下标从 $0$ 开始）；若 $t$ 不是 $s$ 的子串，输出 `-1`。

## 样例 1

输入：
```text
ababcabc
abc
```
输出：
```text
2
```
`t = abc` 在 `s` 中出现了两次：从位置 $2$ 开始的 `abc` 和从位置 $5$ 开始的 `abc`，第一次出现的位置是 $2$。

## 样例 2

输入：
```text
aaaa
aab
```
输出：
```text
-1
```
`s` 中所有长度为 $3$ 的子串只有 `aaa`，没有 `aab`，所以输出 `-1`。

补充 Judge 与资源语义：答案唯一；程序应恰好输出一个整数，匹配时为最小的 $0$ 起始下标，未匹配时为 `-1`，除此之外不输出解释文字。编译标准为 gnu++17，时间限制 1000 ms，内存限制 256 MiB。
