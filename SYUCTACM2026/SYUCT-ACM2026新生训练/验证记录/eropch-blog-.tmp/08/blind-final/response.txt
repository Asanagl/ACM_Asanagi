• # 盲审作答：子串在哪里

  ## 一、任务与约束的复述

  输入是两个非空、只含 `a`–`z` 的字符串 `s`、`t`，各占一行（行末换行不算内容）。记 `n = |s|`、`m = |t|`，约束为 `1 ≤ m ≤ n ≤ 10000`。

  要求找出**最小**的下标 `i`（`0 ≤ i ≤ n-m`），使得从 `s[i]` 开始连续取 `m` 个字符、按原顺序恰好等于 `t`。要点有三：下标从 0 起算；匹配可以互相重叠（如 `s=aaaa, t=aa` 的答案仍是 0，而不是“有多少处”）；只要**第一次**出现的位置，不是最后一次、也不是出现次数。若不存在这样的 `i`，输出 `-1`。

  输出必须是恰好一行、一个整数，不带任何解释性文字。除此之外没有别的要求。评测环境为 gnu++17、1000 ms、256 MiB，答案唯一。

  ## 二、算法

  采用 **KMP（Knuth–Morris–Pratt）**，线性时间，不依赖任何实现库的隐式行为。

  记号：`t[0..k-1]` 表示 `t` 的长度为 `k` 的前缀。

  **步骤 1：计算前缀函数。** 对 `0 ≤ i < m` 定义

  ```
  π[i] = max{ k : 0 ≤ k ≤ i 且 t[0..k-1] == t[i-k+1..i] }
  ```

  即 `t[0..i]` 的“最长真前缀且同时是后缀”的长度（`k = 0` 恒可行，保证有定义）。按下式递推：

  ```
  π[0] = 0
  对 i = 1..m-1:
      k = π[i-1]
      while k > 0 and t[i] != t[k]:  k = π[k-1]
      if t[i] == t[k]: ++k
      π[i] = k
  ```

  **步骤 2：扫描。** 维护 `j` = “当前已是 `s` 后缀的 `t` 的最长前缀长度”，初始 `j = 0`：

  ```
  对 i = 0..n-1:
      while j > 0 and s[i] != t[j]:  j = π[j-1]
      if s[i] == t[j]: ++j
      if j == m: 输出 i-m+1，结束
  输出 -1
  ```

  ### 正确性证明

  **引理 1（边界链）.** 设 `B(q)` 为 `t[0..q]` 的所有“长度 ≤ q 的、同时是前缀和后缀”的长度集合（即 `t[0..q]` 的所有边界长度，含 0）。则

  ```
  B(q) = {0} ∪ { π[q], π[π[q]-1], π[π[π[q]-1]-1], ... }
  ```

  *证明.* 设 `k ∈ B(q)`、`k > 0`。`t[0..k-1]` 是 `t[0..q]` 的真后缀，而 `t[0..π[q]-1]` 是最长真后缀，故任何长度不超过 `π[q]` 的真后缀都是它的后缀，于是 `t[0..k-1]` 是 `t[0..π[q]-1]` 的后缀；又它本身是前缀，所以 `k ∈ B(π[q]-1)`。反之链上每个值显然都是 `t[0..q]` 的边界。归纳即得全集相等。∎

  **引理 2（π 的正确性）.** 上述递推算出的 `π[i]` 等于定义值。
  *证明.* 对 `i` 归纳。设 `π[0..i-1]` 正确，`k = π[i-1]`。`t[0..i]` 的任一非零边界 `l` 满足：`l-1` 是 `t[0..i-1]` 的边界且 `t[l-1] == t[i]`。由引理 1 与归纳假设，`t[0..i-1]` 的边界恰是 `k` 沿 π 链的降序序列；`while` 循环正是按此降序逐个试 `t[k] == t[i]`，并在第一个成功处停下，因此得到的是**最大**的可扩展长度，即 `π[i]`。若链上全部失败（含 `k = 0` 且 `t[0] != t[i]`），最大边界为 0，与赋值一致。∎

  **引理 3（扫描不变式）.** 第 `i` 轮开始前，`j` 等于“使 `t[0..j-1]` 是 `s[0..i-1]` 后缀的最大 `j`”，且 `0 ≤ j < m`（`j = m` 时会立即返回，不会进入下一轮）。
  *证明.* `i = 0` 时 `s[0..-1]` 为空串，`j = 0` 正确。设进入第 `i` 轮时不变式成立，记 `S = { p : t[0..p-1] 是 s[0..i-1] 的后缀 }`，则 `max S = j`。`t[0..l-1]` 是 `s[0..i]` 的后缀当且仅当 `l = 0`，或者 `t[0..l-2] ∈ S` 且 `s[i] == t[l-1]`。故候选 `l` 为 `j+1` 与 `{b+1 : b ∈ B(j-1)}` 的并（`p ∈ S` 且 `p ≤ j` 时，`t[0..p-1]` 同时是 `t[0..j-1]` 的前缀与后缀，即 `p ∈ B(j-1)`；`p > j` 与极大性矛盾）。由引理 1，`B(j-1)` 正是 `π[j-1], π[π[j-1]-1], ...` 这条降序链。程序按 `j, π[j-1], π[π[j-1]-1], ...` 降序试探，取第一个满足 `s[i] == t[·]` 的候选，恰好得到新的最大值；全失败则得 0。不变式保持。∎

  **定理.** 程序输出即题目所要求的答案。
  *证明.* 由引理 3，第 `i` 轮结束后 `j = m` 当且仅当 `t` 是 `s[0..i]` 的后缀，即 `s[i-m+1..i] == t`，也就是在下标 `i-m+1` 处出现一次。由于 `i` 从 0 单调递增、且一旦成立立刻返回，首次返回的必是最小起始下标。若循环结束仍未返回，则任意 `i ∈ [0, n-1]` 都不满足，而任何出现位置的右端点必落在 `[m-1, n-1]` 内，故确实无解，输出 `-1` 正确。∎

  ## 三、复杂度

  - **时间**：计算前缀函数时，`k` 每轮至多 `+1`，而 `while` 每迭代一次 `k` 严格减小（`π[k-1] < k`），故回退总次数不超过增长总次数，为 `O(m)`。扫描同理：`j` 每轮至多 `+1`，回退使 `j` 严格减小，总回退次数 ≤ `n`，为 `O(n)`。合计 **O(n+m)**（摊还），最坏情况也是这个界，不存在 `O(nm)` 退化。
  - **额外空间**：`π` 数组 `O(m)`，计数器 `O(1)`。若计入输入本身，则另有 `O(n+m)` 的字符串存储。远低于 256 MiB。

  （题面下界很小，朴素双重循环最多约 `(n-m+1)·m ≤ 2.5×10^7` 次比较，其实也能过；但它有退化的最坏情况，且复杂度不如 KMP 干净，故只建议用朴素版做对拍。）

  ## 四、边界条件、实现风险与高风险用例

  **必须覆盖的边界**
  1. `m = n`：只有一个候选 `i = 0`；相等输出 0，否则 -1。
  2. `m = 1`：退化为字符查找，出现在末尾时答案为 `n-1`。
  3. 答案在下标 0（`t` 是 `s` 的前缀）与答案在 `n-m`（只出现在末尾）。
  4. 重叠出现，且必须取**最小**：`s=aaaaa, t=aaa → 0`，不能返回 2。
  5. 完全无解 → `-1`，包括“前缀全部相同、只差最后一个字符”这类情形。
  6. 单字符输入：`s=a, t=a → 0`；`s=a, t=b → -1`。

  **实现风险**
  - **行尾 `\r`**：若判题数据是 CRLF 而用 `getline` 读入，`t` 末尾会残留 `\r`，导致永不匹配。用 `cin >> s >> t` 可自动跳过所有空白（含 `\r`），本解法采用此方式规避。
  - **越界访问**：`t[j]` 中 `j` 可能等于 `m`，必须先判断 `j == m` 并返回，才能进入下一轮。代码中 `j == m` 分支立即 `return`，故 `t[j]` 始终有 `j < m`。
  - **下标算术**：结果写成 `i - m + 1`，用 `int` 即可（`n ≤ 10^4`）；混用 `size_t` 易在减法上出错。
  - **回退时漏掉 `j > 0` 保护**：会访问 `π[-1]`。
  - **输出格式**：不得打印提示语或样例说明；末尾单个换行是标准做法。
  - **防御性分支**：若输入违反题面（如 `m > n`、`m = 0`），代码仍给出确定输出而非崩溃，但题面不保证这类输入存在。

  **高风险用例（自拟）**

  | 输入 | 期望输出 | 考察点 |
  |---|---|---|
  | `a` / `a` | `0` | 最小规模 |
  | `a` / `b` | `-1` | 单字符失配 |
  | `ab` / `ab` | `0` | `m = n` 且相等 |
  | `abcabcabd` / `abcabd` | `3` | 部分匹配后回退再命中 |
  | `mississippi` / `issip` | `4` | 多处重叠、取最小 |
  | `baaa` / `aa` | `1` | 只在中后段出现 |
  | `abab` / `bab` | `1` | `π` 链回退 |
  | `a`×10000 / `a`×9999+`b` | `-1` | 朴素算法最坏，KMP 线性 |
  | `(ab)`×5000 / `(ab)`×2499+`aa` | `-1` | 周期串大量回退 |
  | `a`×10000 / `a`×5000 | `0` | 极长重复串 |

  ## 五、完整程序（C++17）

  ```cpp
  #include <iostream>
  #include <string>
  #include <vector>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      std::string s, t;
      if (!(std::cin >> s)) return 0;
      if (!(std::cin >> t)) {            // 题面保证不会发生
          std::cout << -1 << '\n';
          return 0;
      }

      const int n = static_cast<int>(s.size());
      const int m = static_cast<int>(t.size());

      if (m == 0) { std::cout << 0  << '\n'; return 0; }  // 防御分支
      if (m > n) { std::cout << -1 << '\n'; return 0; }   // 防御分支

      // 前缀函数
      std::vector<int> pi(m, 0);
      for (int i = 1; i < m; ++i) {
          int k = pi[i - 1];
          while (k > 0 && t[i] != t[k]) k = pi[k - 1];
          if (t[i] == t[k]) ++k;
          pi[i] = k;
      }

      // 扫描，返回第一处匹配
      int j = 0;
      for (int i = 0; i < n; ++i) {
          while (j > 0 && s[i] != t[j]) j = pi[j - 1];
          if (s[i] == t[j]) ++j;
          if (j == m) {
              std::cout << (i - m + 1) << '\n';
              return 0;
          }
      }

      std::cout << -1 << '\n';
      return 0;
  }
  ```

  样例核对（手工推演，未运行）：样例 1 在 `i = 4` 处首次 `j = 3`，输出 `4-3+1 = 2`；样例 2 中 `j` 始终到不了 3，输出 `-1`；样例 3 在 `i = 2` 处 `j = 3`，输出 `0`。

  ## 六、假设与无法证明之处

  1. **假设输入严格符合题面**：两行、非空、仅小写字母、`1 ≤ m ≤ n`。若违反（空串、含空格、`m > n`），代码走我加的防御分支给出确定输出，但题面并未规定此时应输出什么。
  2. **假设末尾单个换行被评测接受**：题目说“不要输出除这个整数以外的任何内容”，严格逐字节看换行也是额外字符；实践中所有 OJ 都接受，但我无法在此验证判题器细节。
  3. **复杂度是摊还界**：`O(n+m)` 对整体成立，但单轮迭代不是 `O(1)` 最坏；这一点在证明中已按摊还方式写出。
  4. **无法验证的部分**：本次为只读盲审，我没有运行、也没有查看任何代码或数据，因此正确性只来自上面的论证与手工样例推演，未经过编译与实测。若判题数据含题面未声明的字符集或格式（如大写字母、空行、字符串内空格），本解不保证正确。
  5. **设计取舍**：未使用 `std::string::find` 或 `std::search` 的 BMH 版本作为主解，因为标准未对 `basic_string::find` 的复杂度作硬性承诺，无法从题面材料推出其最坏情况性能；KMP 的界可以完整证明。
