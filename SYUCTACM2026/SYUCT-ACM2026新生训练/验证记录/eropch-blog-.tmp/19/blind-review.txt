• ## 1. 任务、输入输出与约束复述

  给定一个 \(n\) 行 \(m\) 列的整数矩阵 \(A\)，需要将它整体顺时针旋转 \(90^\circ\)，得到 \(m\) 行 \(n\) 列的矩阵 \(B\)，并输出 \(B\)。

  - 输入只有一组数据。
  - 第一行为 \(n,m\)，满足 \(1\le n,m\le 500\)。
  - 接下来 \(n\) 行，每行 \(m\) 个整数。
  - 元素范围为 \([-10^9,10^9]\)，包括负数。
  - 输出共 \(m\) 行，每行恰好 \(n\) 个整数，不输出说明文字等其他内容。
  - 必须真正移动元素，不能只交换 `n` 和 `m`，也不能把转置当作旋转。
  - 使用标准输入、标准输出，提交 GNU C++17 程序。

  按从 1 开始的下标，旋转关系为：

  \[
  B_{j,\;n-i+1}=A_{i,j}
  \]

  其中 \(1\le i\le n,\ 1\le j\le m\)。

  ## 2. 算法

  读入并保存原矩阵，然后按“原矩阵的列从左到右、每列从下到上”的顺序输出：

  1. 读入 \(n,m\)。
  2. 读入 \(n\times m\) 个元素，存入 `a`。
  3. 枚举原列 `j = 1 ... m`：
     - 依次输出 `a[n][j], a[n-1][j], ..., a[1][j]`。
     - 换行。
  4. 这样原第 `j` 列就成为旋转后的第 `j` 行，无需另外建立旋转后的矩阵。

  伪代码：

  ```text
  read n, m
  read a[1..n][1..m]

  for j = 1 to m:
      for i = n down to 1:
          output a[i][j]
      output newline
  ```

  ## 3. 逐步正确性证明

  **第一步：确定每个元素旋转后的位置。**

  原矩阵第 \(j\) 列在顺时针旋转后成为第 \(j\) 行；原矩阵中越靠下的元素，旋转后在该行中越靠左。原第 \(i\) 行从新行右侧数起的位置为 \(i\)，因此其新列号为 \(n-i+1\)。

  所以：

  \[
  B_{j,n-i+1}=A_{i,j}
  \]

  例如，\((1,1)\) 映射到 \((1,n)\)，即原左上角来到新右上角；\((n,1)\) 映射到 \((1,1)\)，即原左下角来到新左上角，符合题意。

  **第二步：确定旋转后每一行应输出的序列。**

  固定新矩阵的第 \(r\) 行。根据上述映射，它对应原矩阵的第 \(r\) 列，即 \(j=r\)。

  对于新列号 \(c\)，有：

  \[
  c=n-i+1
  \quad\Longrightarrow\quad
  i=n-c+1
  \]

  因此：

  \[
  B_{r,c}=A_{n-c+1,r}
  \]

  当 \(c=1,2,\ldots,n\) 时，新第 \(r\) 行依次为：

  \[
  A_{n,r},A_{n-1,r},\ldots,A_{1,r}
  \]

  也就是原第 \(r\) 列从下到上的元素。

  **第三步：证明算法输出的内容正确。**

  算法的外层循环依次枚举 \(r=1,\ldots,m\)，内层循环依次输出：

  \[
  A_{n,r},A_{n-1,r},\ldots,A_{1,r}
  \]

  由第二步，这正是旋转后矩阵的第 \(r\) 行。因此所有元素的位置都正确。

  **第四步：证明输出形状正确。**

  每个原元素恰好被访问并输出一次，共输出 \(nm\) 个整数。外层循环产生 \(m\) 行，内层循环每行产生 \(n\) 个整数，因此输出尺寸为 \(m\times n\)，符合要求。

  综上，算法正确。

  ## 4. 时间与额外空间复杂度

  - **时间复杂度：** \(O(nm)\)。读入和输出各处理 \(nm\) 个元素。
  - **空间复杂度：** \(O(nm)\)，用于保存原矩阵；没有另外创建旋转矩阵，其余辅助变量为 \(O(1)\)。
  - 最大元素数为 \(500\times500=250000\)。使用 `long long` 保存时，矩阵元素约占 \(2\) MB，远低于 256 MiB。

  ## 5. 边界条件、实现风险与重点测试

  ### 边界条件与常见风险

  - `n = m = 1`：旋转后仍是唯一元素。
  - `n = 1`：单行旋转成单列，元素顺序不变。
  - `m = 1`：单列旋转成单行，元素顺序反转。
  - 非方阵：必须分别使用原行数、原列数，避免越界或错误交换维度。
  - 顺时针旋转不是普通转置；每列还需要从下到上读取。
  - 倒序循环使用无符号类型时容易下溢，程序使用有符号 `int`。
  - 输出时避免同行元素间缺少空格，也不要输出提示语。
  - 本题元素可放入 32 位有符号整数，但使用 `long long` 保存同样正确。
  - 输入只有一组，不需要循环读到 EOF。

  ### 重点测试

  单行：

  ```text
  输入：
  1 4
  1 2 3 4

  输出：
  1
  2
  3
  4
  ```

  单列：

  ```text
  输入：
  4 1
  1
  2
  3
  4

  输出：
  4 3 2 1
  ```

  方阵，能够区分旋转与普通转置：

  ```text
  输入：
  3 3
  1 2 3
  4 5 6
  7 8 9

  输出：
  7 4 1
  8 5 2
  9 6 3
  ```

  极值：

  ```text
  输入：
  2 2
  -1000000000 1000000000
  1000000000 -1000000000

  输出：
  1000000000 -1000000000
  -1000000000 1000000000
  ```

  此外应验证题目两个样例，并用 \(500\times500\) 数据检查运行效率及输出总数是否为 250000 个整数。

  ## 6. 假设或无法证明之处

  没有额外的算法假设或未证明步骤。程序依赖题面保证输入合法且只有一组矩阵，因此不额外处理输入缺失、格式错误或多组数据。实际运行耗时与评测环境有关，但操作量严格为 \(O(nm)\)。

  ## 7. 完整 GNU C++17 程序

  ```cpp
  #include <bits/stdc++.h>
  using namespace std;

  int main() {
      ios::sync_with_stdio(false);
      cin.tie(nullptr);

      int n, m;
      cin >> n >> m;

      vector<vector<long long>> a(n, vector<long long>(m));

      for (int i = 0; i < n; ++i) {
          for (int j = 0; j < m; ++j) {
              cin >> a[i][j];
          }
      }

      for (int j = 0; j < m; ++j) {
          for (int i = n - 1; i >= 0; --i) {
              if (i != n - 1) {
                  cout << ' ';
              }
              cout << a[i][j];
          }
          cout << '\n';
      }

      return 0;
  }
  ```
