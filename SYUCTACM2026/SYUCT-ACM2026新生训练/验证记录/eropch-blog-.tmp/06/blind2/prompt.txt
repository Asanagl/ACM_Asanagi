# 反转字符串

给定一个非空字符串 s，请把它的字符顺序完全颠倒后输出。

也就是说，若 s = s_1 s_2 ... s_n（n = |s|），则答案 t = t_1 t_2 ... t_n 满足 t_i = s_{n+1-i}：原字符串的最后一个字符变成答案的第一个字符，原字符串的第一个字符变成答案的最后一个字符，其余字符依次按相反顺序排列。每个字符本身不改变，不删去重复字符，也不增加字符，因此答案与原字符串长度相同。

例如 s = abca12 时，n = 6，从右往左读出 2、1、a、c、b、a，答案为 21acba。

## 输入格式

输入只有一行，为一个字符串 s。s 中不含空格，行末（可能）有一个换行符。

## 输出格式

输出一行一个字符串，表示 s 的逆序字符串。输出中不要包含长度、提示文字或其他多余内容。

## 数据范围

- 字符串长度满足 1 <= |s| <= 1,000,000（|s| 表示字符串 s 的字符个数）。
- s 的每个字符都是小写英文字母 a 到 z 或数字 0 到 9，因此 s 中不含空格、标点和大写字母。
- 输入只有一组测试数据。

## 样例 1

输入：
abca12

输出：
21acba

解释：原字符串从右往左依次是 2、1、a、c、b、a，因此输出 21acba。两个 a 都必须保留，数字与字母之间不做任何转换。

## 样例 2

输入：
syuctacm2026

输出：
6202mcatcuys

解释：原字符串长度为 12；从右往左依次读出 6、2、0、2、m、c、a、t、c、u、y、s，得到 6202mcatcuys。数字 2 出现两次，c 也出现两次，反转后它们都各自保留，位置互换。
