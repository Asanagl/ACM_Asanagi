## 1. 任务复述

给定一个只含小写字母的字符串 `s`，以及两个整数 `l` 和 `r`。题目要求把 `s` 中第 `l` 位到第 `r` 位（按 1 开始的位置编号，包含两端）的这一段连续字符原样取出，输出这个子串。输出内容只能是小写字母组成的这一段字符，最后带一个换行。

## 2. 解题算法

由于题意就是把字符串看作 1 下标的一段区间，算法很直接：

1. 读入字符串 `s`。
2. 读入 `l` 和 `r`。
3. 把 1 下标转换为 C++ 字符串的 0 下标：
   - 区间起点为 `l - 1`；
   - 区间长度为 `r - l + 1`。
4. 输出 `s.substr(l - 1, r - l + 1)`，然后换行。

关键步骤只有一处：下标的正确转换。C++ 的 `substr(pos, count)` 中 `pos` 从 0 开始，`count` 是字符个数，因此必须用 `l - 1` 和 `r - l + 1`。

## 3. 正确性证明

设输入字符串为 `s`，长度为 `n`，满足 `1 <= l <= r <= n`。

- 题面中第 `l` 个字符对应 C++ 字符串下标 `l - 1`，因为题面从 1 开始编号，而 C++ 字符串从 0 开始编号。由 `l >= 1` 可知 `l - 1 >= 0`，由 `l <= n` 可知 `l - 1 <= n - 1`，因此起点合法。
- 区间 `[l, r]` 包含的字符个数是 `r - l + 1`。由 `r >= l` 可知这个数至少为 1；由 `r <= n` 和 `l >= 1` 可知 `r - l + 1 <= n`。
- 从 `s` 的下标 `l - 1` 开始连续取 `r - l + 1` 个字符，取到的下标依次是：

  `l - 1, l, ..., r - 1`

  这些下标正好对应题面中第 `l, l+1, ..., r` 个字符，顺序也完全保持一致。
- 因此 `s.substr(l - 1, r - l + 1)` 得到的字符串恰好是题目要求的子串。又因为正确答案唯一，算法输出与正确答案完全一致。

## 4. 复杂度分析

- 时间复杂度：`substr` 需要复制区间内的字符，共 `r - l + 1` 个字符，因此时间复杂度为 `O(r - l + 1)`，最坏为 `O(n)`。
- 空间复杂度：除输入字符串外，需要保存结果的子串，最坏为 `O(n)`；若不计输入和输出占用，额外空间为 `O(n)`，其中 `n <= 1000`，完全满足 256 MiB 限制。

## 5. 边界情况与潜在风险

- **最小输入 `n = 1`**：此时唯一的合法区间只能是 `l = r = 1`，应输出整个单字符。算法取 `substr(0, 1)`，正确。
- **单字符区间 `l = r`**：长度为 `r - l + 1 = 1`，应只输出一个字符。不能误写成 `r - l`，否则会输出空串。
- **整串 `l = 1` 且 `r = n`**：答案应为整个字符串。算法取 `substr(0, n)`，正确。
- **区间贴左端 `l = 1, r < n`**：起点为下标 0，长度为 `r`，输出前 `r` 个字符，正确。
- **区间贴右端 `l > 1, r = n`**：长度为 `n - l + 1`，取到字符串末尾，不能越界；`substr` 在计数不超过剩余长度时正常工作，本算法计数恰好为剩余长度，正确。
- **字符重复**：题目不要求去重，重复字符必须原样保留，`substr` 按位置截取，不会受字符内容影响。
- **`n` 达到上限 1000**：字符串很短，`substr` 最坏复制 1000 个字符，时间与空间都远低于限制。
- **输入读取风险**：`s` 只含小写字母且不含空白，用 `cin >> s` 读取即可；随后读取 `l`、`r`。不能把 `l`、`r` 读成字符类型。
- **输出风险**：评测忽略整体首尾空白，但输出中不能含有额外说明文字。程序只在最后输出换行，符合要求。
- **下标风险**：最容易出错的是把 1 下标直接当成 0 下标，或者把区间长度写成 `r - l`。

## 6. 完整 GNU C++17 实现

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    int l, r;
    cin >> s;
    cin >> l >> r;

    // 题面下标从 1 开始，C++ 字符串下标从 0 开始
    // 起点：l - 1；长度：r - l + 1
    cout << s.substr(l - 1, r - l + 1) << '\n';

    return 0;
}
```

### 与另外两种常见写法的等价性

1. **下标截取拼接**：例如先取出第 `l` 到第 `r` 个字符，逐个拼接到结果字符串中。它与 `substr(l - 1, r - l + 1)` 取的是同一段下标、同样的顺序，因此结果完全相同。
2. **逐字符循环**：从 `i = l - 1` 循环到 `i = r - 1`，每次把 `s[i]` 加入结果。循环次数为 `r - l + 1`，访问的下标正是目标区间，输出顺序与原字符串一致，因此也和 `substr` 写法等价。

三种写法在合法输入下都会输出同一个唯一正确的子串；本实现使用 `substr`，代码最短且下标转换集中在一处。
