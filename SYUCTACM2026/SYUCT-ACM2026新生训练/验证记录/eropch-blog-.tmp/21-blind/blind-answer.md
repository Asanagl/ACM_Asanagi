• # 四邻格统计 — 独立题解与评审

  以下内容完全基于上面给出的题面推导，未参考任何本地文件或其他实现。

  ## 1. 任务复述

  读入一个 \(n\times m\) 的 0/1 网格（每行一个不含空格的 `0`/`1` 字符串），输出同样 \(n\times m\) 形状的整数矩阵：第 \(i\) 行第 \(j\) 列写出格子 \((i,j)\) 的**上、下、左、右**四个邻居中值为 `1` 的个数。答案恒在 0..4，输出唯一。

  **被排除的方向**

  - 四个对角方向 \((i\pm1,j\pm1)\) 一律不计入，无论其值是多少。
  - 越出网格的上下左右方向不存在邻居，既不计数，也不会因为"越界"而把该方向当成 0 值格子去统计——它只是被跳过（效果上等价于贡献 0）。

  **邻居少于 4 的格子（逐类说清）**

  | 格子位置 | 实际邻居数 | 说明 |
  |---|---|---|
  | 内部格 \(2\le i\le n-1,\ 2\le j\le m-1\) | 4 | 唯一"满邻居"的情况 |
  | 四角（要求 \(n\ge2\) 且 \(m\ge2\)） | 2 | 如 \((1,1)\) 只有右、下 |
  | 上/下边界上的非角格（\(m\ge2\)） | 3 | 缺上或缺下 |
  | 左/右边界上的非角格（\(n\ge2\)） | 3 | 缺左或缺右 |
  | \(n=1\)（单行，\(m\ge2\)） | 端点 1、其余 2 | 整行没有任何上/下邻居 |
  | \(m=1\)（单列，\(n\ge2\)） | 端点 1、其余 2 | 整列没有任何左/右邻居 |
  | \(n=m=1\) | 0 | 唯一的格子没有邻居，答案必为 0 |

  ## 2. 算法

  **一句话核心思想**：每个格子独立处理——对四个正交方向各做一次"是否在界内且该位置为 `1`"的判断，把成立的次数累加，越界方向直接跳过（等价贡献 0）。

  **具体步骤**

  1. 读入 `n, m`；接着读入 `n` 个长度为 `m` 的字符串（必须按字符串/字符读，见第 6 节陷阱）。
  2. 对每个 \(0\le i<n,\ 0\le j<m\)：
     - `cnt = 0`；
     - 若 `i>0` 且 `g[i-1][j]=='1'`，`cnt++`；
     - 若 `i+1<n` 且 `g[i+1][j]=='1'`，`cnt++`；
     - 若 `j>0` 且 `g[i][j-1]=='1'`，`cnt++`；
     - 若 `j+1<m` 且 `g[i][j+1]=='1'`，`cnt++`。
  3. 按行输出 `cnt`，同行用单个空格分隔，行末换行；不输出任何其他字符。

  （等价写法：在网格外围补一圈 `0` 得到 \((n+2)\times(m+2)\) 的数组，就不用写四个边界判断。两种写法结果完全一致，本文代码用前一种，省一次内存分配。）

  ## 3. 正确性证明

  记 \(a(x,y)\) 为"扩充值"：当 \(1\le x\le n,\ 1\le y\le m\) 时取原网格的值，否则取 0。定义

  \[
  T(i,j)=a(i-1,j)+a(i+1,j)+a(i,j-1)+a(i,j+1).
  \]

  **引理 1（\(T\) 就是答案）。** 对任意网格内格子 \((i,j)\)，\(T(i,j)\) 恰等于其实际存在的正交邻居中值为 1 的个数。

  *证明.* 逐方向考察这四项。若该方向邻居落在网格内，则 \(a\) 取的就是该邻居的原值，而它确实是实际存在的邻居，贡献正确；若该方向越界，则 \(a=0\)，而题面规定该方向不存在邻居、不参与统计，贡献 0 也正确。四个方向互不相同且穷尽了全部正交邻居（上、下、左、右），故求和即为所求。整个式子中只出现了偏移 \((0,\pm1)\) 与 \((\pm1,0)\)，从未出现 \((\pm1,\pm1)\)，因此对角格子恒被排除。∎

  **引理 2（程序算的就是 \(T\)）。** 对每个 \((i,j)\)，程序累加出的 `cnt` 等于 \(T(i,j)\)。

  *证明.* 逐条对齐四个 `if`：程序仅在 `i>0` 时加上 `g[i-1][j]`，恰对应"\(i=1\) 时不存在上邻居、\(a(0,j)=0\)"；`i+1<n` 对应 \(i=n\) 时下邻居缺失；`j>0`、`j+1<m` 同理对应左右。字符比较 `=='1'` 与数值判 1 等价，因为题面保证每个字符只能是 `'0'` 或 `'1'`。故 `cnt` \(=T(i,j)\)。∎

  **定理（输出正确）。** 输出矩阵第 \(i\) 行第 \(j\) 个数就是格子 \((i,j)\) 的正确答案。

  *证明.* 外层循环 \(i=0..n-1\)、内层 \(j=0..m-1\)，每个格子 \((i,j)\) 恰好被处理一次、且只输出一个数，因此输出恰为 \(n\) 行、每行恰 \(m\) 个整数，形状正确；由引理 2 与引理 1，该数就是正确答案。格式上整数间单空格、行末换行、无任何附加文字，符合"按空白分隔的整数 token 逐个比较"的判题语义。∎

  **边界情形为何不需要单独论证**：引理 1 中的"扩充值 0"对所有下标一致成立。\(n=1\) 时上下两个条件恒不成立（等价于 \(a=0\)）；\(m=1\) 时左右两个条件恒不成立；\(n=m=1\) 时四项全不成立，`cnt=0`；\(n,m\ge2\) 时四角恰有两项成立、边界非角格恰有三项成立。无需任何特判。

  **样例自检**：\((3,3)\) 的上邻居 \((2,3)=1\)，左 \((3,2)=0\)，右 \((3,4)=0\)，下 \((4,3)=0\)，得 1，与题面一致；注意它的对角位置 \((4,2)\)、\((4,4)\) 都是 1，若误按 8 邻域计算会得到 3，这正是该样例用来区分"斜向不算"的关键点。\((1,1)=2\)、\((2,2)=3\) 亦已逐一核对通过。

  ## 4. 复杂度

  - 时间：\(O(nm)\)。每格 4 次常数判断 + 1 次输出，\(nm\le 2.5\times10^{5}\)，总操作量约 \(10^6\) 级。
  - 空间：\(O(nm)\) 存网格（\(2.5\times10^{5}\) 字节），输出缓冲同为 \(O(nm)\)；若不缓冲、逐行输出，则可降为额外 \(O(m)\)。

  ## 5. 边界情形清单

  1. \(n=1,\ m=1\)：输入 `0` 或 `1`，输出 `0`（该格没有任何邻居）。
  2. \(n=1,\ m=5\)，`11111` → `1 2 2 2 1`。
  3. \(m=1,\ n=5\)，五个 `1` → 逐行 `1 / 2 / 2 / 2 / 1`（单列，只有上下）。
  4. \(n=1\) 且全 0 → 全 0；\(m=1\) 且全 0 → 全 0。
  5. 全 0 网格（任意 \(n,m\)）→ 全 0 矩阵。
  6. 全 1 网格：内部 4、边界非角 3、四角 2；若 \(n=1\) 则退化为 `1 2 ... 2 1`。
  7. \(n=2\) 或 \(m=2\)：没有内部格，所有格子都属于"边界"情形，四个 `if` 中总有两到三个恒不成立，需保证不越界。
  8. 最大规模 \(n=m=500\)：250000 个输出整数，每个 0..4 一位数字，输出约 500 KB，需注意输出效率。
  9. 答案上界 4（不会出现 5），可用 `int`，也可直接 `char('0'+cnt)` 输出。

  ## 6. 风险与实现陷阱

  - **最大的坑：把每行当整数读**。`cin >> int` 会把 `0101` 读成十进制 101，并且还会跨行吞掉后续内容，直接把整个输入读错。必须读 `std::string`（或逐字符 `getchar`）。
  - **字符/数值混用**：`g[i][j] == 1` 是错的，应为 `== '1'`。
  - **越界访问**：写成 `if (i>=0 && g[i-1][j]...)` 之类会在 `i=0` 时访问 `g[-1]`（未定义行为，可能 RE 或答案错乱）。四个条件的下界必须是严格 `>` / `<`。
  - **行列颠倒**：先读 `n` 再读 `m`，是 \(n\) 行 \(m\) 列；`i` 管行、`j` 管列，写反会得到转置答案。
  - **斜向误计**：如把 8 邻域都统计，样例中 \((3,3)\) 会输出 3 而非 1，可用作自测断言。
  - **输出格式**：不能有任何提示语、不能输出 `Case #x:`、不能少最后一行；允许行尾多余空格和文件末缺换行，但仍建议规整输出。
  - **效率**：250k 个数用 `std::endl` 逐行冲洗不必要地慢，使用 `'\n'` 并配合 `sync_with_stdio(false)`（或一次性拼进缓冲区 `fwrite`）。
  - **索引体系混用**：若改用 1-based 或加圈填充，要整体统一；混用最易产生 off-by-one 的静默错误。
  - 本题只有一组测试数据，不要写 `while (cin >> n >> m)` 式的多测循环（虽不致命，但会让读入语义与题面不一致）。

  ## 7. 完整 C++17 程序

  ```cpp
  #include <cstddef>
  #include <cstdio>
  #include <iostream>
  #include <string>
  #include <vector>

  int main() {
      std::ios::sync_with_stdio(false);
      std::cin.tie(nullptr);

      int n = 0, m = 0;
      if (!(std::cin >> n >> m)) return 0;

      std::vector<std::string> g(n);
      for (int i = 0; i < n; ++i) {
          std::cin >> g[i];
      }

      std::string out;
      out.reserve(static_cast<std::size_t>(2) * static_cast<std::size_t>(n) *
                      static_cast<std::size_t>(m) +
                  static_cast<std::size_t>(n));

      for (int i = 0; i < n; ++i) {
          for (int j = 0; j < m; ++j) {
              int cnt = 0;
              if (i > 0 && g[i - 1][j] == '1') ++cnt;
              if (i + 1 < n && g[i + 1][j] == '1') ++cnt;
              if (j > 0 && g[i][j - 1] == '1') ++cnt;
              if (j + 1 < m && g[i][j + 1] == '1') ++cnt;
              if (j > 0) out.push_back(' ');
              out.push_back(static_cast<char>('0' + cnt));
          }
          out.push_back('\n');
      }

      std::fwrite(out.data(), 1, out.size(), stdout);
      return 0;
  }
  ```

  编译：`g++ -std=c++17 -O2 -o sol sol.cpp`。程序从 stdin 读入、向 stdout 输出，除结果矩阵外不输出任何字符。
