# 约数清点题解

## 思路

如果 $d$ 是 $n$ 的约数，那么 $n/d$ 也是约数，两个约数成对出现。对于每一对约数，至少有一个不超过 $\sqrt n$，因此只需要枚举到平方根。

枚举正整数 $i$，若 $i$ 整除 $n$：

- 当 $i^2=n$ 时，$i$ 与自己是同一个约数，只计数一次；
- 否则同时得到两个不同约数 $i$ 和 $n/i$，计数两次。

## 算法

1. 读入并检查 $1\le n\le 10^{12}$。
2. 从 `1` 开始枚举 `i`，循环条件写成 `i <= n / i`，避免计算 `i * i` 时发生溢出。
3. 对每个整除 `n` 的 `i`，按是否为平方根给答案加 `1` 或 `2`。
4. 输出答案。

独立的 C++ 参考解不使用成对枚举，而是分解 $n=p_1^{e_1}p_2^{e_2}\cdots$，利用

$$
\tau(n)=\prod_j(e_j+1)
$$

计算约数个数。

## 正确性证明

每个正约数 $d$ 都唯一属于一对 $(d,n/d)$。这对数中至少有一个不超过 $\sqrt n$，所以枚举一定会遇到它。若两个数不同，算法在较小的那个数处一次性将两者都计入；若两个数相同，则 $i^2=n$，算法只计入一次。因此每个正约数恰好被计数一次，最终答案就是 $n$ 的正约数个数。

## 复杂度

- 主解时间复杂度：$O(\sqrt n)$。
- 主解额外空间复杂度：$O(1)$。
- 质因数分解参考解的最坏时间复杂度同样为 $O(\sqrt n)$，额外空间复杂度为 $O(1)$。

## 实现注意事项

- 循环条件使用 `i <= n / i`，不要直接写 `i * i <= n`。
- 完全平方数的平方根只能计数一次。
- $n\le10^{12}$，使用 64 位整数足够保存输入；答案使用无符号 64 位整数保存也很安全。
