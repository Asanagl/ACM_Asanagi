## 环境

- **语言**：C++17 / C++20
- **编译器**：GCC (MinGW-w64)
- **IDE**：Visual Studio Code + GitLens

## 快速开始

### 克隆仓库
```bash
git clone git@github.com:Asanagl/ACM_Asanagi.git
```

### VSCode 工作流
1. 写完代码 → `Ctrl + S` 保存
2. `Ctrl + Shift + G` 打开源代码管理
3. `+` 暂存更改 → 输入提交信息 → `✓` 提交
4. `...` → 推送（或点击底部状态栏同步图标）

## Commit 规范

| 前缀 | 含义 |
|------|------|
| `add:` | 新增题目或模板 |
| `fix:` | 修正错误（如 TLE → AC） |
| `ref:` | 重构/优化代码 |
| `docs:` | 更新题解或笔记 |

示例：
```
add: CF 1800E - 树形DP + 换根
fix: 1800B 前缀和优化，避免暴力超时
```
